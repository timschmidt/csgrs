This candidate adds a private direct product for coefficients containing one
equal, non-unit radicand on each side. Inputs and fixed qualification/cost
protocols are prepared; no source is qualified or admitted yet.

The [coverage diagnostic](../2026-10-13-same-radicand-product-coverage/README.md)
observed 6,379,817 equal-radicand single-radical/no-atom products, or 29.06% of
all coefficient multiplications on the complete boards. Those counts do not
measure this candidate's non-unit guard, time share or allocation savings.
This trial starts from the unchanged endpoint/P4 parent with shared controls.

The original unsupported opaque-product guard remains first. The direct path
computes the constant product, left and right linear products, conditional
linear sum, radical coefficient product and final rational contribution in the
original arithmetic order. It skips addition for the same zero contributions
as ordinary insertion. A surviving radical retains the original left payload,
or the right payload when only its linear contribution survives. Equal-valued
radicands can have distinct storage and numeric caches.

The consumed left vector becomes the output buffer when one radical survives.
Exact cancellation drops scratch vectors. Empty atom capacity is released.
Unit radicands, unequal fields, wider vectors and other shapes keep the original
general body. Reversing the declared edits must recover that body and all other
runtime bytes exactly. Cache storage, normalizer traversal, memo publication,
depth/work limits and the mandatory retry after first-memo drop remain.

Twenty existing projection/storage/memo/alias controls are copied unchanged.
Eight additional tests are shared byte for byte by baseline and candidate.
They compare against the original general multiplier and independent exact
answers, exercise signed/zero/fractional and wide/unreduced values, check
radicand payload identity, observe buffer reuse and cancellation capacity, and
check opaque declines and graph release. The inherited cache and P4 controls
retain their original frontiers and stronger-facts contract.

Qualification will run 28 commands across fresh targets: both variants' focused
controls, 902 all-feature and 815 default scalar library tests, 28 doctests,
formatting, strict default/all-feature all-target Clippy and warning-denied
docs. Counts overlap. The same eight existing layouts, memo inventories and
ordinary-copy sharing are recorded, together with buffer/capacity observations.

If qualification passes, three unchanged historical scalar probes will run
twelve preflights and sixty measurements in five fixed paired blocks. Timing
and allocation executables are separate; all builds finish before probes and
every sample remains. Earlier eligibility comparisons may add work or touch
numeric caches sooner. Reusing a vector can preserve a larger capacity after
earlier cancellation. Both favorable and adverse timing, allocated/retained/
peak bytes and probe sizes must be assessed.

Native correctness, both original full-fixture limits, matched native costs and
receipts, complete report bytes, production CLI size and remaining workflows
are separate retention requirements. The full plan remains incomplete, with
all 39 properties, 14 targets and crate future work in scope. Individual ledger
statuses remain unchanged.
