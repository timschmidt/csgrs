The original unsupported opaque-product guard remains first. The direct path
computes the constant product, left and right linear products, conditional
linear sum, radical coefficient product and final rational contribution in the
original arithmetic order. It skips addition for the same zero contributions
as ordinary insertion. A surviving radical retains the original left payload,
or the right payload when only its linear contribution survives. Equal-valued
radicands can have distinct storage and numeric caches.

general body. Reversing the declared edits must recover that body and all other
runtime bytes exactly. Cache storage, normalizer traversal, memo publication,
