This measures existing retained-form copying during exact quadratic projection
in a separate copy of the qualified endpoint/P4 combination. Thread-local
contexts contain only cache addresses, which are never dereferenced. Fixed
counters distinguish root and recursive reads, missing cells/forms, completed
copies, retained shapes, query outcomes and original retries.

The accessor retains its original cache read, read guard, stored-form read and
single copy. The existing output receives a local name so a completed copy can
be counted before return. The quadratic query records its existing outcome;
the normalizer records an existing retry after releasing its first memo. No
new scalar query, scalar owner, arithmetic operation, cache write or recognition
pass is added. Counter callbacks inspect only existing vector lengths and term
powers. Unwinding restores the previous context, and query scopes cannot move
between threads.

The fixed qualification includes four helper calibrations, five site controls,
the eleven admitted sign regressions, six inherited cache controls, all 883
scalar library tests, five endpoint regressions, formatting, strict stack Clippy
and warning-denied scalar docs. Focused counts overlap the full scalar suite.
Only after those checks does one complete-board observation run, preserving
both original fixtures and the 120-second worker-CPU assertion.
