This experiment tests direct rational, pi and quadratic projection from a
retained Laurent polynomial. Its inputs are recorded before preparation,
qualification or measurement. No runtime is admitted.

Three fresh sources distinguish the unchanged endpoint/P4 baseline, the
previously rejected recursive-view control, and that control with direct
projection. The [scope](scope-v1.json) binds the source review and fixed cost
protocol. Earlier samples remain closed. This comparison neither admits the
recursive control nor attributes its earlier timing regressions to copying.

The projected variant borrows coefficient slices through a private read-only
trait and clones only the exact rational components returned to callers.
Rational zero, pi-power matching, quadratic shape checks and opaque rejection
keep their original meaning. The compacting consumer still materializes an
owned polynomial before reconstruction. Successful rational queries retain
their original sign publication, and quadratic dispatch tracing remains after
successful projection.

The existing owned/retained result enum, graph-free closed payload, recursive
arithmetic, memo insertion and ownership remain. The original retry follows a
failed reused-certificate pass after releasing its memo. No recognition pass,
cache fact, approximation, dependency, public API or budget is added. P4 permits
stronger cached facts, never contradictions or weaker available facts.

Preparation verifies the exact five method edits and added helper definitions,
recovers the recursive control's original tokens, and records three complete
source maps and delta archives. Shared historical tests remain identical.
Six new shared tests cover public projection queries, exact shape boundaries,
cancellation, high-precision sign retention and concurrent graph release.
Three additional private tests cover owned/retained projection shapes,
opaque ownership, payload immutability and release. Five inherited view tests
remain in both experimental variants.

Qualification will run 42 sequential commands: shared and inherited controls,
default/all-feature scalar libraries, doctests, formatting, strict
default/all-feature/all-target Clippy and warning-denied scalar docs. Counts
overlap and do not establish full-workflow coverage. Type layouts, memo counts
and ordinary-copy sharing are recorded separately from correctness.

If qualification passes, three unchanged scalar suites will run eighteen
preflights and ninety measurements in five predeclared three-source blocks,
with separate timing and allocation executables. Every library and probe build
finishes before measurements. All three paired contrasts share those samples;
they are not independent experiments. No sample extension is planned.

The recursive representation's Arc headers remain a retention risk. Borrowed
projection can also change generated code and binary size. Earlier board
instrumentation observed root retained-copy coverage of only 0.6244 percent;
that count is not a timing or savings estimate. Scalar results alone cannot
establish native performance. The original board worker-CPU limit of 120
seconds and copper-neck check-body-wall limit of 60 seconds remain mandatory,
along with native correctness, cost, report and production-size controls.
