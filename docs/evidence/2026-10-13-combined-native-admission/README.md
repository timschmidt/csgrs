# Combined native admission

Do not admit the complete combination to main: the direct library comparison
preserves every measured witness but leaves material construction and broad
consumer regressions. The [decision](decision-v1.json) retains all favorable
and adverse evidence. Main runtime and all 35 authorized native paths remain
unchanged. The full properties plan remains open.

The [source review](review-v1.json) read the 17 changed/added paths against
current main, including its admitted P4 repair. The broader workspace
comparison found only those paths plus the evidence ledger; the independent
comparison package is explicitly excluded from the workspace. The cache
retains rational data without graph owners and preserves the original bounded
fallback. Curve policy/receipt behavior has focused tests. MiMalloc belongs
to native executable/test roots, not independent library consumers.

The [fixed design](scope-v1.json) used four frozen source copies, separate
Cargo targets, byte-identical historical probes and System at library
boundaries. All builds finished before controls and costs. All 164 commands
succeeded: 110 cost processes, six abort controls, 20 preflights, builds and
shared metadata regressions. Formatting and both instrumented metadata
Clippy checks passed. No extra full-stack qualification was run in this phase.

All 365 timing and 134 allocation rows are in the
[assessment](library-assessment-v1.json). Each cost class has five alternating
fresh-process pairs. Witnesses, representation inventories and all 210 abort
receipt rows match between variants; all 231 historical broad witnesses match.

Two quadratic construction cases have median ratios 1.6562 and 1.6462; their
wide paired ranges remain in the data. Signed-word construction is 1.1006.
Some broad differences are small, while replacement/bounds and uncertain
bounds have median ratios 1.4882 and 1.6067. Pair directions and ratios are
descriptive observations, not statistical significance claims.

Thirty allocation rows have an increased field, including 29 with higher
phase-relative retained bytes. All counters are repeatable across the five
samples of each variant. These counters measure requested Rust bytes, not
RSS. For example, the rational multiradical first query retains 53,144 versus
275,096 additional bytes over its phase, for 1,000 inputs. All eleven measured
probe/test binaries are smaller; that does not resolve performance costs.

The earlier allocator trial remains valid: it passed both original native
gates and improved full-board costs against an already optimized parent,
with slower startup and larger CLI output. This experiment does not establish
current-main versus candidate whole-application costs. Further application
measurements of this complete combination are deferred.

The [next bounded combination](next-combination-v1.json) keeps the separable
integer-leaf, metadata, endpoint and process allocator changes without the
unadmitted persistent certificate cache. It is an unexecuted hypothesis, not
an attribution of these regressions. It must earn its own correctness, cost,
original-gate and full-report evidence before admission.

The [review correction](review-correction-v1.json) preserves the original
review while correcting the earlier scalar trial's row count to 68 timing
and 68 allocation rows. No original experiment or sample was rewritten.
