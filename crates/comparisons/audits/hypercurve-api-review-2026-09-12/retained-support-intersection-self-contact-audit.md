The new retained-domain resolver exposed an important difference between a geometric overlap and a complete parameter relation.

The independent diagnostic `retained-support-self-contact-probe.rs` uses the cubic with controls `(9,0), (-7,3), (-7,-10), (9,9)`. It passes through `(0,0)` at source parameters `1/4` and `3/4`. Splitting at the independently selected parameter `sqrt(1/2)` separates these two parameters. The two resulting curves meet both at their shared cut and at the off-diagonal crossing.

An initial implementation intersected the two full source supports and then clipped the returned overlap correspondence. The full source intersection described the diagonal overlap, so clipping retained only the common cut and incorrectly reported completeness. The pre-fix diagnostic in `retained-support-self-contact-probe.log` records exactly this failure: one contact, no origin contact, and `complete=true`.

The implementation now reuses the existing exact self-contact solver, which divides out the universal parameter diagonal before elimination. A full-domain identity, reversal, or endpoint-projective correspondence transports both ordered versions of each self-contact. The selected parameters, point witness, transversality and cross-sign proof survive filtering against both active domains. One prepared source span retains this replay for reuse by other span pairs in the same query. Independent reconstruction of the source is covered; pointer identity is not required.

Continuous retracing leaves another positive-dimensional relation after diagonal removal. Partial non-injective coincidences also require more than one chosen overlap correspondence to establish coverage. These cases retain explicit incompleteness; the resolver does not certify the clipped diagonal as the complete answer. A further step is to publish complete parameter-component coverage and reuse exact self-contact exclusion certificates when an axis-monotonicity certificate is unavailable. This remains part of the original implementation goal.

The final regression matrix exercises 32 self-crossing cases across independent/shared sources, both traversal directions, operand order and both policies. It checks both exact intersection points, their distinct source parameters and the crossing sign. A separate regression prevents a retraced quadratic from certifying a missing positive overlap.
