Baseline Hypercurve: `222e177628edbe07541e54c85a95ddf03b9cab8d`. The circle/analytic-parallel incidence builder still required the entire center source to be finite before using its already selected parameter. That constraint belongs to an unrestricted source query, not to a finite selected circle.

The new regression uses `P(t) = ((2 t^2 - 1)/(2 t - 1), 0)` with homogeneous quadratic controls `(-1,0,-1), (-1,0,0), (1,0,1)`. The source has a genuine pole at `t=1/2`. At the selected positive root `alpha` of `2 t^2 - 1`, isolated in `(1/2,3/4)`, `P(alpha)=(0,0)`. Its derivative numerator is `4(t-1/2)^2+1`, so its tangent points right. The zero-offset selected frame therefore defines the ordinary radius-one counterclockwise left semicircle. Selection at the pole itself must remain rejected.

Before the change, the regression reports an incomplete `Boundary` result (`selected-circle-local-frame-baseline.json`). With the fix, candidate finiteness is still checked across its whole domain. An unrestricted center still requires whole-domain finiteness and regularity. A selected center uses the existing finite-weight and nonzero-source-speed certificate at its exact parameter, along with the unchanged parallel derivative-scale condition. No equation, branch test, tangent predicate or parameter representation changes.
