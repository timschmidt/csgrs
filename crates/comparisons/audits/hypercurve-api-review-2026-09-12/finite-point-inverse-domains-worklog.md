The analytic test exposed a computational closure defect in selected-fiber sign replay. Its optional Bernstein shortcut consults only immediate scalar sign facts. Radical coefficients can lack those facts even when a refined box is decisively separated from zero. GDB snapshots of our isolated child and a temporary diagnostic build showed a negative normal-sheet value near -1.73 while root refinement continued. Full exact replay now supplements that shortcut with certified `RealInterval` evaluation; bounded speculative passes still yield before this work. Common-root evidence is tried before deeper refinement, and an exact nonzero decision is retained while resolving its sign. Wrong normal sheets are discarded before the remaining incidence equality is replayed. All temporary diagnostic code was removed before candidate 7.

They independently specify points on a true analytic parabola offset, both normal sheets, shifts 0/2/-2, source reversal, exact and algebraic point representations, negative homogeneous weights, folds with two preimages, stationary zero-offset points, unused source poles, positive-dimensional constant fibers, collapsed circular offsets, ordinary algebraic and compact selected endpoints, and both STRICT and APPROXIMATE_512. This is a targeted regression result, not a general throughput or allocation benchmark.
