# Exact tangent image retention and source signs

An exact tangent value is now one valid definition: a shared pair of represented coordinate roots or the existing Arc-backed derivative image. from_image is infallible and retains that image. represented_coordinates returns a borrowed pair only when the pair is already available; the former unconditional dx/dy getters are removed and every caller is migrated directly. No compatibility layer or fallible value extraction remains. Cloning these vectors shares their payload. Endpoint setup also retains all supplied exact higher derivatives instead of filtering source expressions.

For vectors u=(X1/D1,Y1/D1) and v=(X2/D2,Y2/D2) at one proved common selected parameter, cross(u,v)=(X1*Y2-Y1*X2)/(D1*D2) and dot(u,v)=(X1*X2+Y1*Y2)/(D1*D2). The previous selected determinant path now handles both bilinear operations. The strict selected-root identity check is unchanged; equal polynomials do not merge different roots. Denominator signs are certified separately before the numerator is reduced modulo the selected source polynomial and signed through the existing root authority. The squared norm is dot(u,u), so nonzero and zero tangents do not require coordinate projections.

Against an arbitrary exact constant vector (a,b), the numerator is a*X+b*Y for a dot product, b*X-a*Y for cross(image,constant), and a*Y-b*X for cross(constant,image). The source denominator sign is still required; constancy never cancels a pole. Constant recognition uses exact Real witnesses, without rational reconstruction. For represented coordinate pairs, the existing arithmetic and interval kernels are unchanged. Independent selected expressions without a common parameter or exact constant operand remain unresolved; their roots are not conflated.

Source scalar sign evidence retains both exact vector definitions and the bilinear operation. That is sufficient to replay the original selected-root identity/domain/sign computation. A certified zero also yields a represented zero scalar; a nonzero sign does not pretend that the scalar has acquired an independent coordinate root. Higher same-side normalization that still needs an unavailable scalar root remains an open extension, with its source derivatives now preserved. This change does not claim universal higher-order branch closure.

An unprojected derivative is reversed by negating its numerator coefficients while retaining the original selected parameter and denominator. This preserves the finite domain and keeps polynomial degree bounded. The existing represented-root negation helper is moved to the tangent authority and otherwise unchanged. No new parameter-owned cache is introduced; the existing Transformed-only cache restriction still prevents retained image/parameter cycles.

Public V881 fixture: P=4*t^3-pi, C=(P,t*P), alpha selected in (0,1). Degree-four Bernstein x controls [-pi,-pi,-pi,1-pi,4-pi] and y controls [0,-pi/4,-pi/2,-3*pi/4,4-pi] represent that curve exactly. At alpha its point is zero, while Cprime=(12*alpha^2,3*pi) has slope alpha. Since 0<alpha<1, this ray precedes a diagonal ray from an incoming horizontal direction. Both policies prove the point is represented and the tangent retains its source while lacking coordinate roots; both baseline traversals block Boundary. V883 changes only the coordinate-view observation to the new API and replays the same geometry/oracle. The integration regression also reverses the selected fragment and swaps candidates, giving eight traversal cases.

The source angular unit uses u=(1,3*alpha^2), its positive multiple, its ninety-degree rotation and its negation. Cross/dot signs determine positive/negative angular halves, while a pi-valued constant operand checks arbitrary exact coordinate support. Source sign evidence is replayed and double reversal preserves its ray. Existing distinct-root and negative homogeneous-weight source determinant regressions remain in the selected suite.

The full architecture goal remains active. General independent-expression scalar arithmetic, stationary/higher-jet branch closure and the earlier monotone overlap workload are not claimed solved here. Payload sharing and removal of coordinate cloning are structural changes; no measured uniform speedup is claimed.
