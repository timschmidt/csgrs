# Constrained fillet API: implemented contract and remaining work

The user explicitly requires additional exact center or contact constraints when a radius leaves a continuous family. Do not choose a representative or report NoSolution merely because contacts remain free.

## Implemented public contract

Hypercurve `0f1c54deaf26f89c7ff3d3acd92dc4f10d08c52e` introduces `CurveFillet2`: exact radius, optional exact center, and optional previous/next `CurveFilletContact2::{Point, Parameter}` constraints. Parameters name the incident input curve's authored chart. A point retains every incident preimage; a parameter selects one source visit. This distinction is mathematical, including repeated circular NURBS visits. Exact Real values and selected parameter/root evidence remain valid; no rational reconstruction is imposed on generic contacts.

Paths and regions return the finite `CurveCornerSolutions2` shared with chamfer. An unresolved supported continuous family reports `CurveError::FilletConstraintRequired`; contradictory slices give no solution, and undecided proofs remain blocked. Center/contact constraints are conjunctive. Public family selectors, their owned path/region reconstruction state and compatibility entry points are removed; all active callers were migrated directly. Historical benchmark JSON and frozen audit sources remain historical evidence.
