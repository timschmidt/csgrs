# Selected-parameter tangent determinant

For two admitted finite tangent images u=(X1(a),Y1(a))/D1(a) and v=(X2(a),Y2(a))/D2(a), the determinant is (X1*Y2-Y1*X2)(a)/(D1(a)*D2(a)). A certified selected parameter is enough to evaluate its sign. Independent coordinate-root construction is unnecessary and can discard correlations.

The implementation first proves that the parameter values coincide. It shares the pre-existing point-image identity routine: retained parameters use exact parameter equality, then their certified value comparison; mixed retained/materialized inputs compare represented parameter roots. It never treats equality of defining polynomials alone as proof of equality of selected roots. Tangent predicates call this authority under STRICT. The existing point-equality caller keeps its original policy and logic.

Both denominator signs are certified before combining the determinant. Zero denominators contradict admitted finite tangent values and are rejected; unresolved signs retain their uncertainty. Each negative denominator reverses the final sign. The combined numerator is reduced modulo the selected source polynomial and passed to the existing selected-polynomial sign authority. Reduction may retain the unreduced exact expression when undecided. No coordinate root, rational reconstruction, global polynomial inverse or new unchecked finite-domain flag is required.

Transformed tangent coordinate images already carry the same original denominator because they are built by the common coordinate-pair factory. The private coefficient view borrows those vectors or the retained-expression vectors. It adds no duplicate coefficient storage. The public retained-expression query keeps its existing optional meaning. Existing source construction, parameter ownership and transformed-only parameter caches remain unchanged. The shared polynomial product also accepts an empty zero factor without size underflow.

If neither image retains a selected parameter, or no common parameter is proved, the existing represented-coordinate arithmetic path is unchanged. This is a targeted exact-predicate capability, not a claim that all retained-vector angular/curvature ordering or all region compositions are complete.

Independent regression oracles use u=(1,3a^2) at 4a^3=pi. Its counter-clockwise rotation satisfies cross(u,Ru)=1+9a^4>0, reversal changes the sign, and scaling u leaves a zero determinant. Axis and stationary vectors cover mixed materialized inputs. C=(1/(1+t),t/(1+t)) has C''=(2,-2)/(1+t)^3, so cross(u,C'') is negative; positive and negative homogeneous weights check denominator-sign transport. Separately issued isolators select the same root. A quartic with two roots in [0,1] checks that the common defining polynomial cannot merge distinct selected values. These tests prove the predicate behavior; no new public region counterexample is claimed.
