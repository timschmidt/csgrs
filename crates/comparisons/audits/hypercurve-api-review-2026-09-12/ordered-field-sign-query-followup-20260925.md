# Ordered-field sign queries (read-only design)

V44's 50-second quartic stack samples exact Horner construction inside Hypersolve's polynomial_sign_at_if_separated: Rational.add_sub_wide_dyadic, tensor addition, recursive value addition, then the isolator's speculative midpoint query. This is one sample, not whole-run attribution. Hypercurve already normalizes the defining coefficient tuple before calling the isolator; adding another initial normalization would duplicate work.

The ordered-field trait currently exposes signs of constructed values only. Consider moving the existing polynomial-sign-at-represented-parameter operation into that trait, with its existing exact Horner implementation as the default algorithm and a certified interval-Horner override in Hypercurve. This would be an execution customization for the same predicate, not a compatibility alias; remove the free helper and update its two callers. All exact-zero and unresolved-interval cases must retain the current arithmetic/sign fallback. A cheap interval decline must never assert equality or discard roots. The original generic algorithm must remain valid for arbitrary exact coefficients.

Before implementing, measure enclosure preparation overhead: independently recomputing a dense base's source boxes for every coefficient can erase the arithmetic savings. Cache only certified successful preparation with a defensible coefficient identity; do not key a persistent cache by transient slice addresses. Avoid another public preparation state solely to optimize one caller. Every implementation/caller found so far is in hypersolve/{ordered_field_roots,root_sign,algebraic_fiber}.rs and hypercurve/bezier_offset.rs; repeat workspace search when editing.

Hypersolve validation should cover the default algorithm and a specialized predicate, endpoint and midpoint exact roots, repeated-root fallback, signed nonrational scales and tiny nonzero values. Hypercurve must retain the existing selected-sheet, local-root, deep-coefficient and quartic gates, and compare measured runtime against preserved exes. No production change has been made for this design.
