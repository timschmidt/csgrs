# Preserve the finite domain in algebraic ray queries

The V58 wrong geometric seed has a concrete domain-loss path. `algebraic_point_retained_rational_curve_ray_winding` obtains the actual retained range, but `algebraic_ray_project_selected_fiber_parameters` searches only `CurveParameterRange2::unit()` for an algebraic query parameter and `isolate_unit_interval_roots` for an Exact query parameter. Subsequent clipping against the retained range cannot recover omitted exterior roots. The boundary-incidence caller has the same defect.

For the pinched fixture B(t)=(t-1,(t-1)^2), cut t=1+a with a²+a⁴=1, the return chord midpoint is (a/2,a²/2). Its interior-side horizontal ray meets B at x=a/sqrt(2), hence t>1. Omitting that crossing gives left winding zero; deriving the opposite side by a unit jump then manufactures right winding -1 and selects the chord in reverse. Actual incident-ray ordering supplies the missing face links, but the geometric classifier must be fixed independently.

There is also an invalid domain assumption in `algebraic_ray_curve_weight_sign`: positivity of the original Bernstein weights proves the denominator sign only on [0,1]. Reuse `RationalBezier2::denominator_sign` on the requested finite range. Its implementation already guards unit caches and proves finite-range nonvanishing/sign. For materialized unit charts, the existing homogeneous Bernstein sign hull only requires the denominator sign over that chart; it need not require every control weight to have that sign.

Proposed machinery reduction: generalize the existing selected-fiber projection entry point to accept BezierParameter2, preserving its direct-resultant-first algebraic schedule and using the existing exact-parameter specialization for Exact. Update its seven internal callers and the two algebraic-ray consumers, passing the actual retained range. Delete the duplicated unit-only ray projector and weight-sign helper; keep final membership and selected-sheet replay. Do not add a compatibility wrapper.

Required regressions: the raw pinched region's algebraic chord-midpoint side winding is +1 (or -1 after reversal), not zero; boundary-incidence queries retain exterior roots; a rational quadratic with homogeneous denominator 1-t/2 restricted beyond t=2 has negative denominator even though all source unit weights are positive. For C(t)=(t/(2-t),t²/(2-t)) on [3,sqrt(10)], a ray from (-4,-44/5) in direction (1,0) crosses exactly once at t=(22-2sqrt(11))/5. Test both traversal directions and policies, and retain unit-domain/tangent/overlap controls. This is an audited follow-up, not yet an implemented or dynamically qualified fix.
