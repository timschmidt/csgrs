Review found a necessary SVG caller migration: `svg::region_from_paths` intentionally derives authored loop roles before applying its fill rule, so it must use the private raw input construction authority instead of the now-normalizing public constructor. This is not the complete normalized-region migration. Remaining public retained-loop constructors (`new`, `try_new_with_loop_topology`) and public traversal constructors still admit raw loops, public re-regularization remains redundant once every constructor is migrated, and several operation fallback producers need an audit of their topology certificates. Global authored winding semantics (including SVG multi-subpath winding) must be audited separately from per-loop material/hole composition; do not silently reinterpret either one.
