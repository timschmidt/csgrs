# Rational normalization boundary (read-only audit)

The V38 late chamfer stack includes Rational::mul_wide_with_dyadic_denominator during restoration of integer polynomial remainder coefficients. The mixed dyadic/general path computes an internal GCD before cross-cancellation. It is tempting to remove that work after the is_internally_unreduced guard, but the current flag is not a complete reducedness certificate: private from_parts_raw constructs unmarked tuples, and existing arithmetic tests intentionally consume an unmarked unreduced general operand. Decimal parsing is also documented as retaining unreduced parts. The canonicalized_ref method currently relies on the explicit lazy-coordinate flag.

A coherent normalization cleanup would first establish one invariant for every published Rational payload and migrate the raw construction paths directly. It must cover parsing, arithmetic temporaries, reduced-result constructors, lazy internal coordinate ratios and all retained arithmetic caches. Only then could the multiplication path consume a retained reducedness fact instead of rediscovering it. No scalar arithmetic is changed on the strength of this one sample, and no claim is made about its whole-run cost.
