# Mixed exact endpoint derivatives

Native derivative coordinates are arbitrary exact Real values. Hypersolve's existing from_exact_value retains their exact point meaning without requiring rational reconstruction. An already represented algebraic vector carries its selected coordinate root and validation information. Borrowing it preserves all that information. Thus these carriers can enter the same exact determinant, norm, curvature and graph-jet comparison. No selected source is replaced by an approximation or an unrelated polynomial root.

The all-native branch is unchanged. Other combinations promote only native values and borrow algebraic vectors through Cow; the representation-only filter is removed. Second derivatives are still requested only at a tangent tie, and third derivatives only after the existing exact signed-curvature equality guard. Missing derivative evidence remains missing. Selected parameter, source derivative reconstruction, reversal, domain/pole handling and arithmetic authorities are unchanged. The angular adapter also borrows represented vectors instead of cloning coefficient storage; this is a structural allocation reduction, not a measured general speedup.

V876 independently constructs native and selected endpoint fragments. The selected source uses z=t-1/2 at the selected root t=1/2; the native endpoint uses z=0. In the quadratic comparison, the first graph y=x^2 is below the second y=2*x^2 for x>0 and is encountered first counterclockwise from the incoming horizontal direction. For the equal-curvature comparison, A=(t,t^2), B=(u+u^2,u^2); at matched x=t=u+u^2, A_y-B_y=2*u^3+u^4>0, so B is encountered first. Choosing either endpoint as selected and swapping fragment positions must preserve these orders. The three equivalent source families are native quadratic, equal-weight rational conic and general rational Bezier. Both policies yield 48 requests. All 48 block in the qualified V874 parent. V878 will replay the exact same probe bytes.

The existing graph-jet unit oracle is extended from matching carrier pairs to all four pairs. For x=s*u+a*u^2, y=c*x^2+k*x^3, S=v dot v=s^2 and J=S*cross(v,j)-3*cross(v,a)*(v dot a)=6*k*s^6. The signed graph third derivative is 6*k, independently of s>0 and a. c ranges over +/-1 and +/-pi; 288 comparisons cover both policies, three speed pairs and lower/higher/equal graph coefficients. This checks that promoting arbitrary exact native values does not introduce a rational-only precondition.

The full semantic, representational, evidentiary and computational closure goal remains active. General retained-expression tangent ordering, stationary/higher-jet branches and the earlier monotone reparameterization workload remain unresolved; no new public region failure or universal closure claim is made here.
