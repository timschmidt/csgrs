# Shared selected-circle dispatch

Baseline Hypercurve: `41c645b169dbcf420cd1800e436fbf5468b4ed81`. The standalone public line/parabola fillet probe returned a certified selected circular arc whose self-intersection was incomplete (`Unsupported`). The baseline normal-library SHA is recorded in `circle-common-dispatch-baseline.json`.

The shared support dispatcher now handles selected circles against circles, rational spans, retained chords and analytic parallels in both operand orders. It keeps the original selected roots, parameter maps, contact points and transverse signs. Region code consumes the same circle overlap correspondence in place of three specialized clipping adapters and a second mapped-overlap enum. Isolated open-curve contacts and regularized region spans retain their different dimensional semantics. No compatibility API or alias was added.

A shared region step pairs corresponding overlap endpoints for both public reports and Boolean topology. Previously the region report mixed paired ranges with independently sorted ranges, although a trimming consumer already required paired endpoints. The public report now documents the paired contract; the topology consumer no longer computes a separate endpoint permutation. Root and parameter identities remain attached to the original source charts, including descending second ranges.

Initial circle/rational tests exposed a whole-source regularity constraint even when the circle's selected source point was regular. Circle construction now certifies finite weight and nonzero source speed at that point, and rational intersection reuses that local invariant. It also rejects the undefined source normal of a zero-distance parallel at a cusp; the parallel derivative-scale sign alone does not establish a source frame. The selected-center path in the two-normal solver still checks whole-source finiteness. That remaining constraint and a derived remote-pole fixture are recorded in `circle-common-dispatch-followup.json`; the fixture has not yet been run.

The first new non-PH circle/parallel matrix timed out after 180 seconds. Fixed-distance projection unnecessarily squared the one-radical equation again when an offset vanished, adding multiplicity and an irrelevant nonzero speed factor. The reduced norm keeps the original branch and tangent predicates. The identical matrix (both policies and operand orders, two transverse contacts and exact point replay) completed in 1.02 seconds in `circle-common-dispatch-reduced-norm-results.json`. This is one measured fixture, not a general throughput, allocation, memory or expression-depth result. The older higher-degree/reparameterized analytic witness still timed out at 60 seconds; it remains unqualified.

The new public fillet regressions exposed two evidence boundaries. The region's finite circle/chord endpoint-only certificate now belongs to the circle fragment and is reused by open curves, preserving the actual tangent cross sign. Circle contacts at retained endpoints reuse their original point and parameter evidence once parameter equality is certified. Direct exact scalar comparisons in a retained circle chart no longer require a separate geometric parameter wrapper. Distinct geometric chart comparisons still require their supports.

Eight new internal tests cover independent circle fields, crossings, tangencies, disjoint and complementary halves, retained chords, rational curves, nonunit B-spline/NURBS charts, oriented and singleton overlaps, local source regularity, analytic/non-PH parallels, and split-result reentry. Two new public regressions cover generated fillet self-overlap, restrictions, reversals and tangent neighbor contacts. Replays require Certified decisions and exact equality at every reported point or overlap endpoint.

The first broad run had one new failure: an older reversed circle/parallel overlap test required an independently ascending second range. Its caller expectations now use the paired contract, with additional exact endpoint replay over full and partial regions, swapped operands, reversed sources and mapped cuts. Two subsequent additions to that test needed fixture corrections: the full regions also share a straight edge, and that edge's prepared carrier uses a retained chord chart rather than the authored quadratic chart. The test now counts both spans, replays the chord's retained point authority and independently checks the straight-edge endpoints against `(0,0)` and `(1,0)`. These attempts are retained in the `circle-common-dispatch-pre-paired-region-qualification/`, `circle-common-dispatch-paired-region-before-fixture-correction/` and `circle-common-dispatch-paired-region-before-chart-correction/` directories.

The chart correction also identifies an unfinished public API boundary: a region carrier reference points back to the authored boundary, while preparation can use a distinct retained chord chart. Internal retained parameters preserve exact point authority, but public replay should expose the actual evaluable carrier/location. This is recorded in the follow-up instead of adding a compatibility adapter.
