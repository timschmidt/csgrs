# Retained-point finite domains: next audit

This is a static follow-up to committed Hypercurve `34ae22f1ca9059356b2a6a1fcb3f9263b2c46577`, not a demonstrated runtime counterexample or completed implementation. Keep the other session's Hyperreal verification work untouched and use the pinned dependency snapshots.

`BezierParallel2::point_incidence` and `contains_point` already accept the actual `CurveParameterRange2` for represented Point2 queries. The retained-point `contains_point_evidence` still has no range argument. Its represented, endpoint, analytic-point and similarity branches recurse into a unit range; its algebraic branch constructs native endpoints 0 and 1 and a unit-range algebraic ray. `BezierAlgebraicChordPairPoint2::incidence_on_parallel` also lacks a domain: represented-point admission, rational component shortcuts and recursive supporting-line projection use the native chart. A rational component shortcut must not replace an authored finite parameter interval by its complete materialized chord.

The production consumer `point_on_fillet_offset` matches `FilletOffsetCarrier2::Parallel { support, .. }` and discards the source that already carries the range. Audit the call's semantics before changing it: it may require finite membership, or a supporting-curve incidence for an extension, and those are different operations. An explicit finite/incident domain should supply the authority rather than accidentally inheriting unit discovery. The arc and chord alternatives currently query supporting geometry, so do not infer the intended parallel contract from the function name alone.

Start with a public counterexample and independent expected contact count on equivalent native/exterior charts, including selected/recursive query points. Prefer an existing certified point and curve from the completed fillet/chamfer fixtures so the admission and exact representation are already established. Check points both inside and outside the finite trim, overlap/constant-image cases, boundary ownership and policy identity. Preserve unsquared normal replay and local denominator/frame proofs. Do not merely widen native root discovery or materialize retained endpoints.

The full implementation goal also still includes normalized public-region construction, one-sided source-cusp frames, independent inverse replay, the recorded known failures and expensive exclusions, and broader algebraic/representation consolidation. The finite fixed-distance qualification does not discharge those requirements.
