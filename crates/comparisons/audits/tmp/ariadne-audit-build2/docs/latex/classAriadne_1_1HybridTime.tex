\doxysubsubsection{Description}
A value in a hybrid time domain, being a pair comprising a real {\itshape continuous\+\_\+time} and an integer {\itshape discrete\+\_\+time}. 

When a Hybrid\+Time is used to define a bound on a hybrid evolution, the evolution should stop when {\itshape either} the continuous time or the discrete time reaches the bounding value. This is to ensure that the evolution time is finite; in particular, that no Zeno behaviour occurs. \begin{Desc}
