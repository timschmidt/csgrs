\hypertarget{group__FunctionModule}{}\label{group__FunctionModule}\index{Function Module@{Function Module}}


\doxysubsubsubsection{Description}
Functions on Euclidean space, including the \doxylink{classAriadne_1_1Function}{Function\texorpdfstring{$<$}{<}P,SIG\texorpdfstring{$>$}{>}} generic template class. 

{\itshape For the mathematical theory of computable functional analysis, see the \doxysectlink{functional_analysis_page}{Functional Analysis}{0} Page.}

In this module are the classes used to represent concrete functions in Euclidean space. These functions can be used as the building blocks for geometric objects and dynamic systems.

The main \doxylink{classAriadne_1_1Function}{Function\texorpdfstring{$<$}{<}P,SIG\texorpdfstring{$>$}{>}} class represents continuous functions. Since any continuous function $\R^n\to\R$ can be approximated arbitarily accurately be a polynomial function on a bounded domain, functions can compute polynomial approximations by application to a \doxylink{classAriadne_1_1TaylorModel}{Taylor\+Model}.\hypertarget{group__FunctionModule_function_information_section}{}\doxysubsubsubsubsubsection{\texorpdfstring{Function information tag.}{Function information tag.}}\label{group__FunctionModule_function_information_section}
The information tag (computational paradigm) {\ttfamily P} describes whether the function is exact, effective, validated or approximate. (See the Information\+Module for more information.) Type aliases are provided, so \doxylink{group__FunctionModule_ga1ce9d5a1cfb352fbd1daf2f696740357}{Effective\+Function\texorpdfstring{$<$}{<}SIG\texorpdfstring{$>$}{>}} is an alias for \doxylink{classAriadne_1_1Function}{Function}\texorpdfstring{$<$}{<}\doxylink{structAriadne_1_1EffectiveTag}{Effective\+Tag},SIG\texorpdfstring{$>$}{>}.

An effective function can be evaluated arbitrarily accurately given arbitrarily accurate approximations to the input. Hence if $f$ is a \doxylink{group__FunctionModule_ga1ce9d5a1cfb352fbd1daf2f696740357}{Effective\+Function}, then it can be automatically converted to a \doxylink{group__FunctionModule_gad8dd512fc373fa20822aefa98e73ab5a}{Validated\+Function}.\hypertarget{group__FunctionModule_function_signature_section}{}\doxysubsubsubsubsection{\texorpdfstring{Function signatures}{Function signatures}}\label{group__FunctionModule_function_signature_section}
The signature {\ttfamily SIG} takes the form {\ttfamily RES(\+ARGS...)} where {\ttfamily RES} describes the output and {\ttfamily ARGS...} the input. Hence a signature {\ttfamily Real(\+Real)} indicates a function $\R\to\R$, whereas {\ttfamily \doxylink{group__LinearAlgebraSubModule_ga00e69bf76ffebd1f3ba573f4662134bc}{Real\+Vector(\+Real\+Vector,\+Real)}} would indicate a function $\R^n\times\R\to\R^m$. \begin{DoxyRemark}{Remarks}
Currently, only \doxylink{classAriadne_1_1Real}{Real} and \doxylink{group__LinearAlgebraSubModule_ga00e69bf76ffebd1f3ba573f4662134bc}{Real\+Vector} are supported types for use in {\ttfamily RES} and {\ttfamily ARGS}, with \doxylink{group__LinearAlgebraSubModule_ga7a29a46d50b613534f91019281b45309}{Real\+Scalar} a synonym for \doxylink{classAriadne_1_1Real}{Real}. 
\end{DoxyRemark}

Evaluate a power series on an algebra using Horner\textquotesingle{}s rule. 

For a polynomial in $n$ variables, Horner\textquotesingle{}s rule is a recursive formula \[ p(x) = \bigl( \bigl(  x^{d_k-d_{k-1}} q_k(\hat{x})x^{d_0} + \cdots + q_1(\hat{x}) \bigr) x^{d_1-d_0} + q_0(\hat{x}) \bigr) x^{d_0} \] where $\hat{x}=(x_1,\ldots,x_{n-1})$ and $q_i$ is the polynomial of terms in $x_n^{d_i}$. To evaluate a polynomial using Horner\textquotesingle{}s rule without using recursive function calls, we maintain registers $r_k$ containing the current evaluation of a polynomial in $(x_1,\ldots,x_k)$.

We list the terms in reverse lexicographic order, defined as $\alpha \prec \beta$ if $\alpha_j>\beta_j$, where $j=\max\{i\mid \alpha_i\neq\beta_i\}$. For a given term $c_\alpha x^\alpha$, let $k=\max\{j\mid \alpha_j\neq\beta_j\}$, where $\beta$ is the next multi-\/index. We update register $r_k$ by \[r\textnormal{\textquotesingle}_k=(((c_\alpha + r_1) x^{\alpha_1} + r_2 )x^{\alpha_2}+\cdots r_k)x^{\alpha_k-\beta_k}.\] The result is obtained by updating a fictional register $r_{n+1}$ at the last step. See J. M. Pena and T. Sauer, "{}\+On the multivariate Horner scheme"{}, SIAM J. Numer. Anal. 37(4) 1186-\/1197, 2000.
