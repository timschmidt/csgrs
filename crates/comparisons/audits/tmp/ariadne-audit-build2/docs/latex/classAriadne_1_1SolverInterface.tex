\doxysubsubsection{Description}
Interface for solving (nonlinear) equations. 

\doxylink{structAriadne_1_1Two}{Two} main kinds of problem are considered. The problem of finding roots of a function $ f $, which are solutions to the equation $f(x)=0$, is addressed by the \doxylink{classAriadne_1_1SolverInterface_a92a518351d9fdf6515a69508825caff2}{solve()} method, The problem of finding a function $ h $ such that $ f(x,h(x))=0 $ is addressed by the \doxylink{classAriadne_1_1SolverInterface_ab6a863c0fa99c7dd6410708e1be464f9}{implicit()} method.

Additionally two parameters are defined which are applicable to any implementation. The \doxylink{classAriadne_1_1SolverInterface_acc567896bfc4044b855b87ffa69b3d28}{maximum\+\_\+error()} provides an upper bound on the size of a box containing a solution point, uniforma bounds for an implicit function. The \doxylink{classAriadne_1_1SolverInterface_a11e3046b9e45bd1f2a87dde7069f8036}{maximum\+\_\+number\+\_\+of\+\_\+steps()} provides a timeout mechanism. {\em bx} & A coordinate-\/aligned box $B$ in $\R^n$ for which the root is to be found.\\
\hline
\end{DoxyParams}
A root $p$ of $f$ is {\itshape transverse} if the Jacobian derivative matrix $Df(p)$ is nonsingular. The solution method should converge to a transverse root $p$ if the box $B$ contains $p$ in its interior, and is sufficiently small.

The choice of box in which to search is to be determined by the user. If the box is too big, then the solution typically fails. The semantics of the method requires that there be a uniqure root in the box, and many algorithms also require the Jacobian derivative matrix $Df(x)$ to be nonsingular over the entire box. The Jacobian derivative is nonsingular over a sufficiently small neighbourhood of a transverse root. However, choosing too small a box may also cause the algorithm to fail if the root is too close to the boundary.

The \doxylink{classAriadne_1_1SolverInterface_ad4b9d5462b0b992b3ec63810f984b623}{solve\+\_\+all()} method is an algorithm which attempts to find all roots.

Solve $f(a,x)=0$ for $a$ in $A$, looking for a solution with $x$ in $X$. The result is a function $h$ with domain $A$ such that $f(a,h(a))=0$ for all $a\in A$.

\hline
{\em A} & A subset of $\R^m$ giving the required domain of the solution function $h$. \\
\hline
{\em X} & A subset of $\R^n$ giving a codomain of $h$ i.\+e. $h$ satisfies $h(a)\in X$ for all $a\in A$. \\
\hline
\end{DoxyParams}
\begin{DoxyWarning}{Warning}
If the domain {\itshape A} is too large, there may not be a continuous solution over it. If the codomain {\itshape X} is too small, then there may not be a solution within it, but if it is too large, there may not be a unique solution, and some solvers may have problems with the first few steps of the solution.
\end{DoxyWarning}
A {\itshape strong solution} to the problem exists if for every $a\in A$, there is a unique solution $x\in X$ to the equation $f(a,x)=0$, and this solution varies continuously in $a$. A {\itshape weak solution} is a function $h$ with domain $A$ such that $f(a,h(a))=0$ for all $a\in A$, if $f(a,x)=0$ for $x\in X$ then $h(a)=x$, and there exists $(a,x)\in A\times X$ such that $f(a,x)=0$. If $D_2f(a,x)$ is nonsingular for all $(a,x)\in A\times X$, then any solution is guaranteed to be unique. May throw a \doxylink{classAriadne_1_1NoSolutionException}{No\+Solution\+Exception}, but {\itshape only} if there are no solutions to $f(a,x)=0$ in $A\times X$. If there is a continuous branch of solutions $x=h(a)$ such that $h(a)\in X$ for some parameter values, but $h(a)\not\in X$ for others, then $h$ is a valid result for the function.
