\hypertarget{nonlinear_programming_page_standard_nonlinear_optimisation}{}\doxysubsubsection{\texorpdfstring{Standard optimisation problem}{Standard optimisation problem}}\label{nonlinear_programming_page_standard_nonlinear_optimisation}
Consider the nonlinear programming problem \[ \boxed{ \max f(x) \text{ s.t. } g_j(x)\geq 0,\ j=1,\ldots,l; \ h_k(x) = 0,\ k=1,\ldots,m . } \] Applying a penalty function yields the unconstrained maximisation of \[ f(x) + \mu  \sum_{j=1}^{l} \log g_j(x) - \frac{1}{2\nu} \sum_{k=1}^{m} (h_k(x) )^2 . \] Differentiating with respect to $x$ yields \[ \nabla_{\!i\,} f(x) + \mu  \sum_{j=1}^{l} \frac{\nabla_{\!i\,}g_j(x)}{g_j(x)} - \frac{1}{\nu} \sum_{k=1}^{m} h_k(x)\nabla_{\!i\,}h_k(x) = 0. \] Setting $\lambda_j = \mu/g_j(x)$ and $\kappa_k = - h_k(x)/\nu$ yields \[ \nabla_{\!i\,} f(x) +  \sum_{j=1}^{l} \lambda_j \nabla_{\!i\,}g_j(x) + \sum_{k=1}^{m} \kappa_k\,\nabla_{\!i\,}h_k(x) . \] Combining these equations yields \[ \begin{gathered} \nabla f(x) + \sum_{j=1}^{l} \lambda_j \nabla g_j(x) + \sum_{k=1}^{m} \kappa_k \nabla h_k(x) = 0; \\ \lambda_j g_j(x) - \mu = 0; \\ h_k(x) + \nu \kappa_k = 0; \\ \lambda_j \geq 0; \ g_j(x) \geq 0 . \end{gathered} \] Setting $\nu=0$ these equations yields the {\itshape central path} for the problem, which is a relaxation of the optimality conditions \[ \boxed{ \begin{gathered} \nabla f(x) + \sum_{j=1}^{l} \lambda_j \nabla g_j(x) + \sum_{k=1}^{m} \kappa_k \nabla h_k(x) = 0; \\ \lambda_j g_j(x) = \mu; \\ h_k(x) = 0; \\ \lambda_j \geq 0; \ g_j(x) \geq 0 . \end{gathered} } \] Taking $\mu\to0$ yields the standard Karush-\/\+Kuhn-\/\+Tucker conditions for optimality \[ \boxed{ \begin{gathered} \nabla f(x) + \sum_{j=1}^{l} \lambda_j \nabla g_j(x) + \sum_{k=1}^{m} \kappa_k \nabla h_k(x) = 0; \\ \lambda_j g_j(x) = 0; \\ h_k(x) = 0; \\ \lambda_j \geq 0; \ g_j(x) \geq 0 . \end{gathered} } \]

A Lagrangian for this problem is \[ \boxed{\displaystyle L(x,\lambda,\kappa) = f(x) + \sum_{j=1}^{l} \lambda_j g_j(x) + \sum_{k=1}^{m} \kappa_k h_k(x) . } \] The standard Karush-\/\+Kuhn-\/\+Tucker conditions for optimality are obtained by setting the partial derivatives of $L$ to zero, with the inequality constraints $\lambda_j,g_j(x)\geq0$ allowing for the relaxation $\lambda_j=0 \vee g_j(x)=0$.

The standard (Fritz) John conditions for optimality are \[ \boxed{ \begin{gathered} \mu \nabla f(x) + \sum_{j=1}^{l} \lambda_j \nabla g_j(x) + \sum_{k=1}^{m} \kappa_k \nabla h_k(x) = 0; \\ \lambda_j g_j(x)=0; \\ h_k(x)=0; \\ \mu + \sum_j \lambda_j + \sum_k \kappa_k^2 = 0; \\ \lambda_j \geq 0; \ g_j(x) \geq 0 . \end{gathered} } \]

\begin{DoxyNote}{Note}
Taking $f(x) = -cx$, $g(x)=-x$ and $h(x)=Ax-b$ yields the primal linear programming problem $\min cx \mid Ax=b,\ x\geq 0$. Taking $f(y)=yb$, $g(y) = yA-c$ yields the dual linear programming problem $\max yb \mid yA\leq c$. This means that the standard {\itshape primal} nonlinear programming problem with only affine inequality constraints more closely resembles the {\itshape dual} linear programming problem. Despite this, we shall use {\ttfamily x} for the primal variables of the standard primal nonlinear programming problem.
\end{DoxyNote}

Consider the problem \[ \max f(x) \text{ s.t. } g(x) \geq 0 . \] The central path is defined by \[ \boxed{ \begin{gathered}  \nabla f(x) + \lambda \cdot \nabla g(x) = 0; \\ \lambda g(x) = \mu; \\ \lambda \geq 0,\ g(x) \geq 0. \end{gathered} } \] Taking $\mu\to 0$, we obtain the standard Karush-\/\+Kuhn-\/\+Tucker conditions. \[ \boxed{ \begin{gathered}  \nabla f(x) + \lambda \cdot \nabla g(x) = 0; \\ \lambda g(x) = 0; \\ \lambda \geq 0,\ g(x) \geq 0. \end{gathered} } \]\hypertarget{nonlinear_programming_page_nonlinear_equality_constraints}{}\doxysubsubsection{\texorpdfstring{Equality constrained optimisation problem}{Equality constrained optimisation problem}}\label{nonlinear_programming_page_nonlinear_equality_constraints}
Consider the problem \[ \max f(x) \text{ s.t. } h(x) = 0 . \] The central path is defined by \[ \boxed{ \begin{gathered}  \nabla f(x) + \kappa \cdot \nabla h(x) = 0; \\ h(x) + \kappa \mu = 0. \end{gathered} } \] The Karush-\/\+Kuhn-\/\+Tucker optimality conditions are \[ \boxed{ \begin{gathered}  \nabla f(x) + \kappa \cdot \nabla h(x) = 0; \\ h(x) = 0. \end{gathered} } \]

The problem can be relaxed by adding the penalty function $-g(x)^2/2\mu$. Then the optimality conditions are \[ \nabla f(x) - \frac{g(x)}{\mu} \nabla g(x) = 0\] Taking Lagrange multiplier $\lambda = g(x)/\mu$, we obtain \[ \boxed{ \begin{gathered} \nabla f(x) -  \lambda \nabla g(x) = 0; \\ g(x) - \lambda \mu = 0 \end{gathered} } \] which relaxes to $g(x)=0$ as $\mu\to0$.\hypertarget{nonlinear_programming_page_nonlinear_bounded_constraints}{}\doxysubsubsection{\texorpdfstring{Bounded constraints}{Bounded constraints}}\label{nonlinear_programming_page_nonlinear_bounded_constraints}
Consider the problem \[ \max f(x) \text{ s.t. } |g(x)| \leq \delta \] We can handle the problem in two ways; either by considering the smooth constraint $\delta^2-g(x)^2\geq0$ or the two constraints $\delta + g(x) \geq 0$ and $\delta - g(x)\geq 0$.

In the former case, we obtain the conditions \[ \begin{gathered} \nabla f(x) + 2 \lambda g(x) \nabla g(x) = 0; \\ \lambda (\delta^2 - g(x)^2) = \mu. \end{gathered} \] Replacing the standard Lagrange multiplier $\lambda$ with $-2\lambda g(x)$, we obtain \[ \begin{gathered} \nabla f(x) - \lambda \nabla g(x) = 0; \\ -\lambda (\delta^2 - g(x)^2) / 2g(x) = \mu. \end{gathered} \] Rearranging the second formula gives \[ \boxed{ \begin{gathered} \nabla f(x) - \lambda \nabla g(x) = 0; \\ \bigl(\delta^2-g(x)^2\bigr) \lambda + 2 g(x) \mu = 0 . \end{gathered} } \] Differentiating gives \[ (\delta^2-g(x)^2) {\Delta\lambda} + (2 \mu - 2 g(x) \lambda) \nabla g(x) {\Delta x} = 0\] In order to solve for ${\Delta x}$ in terms of ${\Delta\lambda}$, we require $ \mu -  g(x) \lambda \neq 0$. Since the optimal $x^*,\lambda^*$ satisfy $(\delta^2-g(x^*)^2) \lambda^* + 2 g(x^*) \mu = 0$, we have $\lambda^* g(x^*) \geq 0$.

In the former case, we obtain the conditions \[ \begin{gathered} \nabla f(x) - \lambda^+ \nabla g(x) + \lambda^- \nabla g(x) = 0; \\ \lambda^+ (\delta + g(x)) = \mu; \\ \lambda^- (\delta - g(x)) = \mu \end{gathered} \] Set $\lambda = \lambda^+ - \lambda^-$. Then we have \[ \lambda = \mu \biggl( \frac{1}{\delta+g(x)} - \frac{1}{\delta-g(x)}\biggr) = \frac{-2\mu g(x)}{\delta^2-g(x)^2} . \] Rearranging again gives \[ (\delta^2-g(x)^2) \lambda + 2 g(x) \mu = 0\] Note that $\lambda^+ + \lambda^- = 2\delta\mu/(\delta^2-g(x)^2) \geq \bigl|\lambda^+-\lambda^-\bigr| $\hypertarget{nonlinear_programming_page_nonlinear_state_constraints}{}\doxysubsubsection{\texorpdfstring{State constraints}{State constraints}}\label{nonlinear_programming_page_nonlinear_state_constraints}
Setting $g(x)=x$ and taking $\underline{x}\leq x\leq\overline{x}$, we obtain the state constraints \[ \boxed{ \begin{gathered} \nabla f(x) - \lambda \nabla g(x) = 0; \\ (\overline{x}-x)(x-\underline{x})\lambda + (2x-\underline{x}-\overline{x}) \mu = 0 . \end{gathered} } \] If $\overline{x}=-\underline{x}=\delta$, this simplifies to \[ (\delta^2-x^2) \lambda + 2 x \mu = 0 . \] Differentiating yields \[ {\Delta\lambda} = -2\mu \frac{\delta^2+x^2}{(\delta^2-x^2)^2} {\Delta x} \] which can be used to eliminate these Lagrange multipliers entirely.\hypertarget{nonlinear_programming_page_general_nonlinear_optimisation}{}\doxysubsection{\texorpdfstring{General Optimisation Problem}{General Optimisation Problem}}\label{nonlinear_programming_page_general_nonlinear_optimisation}
In Ariadne, we need to problems with a more general form of the constraints including bounds on the variables and constraints with upper and lower bounds. We henceforth consider the generalised problem\+: \[ \boxed{\min f(x) \text{ s.t. } \underline{w}_j \leq g_j(x)\leq  \overline{w}_j, \ j=1,\ldots,m; \  \underline{x}_i \leq x_i\leq  \overline{x}_i,\ i=1,\ldots,n. } \] We make the constraints on $g$ into equality constraints by introducing variables ${w}_i$ \[ g_j(x) - w_j = 0, \ \underline{w}_j \leq w_j \leq \overline{w}_j,\ j=1,\ldots,m. \] We add a penalty function, and attempt to minimise the function \[ \boxed{ f(x) - \mu \sum_{j=1}^{m} \bigl(\log(w_j-\underline{w}_j) + \log(\overline{w}_j-w_j) \bigr) - \mu \sum_{i=1}^{n} \bigl( \log(x_i-\underline{x}_i) + \log(\overline{x}_i-x_i) \bigr)  + \frac{1}{2\nu} \sum_{j=1}^{m} (g_j(x)-w_j)^2 . } \] Differentiating with respect to $w$ and $x$ gives \[ \begin{gathered} \nabla_{\!i\,}f(x) - \mu \Bigl( \frac{1}{x_i-\underline{x}_i} - \frac{1}{\overline{x}_i-x_i} \Bigr) + \frac{1}{\nu} \sum_{j=1}^{m} (g_j(x)-w_j) \nabla_{\!i\,}g_j(x) = 0; \\  - \mu \Bigl(\frac{1}{w_j-\underline{w}_j} - \frac{1}{\overline{w}_j-w_j} \Bigr) - \frac{1}{\nu} (g_j(x)-w_j) = 0.  \end{gathered} \] Setting $y_j = -(g_j(x)-w_j)/\nu$ gives \[ \begin{gathered}  \mu \Bigl(\frac{1}{w_j-\underline{w}_j} - \frac{1}{\overline{w}_j-w_j} \Bigr) -  y_j = 0; \\ \nabla_{\!i\,}f(x) - \mu \Bigl( \frac{1}{x_i-\underline{x}_i} - \frac{1}{\overline{x}_i-x_i} \Bigr) - \sum_{j=1}^{m} y_j \nabla_{\!i\,}g_j(x) = 0; \\ g_j(x)-w_j + \nu\,y_j = 0.  \end{gathered} \] Setting $\nu=0$ simplifies to \[ \boxed{ \displaystyle \begin{gathered}  \mu  \Bigl(\frac{1}{w_j-\underline{w}_j} - \frac{1}{\overline{w}_j-w_j} \Bigr) -  y_j = 0; \\ \nabla_{\!i\,}f(x) - \mu \Bigl( \frac{1}{x_i-\underline{x}_i} - \frac{1}{\overline{x}_i-x_i} \Bigr) - \sum_{j=1}^{m} y_j \nabla_{\!i\,}g_j(x) = 0; \\ g_j(x)-w_j = 0.  \end{gathered} } \] Setting $z_i=\mu \bigl( 1/(x_i-\underline{x}_i) - 1/(\overline{x}_i-x_i) \bigr)$ gives \[ \boxed{ \displaystyle \begin{gathered}   \mu  \Bigl(\frac{1}{w_j-\underline{w}_j} - \frac{1}{\overline{w}_j-w_j} \Bigr) -  y_j = 0; \\ \mu \Bigl( \frac{1}{x_i-\underline{x}_i} - \frac{1}{\overline{x}_i-x_i} \Bigr) - z_i = 0; \\ \nabla_{\!i\,}f(x) - z_i - \sum_{j=1}^{m} y_j \nabla_{\!i\,}g_j(x) = 0; \\ g_j(x)-w_j + \nu\,y_j= 0.  \end{gathered} } \] It is possible to eliminate the dual variables $y_j$ to obtain the alternative (and less useful) form \[ \begin{gathered}  -\nabla_{\!i\,}f + \mu \biggl( \frac{1}{x_i-\underline{x}_i} - \frac{1}{\overline{x}_i-x_i} \biggr) + \mu \sum_{j=1}^{m} \biggl( \frac{1}{w_j-\underline{w}_j} - \frac{1}{\overline{w}_j-w_j} \biggr) \nabla_{\!i\,} g_j(x) = 0; \quad  g_j(x) - w_j + \nu\,y_j = 0.  \end{gathered} \]

Note that if $\underline{x}_i=0$ and $\overline{x}_i=\infty$, then \[ \mu ( 1/x_i - 1/\infty ) - z_i = 0  \] so \[ x_i\,z_i = \mu . \]

Note that if $ \underline{w}_j = \overline{w}_j $, then $ w_j = \underline{\overline{w}}_j $ and we can set $y_j$ arbitrarily. Hence $\mu  \bigl(\frac{1}{w_j-\underline{w}_j} - \frac{1}{\overline{w}_j-w_j} \bigr) -  y_j = 0$ is replaced by $w_j-\underline{\overline{w}}_j$ for this $j$.\hypertarget{nonlinear_programming_page_nonlinear_optimisation_as_linear}{}\doxysubsubsection{\texorpdfstring{The linear case}{The linear case}}\label{nonlinear_programming_page_nonlinear_optimisation_as_linear}
If $f(x) = c^Tx$, $g(x)=Ax-b$, $\underline{w}=\overline{w}=0$, $\underline{x}=0$ and $\overline{x}=\infty$, then $w=0$ and we obtain the conditions \[  x_i\,z_i = \mu; \quad A^Ty + z = c; \quad Ax + \nu\,y = b,\] which are a relaxed version of the standard conditions for linear programming

Conversely, if $f(x)=-b^Tx$, $g(x)=c-A^Tx$, $\underline{w}=0$, $\overline{w}=\infty$, $\underline{x}=-\infty$ and $\overline{x}=+\infty$, then $z=0$ and \[  w_j\,y_j = 0; \quad Ay = b; \quad A^T x+w = c + \nu\,y = 0 . \] This is a relaxed version of the standard conditions for linear programming with $w$ instead of $z$ for the slack variables, and $x$ and $y$ interchanged.\hypertarget{nonlinear_programming_page_general_nonlinear_feasibility}{}\doxysubsection{\texorpdfstring{General feasibility problem}{General feasibility problem}}\label{nonlinear_programming_page_general_nonlinear_feasibility}
Consider the generalised feasibility problem\+: \[ \boxed{ \underline{w}_j \leq g_j(x)\leq  \overline{w}_j, \ j=1,\ldots,m; \  \underline{x}_i \leq x_i\leq  \overline{x}_i;\ i=1,\ldots,n. } \] where $-\infty < \underline{x}_i < \overline{x}_i < +\infty$.

A similar analysis to the minimisation problem with $f(x) = 0$ gives the relaxation \[ \begin{gathered}  \mu \Bigl(\frac{1}{w_j-\underline{w}_j} - \frac{1}{\overline{w}_j-w_j} \Bigr) -  y_j = 0; \\  \mu \Bigl( \frac{1}{x_i-\underline{x}_i} - \frac{1}{\overline{x}_i-x_i} \Bigr) + \sum_{j=1}^{m} y_j \nabla_{\!i\,}g_j(x) = 0; \\ g_j(x)-w_j + \nu\,y_j = 0.  \end{gathered} \] Setting $z_i=\mu \bigl( 1/(x_i-\underline{x}_i) - 1/(\overline{x}_i-x_i) \bigr)$ gives \[ \boxed{ \displaystyle \begin{gathered}   \mu  \Bigl(\frac{1}{w_j-\underline{w}_j} - \frac{1}{\overline{w}_j-w_j} \Bigr) -  y_j = 0; \\ \mu \Bigl( \frac{1}{x_i-\underline{x}_i} - \frac{1}{\overline{x}_i-x_i} \Bigr) - z_i = 0; \\ z_i + \sum_{j=1}^{m} y_j \nabla_{\!i\,}g_j(x) = 0; \\ g_j(x)-w_j + \nu\,y_j= 0.  \end{gathered} } \]

The {\itshape Lagrangian} function is defined as \[ \boxed{ \displaystyle L(w,x,y) = \sum_{j=1}^{m} \bigl( \log(w_j-\underline{w}_j)+\log(\overline{w}_j-w_j) \bigr) + \sum_{i=1}^{n} \bigl( \log(x_i-\underline{x}_i)+\log(\overline{x}_i-x_i) \bigr) + \sum_{j=1}^{m} y_j(g_j(x)-w_j) } \] The optimality conditions are obtained as a critical point of the Lagrangian. Hence the derivative of the optimality conditions is a symmetric matrix, being the Hessian of the Lagrangian, and is the matrix \[ \begin{pmatrix} -D & 0 & -I \\ 0 & -E + Y\cdot H & A^T \\ -I & A & 0 \end{pmatrix} \] where \[ \begin{gathered}D_{jj}=1/(w_j-\underline{w}_j)^2+1/(\overline{w}_j-w_j)^2, \\ E_{ii}=1/(x_i-\underline{x}_i)^2+1/(\overline{x}_i-x_i)^2, \\ Y_{jj}=y_j, \\ A_{ji} = \partial{g_j(x)}/\partial{x}_i, \\ H_{ji_1i_2} = \partial^2g_j(x)/\partial x_{i_1}\partial x_{i_2} . \end{gathered} \]

To solve the Newton step for \[ \begin{aligned} D \delta w + \delta y &= r_w; \\ (E-Y\cdot H) \delta x -A^T\delta y &= r_x; \\ \delta w - A\delta x &= r_y ;  \end{aligned}\] we find \[ A^TD \, \delta w + (E-Y\cdot H) \delta x = A^T r_w + r_x \] and hence \[ \begin{aligned} (A^TDA + E - Y\cdot H) \delta x &= A^T r_w + r_x - A^T D r_y \\ &= A^T(r_w-Dr_y)+r_x . \end{aligned} \] We therefore can solve the system as \[ \boxed{\begin{aligned} (A^TDA + E - Y\cdot H) \delta x &= A^T(r_w-Dr_y)+r_x \\ \delta w &= A \delta x + r_y \\ \delta y &= r_w - D \!\; \delta w . \end{aligned} } \]

Since a feasible solution $(w^*,x^*)$ must satisfy \[ \sum_{j=1}^{m} y_j^* (g_j(x^*)-w_j^*) = 0, \] a test of infeasibility is \[ y^* \cdot (g([x])-[w]) \not\ni 0 .\] This can be most accurately evaluated as \[ \boxed{ \displaystyle (y^* \cdot g)([x])- y^*\cdot [w] \not\ni 0 . } \] For this reason, we prefer a method which keeps the dual variables $y_j$, but not the variables $z_i$.

This yields the basis of an {\itshape infeasible interior point} method. We keep the constraints on $x$ and the inequality constraints on $w$ satisfied, and try to solve the constraints $g_j(x)-w_j = 0 $. The method can be applied with or without explicit use of the dual variables $y$ and $z$.\hypertarget{nonlinear_programming_page_gneral_nonlinear_feasibility_reformulation}{}\doxysubsubsection{\texorpdfstring{Reformulation of the nonlinear feasibility problem}{Reformulation of the nonlinear feasibility problem}}\label{nonlinear_programming_page_gneral_nonlinear_feasibility_reformulation}
We can multiply out the fractional terms to obtain     \[ \boxed{\begin{gathered}
       g_j(x) - w_j = 0. \\
       z_i - \sum_{j=1}^{m} y_j \nabla_{\!i\,} g_j(x) = 0 \\
       z_i(x_i-\underline{x}_i)(\overline{x}_i-x_i) - (\underline{x}_i+\overline{x}_i-2x_i) = 0 \\
       y_i(w_j-\underline{w}_j)(\overline{w}_j-w_j) - (\underline{w}_j+\overline{w}_j-2w_j) = 0 \end{gathered} } \]

We can separate out the lower and upper terms to obtain       \[ \boxed{\begin{gathered}
       g_j(x) - w_j = 0. \\
       (\underline{z}_i - \overline{z}_i) - \sum_{j=1}^{m} (\underline{y}_j - \overline{y}_j) \nabla_{\!i\,} g_j(x) = 0 \\
       \underline{z}_i(x_i-\underline{x}_i) = 0; \quad
       \overline{z}_i(\overline{x}_i-x_i) = 0 \\
       \underline{y}_j({w}_i-\underline{w}_i) = 0 ; \quad
       \overline{y}_j(\overline{w}_j-w_j) = 0 \end{gathered} } \]

\begin{DoxyRemark}{Remarks}
If there are no equality constraints, we can eliminate $y$ to yield \[ \frac{1}{x_i-\underline{x}_i} - \frac{1}{\overline{x}_i-x_i} - \sum_{j=1}^{m} \Biggl( \frac{1}{w_j-\underline{w}_j} - \frac{1}{\overline{w}_j-w_j} \Biggr) \, \nabla_{\!i\,} g_j(x) = 0; \qquad g_j(x)-w_j = 0 . \] We can further eliminate $w$ to yield \[ \displaystyle \frac{1}{x_i-\underline{x}_i} - \frac{1}{\overline{x}_i-x_i} - \sum_{j=1}^{m} \Biggl( \frac{1}{g_j(x)-\underline{w}_j} - \frac{1}{\overline{w}_j-g_j(x)} \Biggr) \, \nabla_{\!i\,} g_j(x) = 0  \] If there are equality constraints, which we write $h_k(x) = 0$, then \[ \frac{1}{x_i-\underline{x}_i} - \frac{1}{\overline{x}_i-x_i} - \sum_{j=1}^{m}  \Biggl( \frac{1}{g_j(x)-\underline{w}_j} - \frac{1}{\overline{w}_j-g_j(x)} \Biggr) \, \nabla_{\!i\,} g_j(x) + \sum_{k=1}^{l} y_k \, h_k(x) = 0 ; \qquad   h_k(x) = 0.  \] However, since our general case includes both inequality and equality constraints, it is more straightforward to use Lagrange multipliers for both kinds of constraint.
\end{DoxyRemark}
\hypertarget{nonlinear_programming_page_nonlinear_inequality_feasibility}{}\doxysubsubsection{\texorpdfstring{Inequality constrained feasibility problems}{Inequality constrained feasibility problems}}\label{nonlinear_programming_page_nonlinear_inequality_feasibility}
Consider the feasibility problem \[ g_j(x) \leq 0, \ j=1,\ldots,m; \ \ \underline{x}_i \leq x_i\leq  \overline{x}_i,\ i=1,\ldots,n. \] We can re-\/cast this as an optimisation problem by introducing an extra variable $t$ and taking \[ \max t \ \text{ s.t. } \ g_i({x})+t\leq 0,\ j=1,\ldots,n;\ \ \underline{x}_i \leq x_i\leq  \overline{x}_i,\ i=1,\ldots,n. \] The Karush-\/\+Kuhn-\/\+Tucker conditions for optimality with dual variables $y$ and slack variables $w$ are \[ \textstyle \sum_{i=1}^{m} y_i \nabla g_i({x}) = 0; \ \sum_{j=1}^{n} x_j =1; \ g_i({x}) + t + {w}_i = 0; \ {w}_iy_i=0;\ {w}_i,y_i\geq 0,\ i=1,\ldots,m \] The problem has no solution if there exists $y^*$ such that \[ y^*_i \cdot g_i([x]) > 0 . \]\hypertarget{nonlinear_programming_page_nonlinear_optimisation_newton}{}\doxysubsection{\texorpdfstring{Solving the Karush conditions by Newton-\/like methods}{Solving the Karush conditions by Newton-\/like methods}}\label{nonlinear_programming_page_nonlinear_optimisation_newton}
We now consider the general nonlinear programming problem \[ \max f(x) \mid \underline{x}_i \leq x_i \leq \overline{x}_i \wedge \underline{w} \leq g_j(x) \leq \overline{w}_j \] We assume a bounded domain with nonempty interior, so $-\infty < \underline{x}_i < \overline{x}_i \leq +\infty$, but allow for the other constraints to be equality constraints $\underline{w}_j=\overline{w}_j$ or unbounded $\underline{w}_j=-\infty$ or $\overline{w}_j=+\infty$. We set $w_j=g_j(x)$, so we can write $\underline{w} \leq w_j \leq \overline{w}_j$ and $g(x)-w=0$. However, we treat bounded, unbounded and equality constraints slightly differently.

We can write the relaxed Karush conditions in the following form \[ \begin{gathered} \nabla f(x) - \sum_{j=1}^{m} \lambda_j \nabla g(x) = 0\\ s_j(g_j(x),\lambda_j,\mu) = 0 \end{gathered} \] where $s_j(w_j,\lambda_j,\mu)$ depends on the bounds $\underline{w}_j,\overline{w}_j$. Setting $y_j=g_j(x)$, the Jacobian matrix for the Karush conditions is given by \[ \begin{pmatrix} \nabla^2 f + \sum_j \lambda_j \nabla^2 g_j & \nabla g ^T \\ \nabla_w s \nabla g & \nabla_\lambda s \end{pmatrix} \] Writing $H=\nabla^2 f + \sum_j \lambda_j \nabla^2 g_j$, $A=\nabla g$, $W_{jj} = \partial s_j/\partial \lambda_j$, and $\Lambda_{jj} = \partial s_j/\partial w_j $, we have the system \[ \begin{pmatrix} H & A^T \\ \Lambda A & W \end{pmatrix} \] Premultiplying by $\Lambda^{-1}$ and setting $D=\Lambda^{-1}W$ yields the form \[ \begin{pmatrix} H & A^T \\ A & D \end{pmatrix} \] which is symmetric since $H$ is symmetric and $D$ is diagonal. This system can be solved for $\Delta x$ by inverting the matrix $H-A D^{-1} A^T = H-AW^{-1}\Lambda A$. In particular, the matrix can be formed as long as $\partial s_j/\partial \lambda_j \neq 0$ for all $j$. This is indeed the case for all the examples we have considered.

In a primal-\/dual method, we introduce slack variables $s_i$ corresponding to each inequality constraint $g_i({x})\leq 0$ to form an equality constraint $g_i({x})+s_i=0$. However, these slack variables are temporaries, and are recomputed each step.

In a primal-\/dual-\/slack method, we instead update the slack variables using a Newton-\/like step \[ x\textnormal{\textquotesingle}=x-\alpha \Delta x; \quad s\textnormal{\textquotesingle}=s-\alpha\Delta s \] with \[ \nabla g_i({x}) \Delta x + \Delta s_i = g_i({x})+s_i . \] After the Newton-\/like step, the equality $g_i(x\textnormal{\textquotesingle}) + s_i\textnormal{\textquotesingle}$ does not hold, unless $g_i$ is affine, in which case $g_i(x\textnormal{\textquotesingle})+s\textnormal{\textquotesingle}=0$ up to roundoff error. We call methods in which the slack is stored and updated by a Newton-\/like step {\itshape primal-\/dual-\/slack} methods, to distinguish them from ordinary primal-\/dual methods.

In general, enforcing primal feasibility using a primal-\/dual-\/slack method may be harder than for an ordinary primal-\/dual method. In Ariadne, we are interested in solving feasibility problems where the constraints gradually tighten. This means that a feasable point can be used as in initial seed for iterating a tighter subproblem, and bound on the feasibly set of $y$ can be used in a tighter subproblem, and a certificate of infeasibility means that no further subproblems need to be considered.

A possible algorithm for solving feasibility problems is as follows\+:
\begin{DoxyItemize}
\item Use a non-\/rigorous iterative nonlinear programming solver (e.\+g. an interior point solver) to find $x_0,y_0$ giving a local solution to the related optimality problem.
\item If $y_0$ is feasible, repeat for the tighter subproblems, using computed $(x_0,y_0)$ as a seed for the iterative solver.
\item If $x_0\cdot g([y])>0$, the problem is infeasible.
\item Reduce $[y]$ using the constraint $x_0\cdot g([y])\leq 0$ and hull/box reduce, possibly using the expansion $x_0\cdot g([y]) = x_0\cdot g(y_0)+\nabla g([y])(y-y_0)$.
\item If $[y]$ is empty, the problem is infeasible.
\item Apply the Krawczyk contractor to the Karush-\/\+Kuhn-\/\+Tucker optimality conditions $  x\cdot \nabla g(y) = 0; \ \sum x_i =1; \ g(y) + t + z = 0; \ x_iz_i=0; \ x_i,z_i\geq 0,\ i=1,\ldots,n$.
\item Split domain in two and repeat. The splitting should be done to increase {\itshape linearity} of the $\nabla g$, since linear solvers are very effective. Note that we should repeat from the beginning in case the failure to prove disjointness was due to $(x_0,y_0)$ being a local maximum.
\item It may be worth contracting $[y]$ from time to time to improve the iteration speed.
\item The use of $x_0\cdot g([y])\leq 0$ rather than $g_i([y])\leq 0$ to perform the contraction is to focus attention on the possibly violated constraints.

\end{equation*} Note that the conditions are equivalent to minimising the Lagrangian   \begin{multline*} L({w},{x},{y},\,\unl{w},\ovl{w},\unl{x},\ovl{x},\,\unl{v},\ovl{v},\unl{z},\ovl{z}) = f({x}) + \sum_{i=1}^{m} {y}_i(g_i({x})- {w}_i) \\
     + \sum_{i=1}^{m} \bigl(  \unl{v}_i( {w}_i+\unl{w}_i-\unl{c}_i)\!-\!\mu\log\!|\unl{w}_i| \;+\; \ovl{v}_i( {w}_i+\ovl{w}_i-\ovl{c}_i)\!-\!\mu\log\!|\ovl{w}_i| \bigr) \\
     \qquad\qquad + \sum_{j=1}^{n} \bigl(  \unl{z}_j({x}_j+\unl{x}_j-\unl{d}_j)\!-\!\mu\log\!|\unl{x}_j| \;+\; \ovl{z}_j({x}_j+\ovl{x}_j-\ovl{d}_j)\!-\!\mu\log\!|\ovl{x}_j| \bigr) \,. \end{multline*}

The variables are updated using a Newton step \[ \mathbf{x}\textnormal{\textquotesingle} = \mathbf{x} - \alpha \, \mathbf{\delta x} \] where $0<\alpha\leq 1$ is such that $\unl{w}\textnormal{\textquotesingle},\unl{x}\textnormal{\textquotesingle},\unl{v}\textnormal{\textquotesingle},\unl{z}\textnormal{\textquotesingle} < 0$ and $\ovl{w}\textnormal{\textquotesingle},\ovl{x}\textnormal{\textquotesingle},\ovl{v}\textnormal{\textquotesingle},\ovl{z}\textnormal{\textquotesingle}>0$. To avoid approaching too close to the boundary, we require \[ \unl{w}_i\,\unl{v}_i > \mu \gamma, \quad \ovl{w}_i\,\ovl{v}_i > \mu \gamma, \quad \unl{x}_j\,\unl{z}_j > \mu \gamma, \quad \ovl{x}_j\,\ovl{z}_j > \mu \gamma, \] where $\gamma$ is a small constant, which we take to be $1/1024$.

The parameter $\mu$ is estimmated by \[  \mu = \frac{1}{2(m+n)} \biggl( \sum_{i=1}^{m}\bigl(\unl{v}_i\,\unl{w}_i+\ovl{v}_i\,\ovl{w}_i\bigr) + \sum_{j=1}^{n}\bigl(\unl{z}_j\,\unl{x}_j+\ovl{z}_j\,\ovl{x}_j\bigr) \biggr) . \] For the next step, we multiply $\mu$ by a constant $\sigma$, which we take to be $1/8$.
