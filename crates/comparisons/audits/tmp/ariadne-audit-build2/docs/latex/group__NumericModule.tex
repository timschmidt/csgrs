\doxysubsubsection{Numeric Module }
\hypertarget{group__NumericModule}{}\label{group__NumericModule}\index{Numeric Module@{Numeric Module}}


\doxysubsubsubsection{Description}
Numerical types, including \doxylink{classAriadne_1_1Natural}{Natural}, \doxylink{classAriadne_1_1Integer}{Integer}, \doxylink{classAriadne_1_1Dyadic}{Dyadic}, \doxylink{classAriadne_1_1Decimal}{Decimal}, \doxylink{classAriadne_1_1Rational}{Rational} and \doxylink{classAriadne_1_1Real}{Real} types, generic types \doxylink{classAriadne_1_1Number}{Number}, double/multiple precision floating-\/point types \doxylink{classAriadne_1_1Float_3_01DP_01_4}{Float$<$\+DP$>$} and \doxylink{classAriadne_1_1Float_3_01MP_01_4}{Float$<$\+MP$>$} (with shorthands \doxylink{namespaceAriadne_af915b9f1459c9691328efa71c6f39c6e}{Float\+DP} and \doxylink{namespaceAriadne_a07966b67e613cc8779412beecb60651d}{Float\+MP}), and correctly-\/rounded types \doxylink{classAriadne_1_1Ball}{Ball\texorpdfstring{$<$}{<}F,FE\texorpdfstring{$>$}{>}}, \doxylink{classAriadne_1_1Bounds}{Bounds\texorpdfstring{$<$}{<}F\texorpdfstring{$>$}{>}} \doxylink{classAriadne_1_1UpperBound}{Upper\+Bound\texorpdfstring{$<$}{<}F\texorpdfstring{$>$}{>}}, \doxylink{classAriadne_1_1LowerBound}{Lower\+Bound\texorpdfstring{$<$}{<}F\texorpdfstring{$>$}{>}} and \doxylink{classAriadne_1_1Approximation}{Approximation\texorpdfstring{$<$}{<}F\texorpdfstring{$>$}{>}}. 

{\itshape For the mathematical theory of computability on real numbers, see the \doxysectlink{real_numbers_page}{Computable Real Numbers}{0} Page.}

In this module, we define Ariadne\textquotesingle{}s base numerical types, including support for interval arithmetic via balls and bounds. The main concrete algebraic number types are \doxylink{classAriadne_1_1Integer}{Integer}, \doxylink{classAriadne_1_1Dyadic}{Dyadic}, and \doxylink{classAriadne_1_1Rational}{Rational}. A \doxylink{classAriadne_1_1Decimal}{Decimal} number class is provided for user input. The main real number type is \doxylink{classAriadne_1_1Real}{Real}, with directed versions \doxylink{classAriadne_1_1LowerReal}{Lower\+Real} and \doxylink{classAriadne_1_1UpperReal}{Upper\+Real}. Generic numbers are defined using the \doxylink{classAriadne_1_1Number}{Number} templates, with typedefs e.\+g. Effective\+Number for \doxylink{classAriadne_1_1Number}{Number}\texorpdfstring{$<$}{<}\doxylink{structAriadne_1_1EffectiveTag}{Effective\+Tag}\texorpdfstring{$>$}{>}. Validated and approximate versions of real numbers are given by \doxylink{classAriadne_1_1ValidatedReal}{Validated\+Real} and \doxylink{classAriadne_1_1ApproximateReal}{Approximate\+Real}, and convergent sequences without error bounds by \doxylink{classAriadne_1_1NaiveReal}{Naive\+Real}.

Concrete numerical types are defined in terms of the \doxylink{namespaceAriadne_af915b9f1459c9691328efa71c6f39c6e}{Float\+DP} and \doxylink{namespaceAriadne_a07966b67e613cc8779412beecb60651d}{Float\+MP} floating-\/point number classes. These support rounded arithmetic and elementary functions using the \doxylink{group__NumericModule_ga54a3e0b3f2deed7e8fb80c5211414f2e}{down} and \doxylink{group__NumericModule_gaf2afab3884f1860d5e0ba6f8004a132f}{up} tags (equivalantly, \doxylink{group__NumericModule_ga6e90b4c1e041590cd9713739bd662aab}{downward} and \doxylink{group__NumericModule_gaf5c792cfa75f61390a4d3e51efb223e5}{upward}). Rounding to nearest is specified by the \doxylink{group__NumericModule_ga0ae8cc613c31723d1122d0627a20152a}{near} (equivalently, \doxylink{group__NumericModule_ga8fe1087fba3fafcf0af365dfd7e4d7c9}{to\+\_\+nearest}) tag. Approximate arithmetic without control of the rounding mode can be specified by the \doxylink{group__NumericModule_ga95ba69cd782bab325c6b504b58ad7771}{approx} rounding type. Comparisons are performed considering these numbers as exact values, and must be decidable. This means that these "{}raw"{} floating-\/point types should not be used directly, but wrapped in one of the validated concrete approximation classes listed below.

Types supporting exact or rounded arithmetic may be used to define (validated) approximations to numbers via the classes Value\texorpdfstring{$<$}{<}F\texorpdfstring{$>$}{>}, \doxylink{classAriadne_1_1Ball}{Ball\texorpdfstring{$<$}{<}F,FE\texorpdfstring{$>$}{>}}, \doxylink{classAriadne_1_1Bounds}{Bounds\texorpdfstring{$<$}{<}F\texorpdfstring{$>$}{>}} \doxylink{classAriadne_1_1UpperBound}{Upper\+Bound\texorpdfstring{$<$}{<}F\texorpdfstring{$>$}{>}}, \doxylink{classAriadne_1_1LowerBound}{Lower\+Bound\texorpdfstring{$<$}{<}F\texorpdfstring{$>$}{>}} and \doxylink{classAriadne_1_1Approximation}{Approximation\texorpdfstring{$<$}{<}F\texorpdfstring{$>$}{>}}.

Note that to prevent accidental calls to approximate functions, all non-\/exact operations (except explicitly-\/rounded operations on raw values) must yield an \doxylink{classAriadne_1_1Approximation}{Approximation} value.

Positive numbers can be defined using the \doxylink{classAriadne_1_1Positive}{Positive\texorpdfstring{$<$}{<}X\texorpdfstring{$>$}{>}} template. A \doxylink{classAriadne_1_1Natural}{Natural} is a \doxylink{classAriadne_1_1Positive}{Positive}\texorpdfstring{$<$}{<}\doxylink{classAriadne_1_1Integer}{Integer}\texorpdfstring{$>$}{>}.

The following aliases are used for arithmetical operations\+: 
\begin{DoxyDescription}
\item[]\hfill \\
{\ttfamily nul(x)} is equivalent to {\ttfamily 0\texorpdfstring{$\ast$}{*}x} 
\item[]\hfill \\
{\ttfamily pos(x)} is equivalent to {\ttfamily +x} 
\item[]\hfill \\
{\ttfamily neg(x)} is equivalent to {\ttfamily -\/x} 
\item[]\hfill \\
{\ttfamily sqr(x)} is equivalent to {\ttfamily x\texorpdfstring{$^\wedge$}{\string^}2}, the {\itshape square} operation 
\item[]\hfill \\
{\ttfamily hlf(x)} is equivalent to {\ttfamily x/2} 
\item[]\hfill \\
{\ttfamily rec(x)} is equivalent to {\ttfamily 1/x}, the {\itshape reciprocal} operation. 
\item[]\hfill \\
{\ttfamily add(x,y)} is equivalent to {\ttfamily x+y} 
\item[]\hfill \\
{\ttfamily sub(x,y)} is equivalent to {\ttfamily x-\/y} 
\item[]\hfill \\
{\ttfamily mul(x,y)} is equivalent to {\ttfamily x\texorpdfstring{$\ast$}{*}y} 
\item[]\hfill \\
{\ttfamily div(x,y)} is equivalent to {\ttfamily x/y} 
\item[]\hfill \\
{\ttfamily pow(x,n)} is equivalent to {\ttfamily x\texorpdfstring{$^\wedge$}{\string^}n} 
\item[]\hfill \\
{\ttfamily fma(x,y,z)} is equivalent to {\ttfamily x\texorpdfstring{$\ast$}{*}y+z}, the {\itshape fused-\/multiply-\/and-\/add} operation. 
\end{DoxyDescription}Note that C++ does not support the power operator {\ttfamily \texorpdfstring{$^\wedge$}{\string^}}. In Python, the power operator is denoted {\ttfamily \texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}}. In Ariadne, only integer exponents {\itshape n} are supported; for general powers use the identity $x^y=e^{x\log(y)}$ and write {\ttfamily exp(y\texorpdfstring{$\ast$}{*}log(x))}.

The following non-\/arithmetical elementary functions are provided\+: 
\begin{DoxyDescription}
\item[]\hfill \\
{\ttfamily sqrt(x)}, the square-\/root function $\sqrt{x}$ 
\item[]\hfill \\
{\ttfamily exp(x)}, the natural exponent $e^x$ 
\item[]\hfill \\
{\ttfamily log(x)}, the natural logarithm $\log(x)$ (sometimes written $\ln(x)$). 
\item[]\hfill \\
{\ttfamily sin(x)}, the sine function $\sin(x)$, with argument in {\itshape radians}. 
\item[]\hfill \\
{\ttfamily cos(x)}, the cosine function $\cos(x)$, with argument in {\itshape radians}. 
\item[]\hfill \\
{\ttfamily tan(x)}, the tangent function $\tan(x)$, with argument in {\itshape radians}. 
\item[]\hfill \\
{\ttfamily atan(x)}, the inverse tangent function $\arctan(x)$ or $\tan^{-1}(x)$, returning princial value in the open interval $(-\pi/2\!:\!+\pi/2)$ 
\end{DoxyDescription}

The following lattice operations are provided\+: 
\begin{DoxyDescription}
\item[]\hfill \\
{\ttfamily abs(x)}, the absolute-\/value $|x|$ 
\item[]\hfill \\
{\ttfamily max(x,y)}, the maximum $\max(x,y)$ 
\item[]\hfill \\
{\ttfamily min(x,y)}, the minimum $\min(x,y)$ 
\end{DoxyDescription}
