\doxysubsubsection{Description}
Solver for feasibility problems based on a penalty-\/function approach. 

For the feasibility problem $x\in D,\ g(x)\in C,\ h(x)=0$ where $D$ is bounded and $D,C$ have nonempty interiors. Introduce slack variable $w=g(x)$, and minimise \[ \sum_{j} (g_j(x)-w_j)^2 + \sum_k h_k(x)^2 \] with $x\in D$ and $w\in C$. Since the minimiser is not unique, we need to add penalty terms $-\mu/2(\log(x_u-x)+log(x-x_l))$ and $-\nu/2(\log(w_u-w)+log(w-w_l))$. It suffices to add a penalty in $x$.
