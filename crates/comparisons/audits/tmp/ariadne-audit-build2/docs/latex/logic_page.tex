In standard logic, a proposition may either be {\itshape true} or {\itshape false}. The result is represented by an element of the {\itshape Boolean} type $\B$. For comparisons between integer or rational numbers, this is sufficient; given $q_1,q_2\in\Q$, represented as fractions, we can decide (i.\+e. compute) whether $q_1\leq q_2$ or not.

From the viewpoint of computation, however, Boolean logic is insufficient.

A classical example is the {\itshape halting problem}\+: is it possible to write a computer program which can inspect another program, and determine whether that program eventually terminates, or runs forever? It turns out that writing such a program is impossible! While some programs clearly terminate, and others clearly run forever, there are some whose behaviour is so complex that it is impossible to tell. This means that any (correct) program we write which aims to determine whether another program halts, will answer {\itshape true} or {\itshape false} for some inputs, but there must be other inputs for which our program either terminates with answer {\itshape dont\+\_\+know}, or runs forever without producing a definite answer. To represent the output of such a program, we introduce a third logical value {\itshape indeterminate} (this terminology was used by the Boost\+::\+Tribool library) representing either "{}don\textquotesingle{}t know"{} or "{}can\textquotesingle{}t know"{}.

Another example is comparing two real numbers\+: given $r_1,r_2\in\R$, is $r_1\leq r_2$? If all the information about $r_1,r_2$ we have access to are the streams of digits from the decimal expansions, then the comparison is not always possible. Suppose we find $r_1=3.141592\cdots$ and $r_2=3.141592\cdots$. Then we cannot tell, at this stage of the computation, which of $r_1$ and $r_2$ is larger, or even whether they are equal. On computing more digits, we could find $r_1=3.141592653\,589\cdots$ and $r_2=3.141592653\,921\cdots$, in which case $r_1<r_2$. But we could instead find $r_2=3.141592653\,589\cdots$, so would still be unable to tell. On computing yet more digits we might find $r_1=3.141592653589793\,238\cdots$ and $r_2=3.141592653589793\,160$ in which case we can tell $r_1>r_2$, but we might also find $r_2=3.141592653589793\,238\cdots$, and still not know the answer. Of course, if $r_1\neq r_2$, by computing enough digits, we will {\itshape eventually} be able to decide which of $r_1<r_2$ or $r_2>r_1$ is true, but if $r_1=r_2$, then no matter how many digits we compute, we will still never know which if $r_1 \lesseqgtr r_2$ holds. In this case again the computation would run forever, and we would consider the value {\itshape indeterminate}.

The resulting logic is {\itshape Kleenean} logic $\K=\{T,F,I\}$, with three values {\itshape true} $\top,\mathsc{T}$, {\itshape false} $\bot,\mathsc{F}$ and {\itshape indeterminate} $\uparrow,\mathsc{I}$. The Kleenean type represents the result of {\itshape quasidecidable} predicates.

A subtype of the Kleeneans is given by the {\itshape Sierpinskian} type $\S=\{\tru,\indt\}$ with open sets $\{\},\{\tru\},\{\tru,\indt\}$. The Sierpinsian type represents the result of {\itshape verifiable} predicates. The negation of a \doxylink{classAriadne_1_1Sierpinskian}{Sierpinskian} has values $\{\fls,\indt\}$.

{\itshape Remark on notation\+:} The symbol \textquotesingle{} $\bot$\textquotesingle{} or "{}bottom"{} denotes the lowest value in a lattice structure. For Boolean logic, this has a natural interpretation as {\itshape false}, but for three-\/valued logics, it can also be interpreted as "{}no information"{} i.\+e. {\itshape indeterminate}. The symbol \textquotesingle{} $\uparrow$\textquotesingle{} or "{}diverges"{} denotes a non-\/terminating computation, which is an error. For decidable logic, this is an error, but for quasidecidable logic, even though a computation may be infinite, {\itshape indeterminate} should be a valid logical value. Further, when computing a binary logical operator, an infinite computation can be terminated if the other value allows the operator to be short-\/circuited. For these reasons, \textquotesingle{} $\bot$\textquotesingle{} and \textquotesingle{} $\uparrow$\textquotesingle{} are not unambiguously clear notations for {\itshape false} and {\itshape indeterminate}. \textquotesingle{} $?$\textquotesingle{} could instead be used for {\itshape indeterminate}.\hypertarget{logic_page_logical_types}{}\doxysubsection{\texorpdfstring{Logical types}{Logical types}}\label{logic_page_logical_types}

The basic logical type used in (classical) mathematics and programming is the Boolean type $\mathbb{B}=\{T,F\}$. This type is suitable as the result of a decidable logical predicate. In continuous mathematics, most predicates are not decidable, since non-\/robust instances cannot be resolved. An example is the positivity check $x \geq 0$ for real numbers $x\in\mathbb{R}$; if $x$ is exactly equal to $0$, then (see the \doxysectlink{real_numbers_page}{Computable Real Numbers}{0} for more details).\hypertarget{logic_page_kleeneans}{}\doxysubsubsection{\texorpdfstring{The Kleeneans}{The Kleeneans}}\label{logic_page_kleeneans}
The Kleeneans take values $\K=\{\tru,\fls,\indt\}$. As a topological space, $\K$ has basic open sets $\{\tru\},\{\fls\}$, which generate the full topology of open sets $\{\},\{\tru\},\{\fls\},\{\tru,\fls\},\{\tru,\indt,\fls\}$. This means that for a predicate $\phi:\X\to\K$, both $\mathrm{sat}(\phi):=\{x\in\X\mid \phi(x)=\tru\}$ and $\{x\in\X\mid \phi(x)=\fls\}$ are open sets. This makes sense, since to verify $\phi(x)$ for $x$ given by increasingly accurate approximations means that $x$ must lie in the interior of $\mathrm{sat}(\phi)$. The set $\{x\in\X\mid \phi(x)=\indt\}$ is closed, and we can think of it as the {\itshape logical boundary} of $\mathrm{sat}(\phi)$. This may be different from the geometric boundary e.\+g. if $f(x)=\max(\min(x+1,0),x-1)$ and $\phi(x) \equiv \, f(x) \gtrsim 0$, then $\mathrm{sat}(\phi)=]1\!:\!\infty)$ with boundary $\{1\}$, but the logical boundary is $\{x\mid f(x)=0\}=[-1\!:\!+1]$.

The Kleenean data type can be represented in terms of the alphabet $\mathtt{T},\mathtt{F},\mathtt{I}$ by taking $\mathtt{I}^\omega \mapsto I$, $\mathtt{I}^*\mathtt{T}^\omega \mapsto T$ and $\mathtt{I}^*\mathtt{F}^\omega \mapsto F$. Alternatively, using binary, we can take $\mathtt{0}^\omega \mapsto I$, $\mathtt{0}^*\mathtt{11}^\omega \mapsto T$, and $\mathtt{0}^*\mathtt{10}^\omega \mapsto F$.

At any finite stage of a calculation computing a Kleenean value, we may {\itshape know} that the answer is {\itshape true} or {\itshape false}. Otherwise, the answer is {\itshape indeterminate}, which should now be interpreted as {\itshape unknown}, rather than {\itshape unknowable}. We define the {\itshape validated Kleenean} type to have three values, $\widehat{\K}=\{\tru,\unkn,\fls\}$ or $\{\top,?,\bot\}$. The validated Kleeneans can be interpreted as intervals of Booleans, with $\unkn=[\fls\!:\!\tru]$. They can also be interpreted as balls around Boolean values. Here we have a distinction between descriptions $\fls\pm1$ and $\tru\pm1$, which can be interpreted as indicating a "{}guess"{} as to whether the result is "{}likely"{} or "{}unlikely"{}.

A representation of $\K$ by sequences of validated Kleeneans is given by $\unkn^*\fls^\omega\mapsto\fls$, $\unkn^*\tru^\omega\mapsto\tru$ and $\unkn^\omega\mapsto\indt$. This is a partial function $\widehat{\K}^\omega \pfto \K$; we can extend this to a total function by allowing junk after the first occurrence of $\tru$ or $\fls$. A representation by binary digits can be given by $0^*10^\omega\mapsto\fls$, $0^*11^\omega\mapsto\tru$ and $0^\omega\mapsto\indt$. Here, the occurrence of the first \textquotesingle{} $1$\textquotesingle{} indicates that the result is known, and the digit immediately following indicates the answer. Again, we may weaken the representation to a total function by allowing $0^*10\cdots\mapsto\fls$, $0^*11\cdots\mapsto\tru$.\hypertarget{logic_page_sierpinskians}{}\doxysubsubsection{\texorpdfstring{The Sierpinskians}{The Sierpinskians}}\label{logic_page_sierpinskians}
The Sierpinskians take values $ \S=\{\tru,\indt\}$. As a topological space, $\S$ has basic open set $\{\tru\}$, which generates the full topology of open sets $\{\},\{\tru\},\{\tru,\indt\}$.

The Sierpinsian data type can be represented in terms of the alphabet $\mathtt{T},\mathtt{I}$ by taking $\mathtt{I}^\omega \mapsto I$, and $\mathtt{I}^*\tru^\omega \mapsto T$. Alternatively, using binary, we can take $\mathtt{0}^\omega \mapsto I$, $\mathtt{0}^*\mathtt{1}^\omega \mapsto T$. A complete representation is obtained if we allow $\mathtt{0}^*\mathtt{1} \{\mathtt{0},\mathtt{1}\}^\omega \mapsto T$.

It turns out that there are two possible interpretations of the Sierpinskian type. To see this, note that the Sierpinskians are a subtype of the Kleeneans, so have a natural inclusion $\mathbb{S}\hookrightarrow\mathbb{K}$. However, since the indeterminate value $I$ denotes an unknown (or unknowable) value, there is also a natural projection $\mathbb{K}\to\mathbb{S}$ given by $T \mapsto T$ and $F,I \, \mapsto I$. The composition is \textbackslash{}emph\{not\} the identity on $\mathbb{K}$, so loses information. The inclusion of $\mathbb{S}$ in $\mathbb{K}$ loses the information that the value is not $F$, whereas the projection of $\mathbb{K}$ onto $\mathbb{S}$ loses the information that the value is $F$. The "{}weak"{} interpretation of Sierpinskian is the result of a predicate for which we have not tested for falseness, only truth. This is useful when only a definitely true value is relevant, or when only partial information about the object is available. The "{}strong"{} interpretation of Sierpinskian is the result of a predicate which {\itshape cannot} be {\itshape robustly} false, such as the apartness (inequality) predicate on continous types. In Ariadne, the "{}weak"{} Sierpinskians are called upper-\/\+Kleeneans, and are not equivalent to Sierpinskians, even though they take the same values.

There is also a computable mapping of $K$ to $\{\tru,\indt\}$ given by $\tru\mapsto\tru$ and $\indt,\fls\mapsto\indt$. However, composing these maps does not give the identity on $\K$, since $\fls\mapsto\indt$ i.\+e. the fact that a proposition is definitely {\itshape false} is "{}forgotten"{}. For this reason we distinguish the Sierpinskians from the {\itshape lower-\/Kleeneans} $\K_<$, which has the same values $\K_<=\{\tru,\indt\}$ and topology, but for which the mapping $\K_<\to\K$ taking $\fls\mapsto\indt$ is treated as a conversion. Intuitively, the distiction between $\S$ and $\K_<$ is that a predicate returning value in $\S$ can never be verifiably false (such as the apartness predicate $\neq$), while a value in $\K_<$ indicates that information regarding falseness has been discarded. One may also think of $\S$ as "{}positive"{} Kleeneans $\K^+$.\hypertarget{logic_page_logical_operations}{}\doxysubsection{\texorpdfstring{Logical Operations}{Logical Operations}}\label{logic_page_logical_operations}

In classical mathematics, orderings are typically determined by the less-\/then-\/or-\/equal predicate $\leq$, and may be {\itshape partial}, satisfying axioms of
\begin{DoxyItemize}
\item Reflexivity\+: $x \leq x$
\item Antisymmetry\+: $x \leq y \wedge y \leq x \Rightarrow x=y $
\item Transitivity\+: $x \leq y \wedge y \leq z \Rightarrow x \leq z$
\end{DoxyItemize}

or {\itshape total}, additionally satisfying
\begin{DoxyItemize}
\item Totality\+: $ x\leq y \vee y \leq x $.
\end{DoxyItemize}

In computable mathematics, we additionally distinguish {\itshape decidable}, {\itshape quasidecidable} and {\itshape semideciable} orderings, returning Boolean, Kleenean or (weak) Sierpinskian values, respectively.

In a decidable total order, the standard operators $=,\neq,\leq,\geq,<,>$ (in C++, denoted respectively by {\ttfamily ==}, {\ttfamily !=}, {\ttfamily \texorpdfstring{$<$}{<}=}, {\ttfamily \texorpdfstring{$>$}{>}=}, {\ttfamily \texorpdfstring{$<$}{<}}, {\ttfamily \texorpdfstring{$>$}{>}}) take Boolean values, and satisfy the standard relations, namely \[ \begin{aligned} x=y &\iff x\leq y \wedge y \leq x, \\ x\neq y &\iff \neg (x=y),\\ x\geq y &\iff y\leq x, \\ x<y &\iff x\leq y \wedge x\neq y \iff x \leq y \wedge \neg(x\geq y),\\ x>y &\iff y<x . \end{aligned}\] Further, in a field, we can define $x\leq y$ in terms of the positivity predicate $(y-x) \geq 0$

In a decidable partial order, we can similarly define $x\geq y\iff y\leq x$ and $x=y \iff x\leq y \wedge y\leq x$. We shall postpone the discussion of the meaning of $x<y$.
