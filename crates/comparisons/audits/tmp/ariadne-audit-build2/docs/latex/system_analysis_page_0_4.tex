\doxysection{Analysing a Dynamic System (version 0.\+4) }
\hypertarget{system_analysis_page_0_4}{}\label{system_analysis_page_0_4}\index{Analysing a Dynamic System (version 0.4)@{Analysing a Dynamic System (version 0.4)}}
Analysis of dynamic systems in Ariadne is performed via {\itshape evaluator} classes, which perform certain tasks. Ariadne currently supports three kinds of evaluators\+:
\begin{DoxyItemize}
\item \doxylink{classAriadne_1_1EvolverInterface}{Evolver} Compute time evolution.
\item \doxylink{classAriadne_1_1PaverInterface}{Paver} Discreteise sets and orbits on a grid.
\item \doxylink{classAriadne_1_1ReachabilityAnalyserInterface}{Reachability\+Analyser} Compute finite-\/ and infinite-\/time reachable sets on a grid.
\end{DoxyItemize}

System evolution is performed starting from an initial point or set of points. There are a number of ways of defining initial sets in Ariadne, but the most general is using the \doxylink{classAriadne_1_1ImageSet}{Image\+Set} class. Commonly used sets are provided for convenience, such as \doxylink{classAriadne_1_1Box}{Box} and \doxylink{classAriadne_1_1Polytope}{Polytope} classes. For analysing hybrid systems, a \doxylink{classAriadne_1_1HybridEnclosure}{Hybrid\+Enclosure} class is also provided.

Safety specifications are also defined by means of sets. The \doxylink{classAriadne_1_1ConstraintSet}{Constraint\+Set} class is the most general way of given a specification, but the \doxylink{classAriadne_1_1Box}{Box} and \doxylink{classAriadne_1_1Polyhedron}{Polyhedron} classes can also be used. For hybrid systems, a \doxylink{classAriadne_1_1HybridEnclosure}{Hybrid\+Enclosure} is also provided.\hypertarget{system_analysis_page_0_4_system_analysis_evolution}{}\doxysubsection{\texorpdfstring{Evolution of systems}{Evolution of systems}}\label{system_analysis_page_0_4_system_analysis_evolution}

\begin{DoxyItemize}
