Indicate that a floating-\/point literal is the exact value of a number in double-\/precision. 

The input {\itshape lx} is converted first converted to a double-\/precision value {\itshape x}. If {\itshape lx} and {\itshape x} differ, then the decimal literal input to {\itshape lx} almost certainly does not represent a double-\/precision number exactly, and an assertion fails. 

For example, {\ttfamily 0.\+625\+\_\+x} yields the exact double-\/precision value $5/2^3$, but {\ttfamily 0.\+6\+\_\+x} fails, since $3/5$ is not exactly representable as a double-\/precision number. \Hypertarget{classAriadne_1_1ExactDouble_abd313746e70a0e828a8a9d12483ada8d}\index{ExactDouble@{ExactDouble}!operator"{}"{}\_pr@{operator""""\_pr}}
