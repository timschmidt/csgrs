\doxysubsubsection{Description}
A dyadic number of the form $p/2^q$ for integers $p$, $q$; equivalently, a number with a finite binary expansion. 

\begin{DoxySeeAlso}{See also}
\doxylink{classAriadne_1_1Integer}{Integer}, \doxylink{classAriadne_1_1Decimal}{Decimal}, \doxylink{classAriadne_1_1Rational}{Rational}, \doxylink{classAriadne_1_1Float_3_01DP_01_4}{Float$<$\+DP$>$}, \doxylink{classAriadne_1_1Float_3_01MP_01_4}{Float$<$\+MP$>$}
\end{DoxySeeAlso}
The number $1.375$ is an example of a dyadic number, since it is equal to $1.375=11/8=11/2^3=1.101_2$. The number $0.1375$ is not a dyadic number, since $0.1375=11/80=11/(2^4\times 5)=0.0010\overline{0011}_2$, so the denominator is not a power of $2$, and its binary expansion is recurring. \doxysubsubsubsection*{Public Member Functions}
