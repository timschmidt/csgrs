In this tutorial, we\textquotesingle{}ll look at the analysis of a simple neural network with a single hidden layer. We will use two input variables, three hidden nodes, and a single output variable, and take a sigmoid activation function.

Before starting, let\textquotesingle{}s take a look at the documentation for the C++ \doxylink{classAriadne_1_1Function}{Function\texorpdfstring{$<$}{<}P,SIG\texorpdfstring{$>$}{>}} class. The class has two template parameters, the {\itshape information} or {\itshape computational paradigm} parameter {\ttfamily P}, which was explained in the \doxylink{group__InformationSubModule}{Information}, and a {\itshape signature} parameter {\ttfamily SIG}, which is explained in \doxysectlink{group__FunctionModule_function_signature_section}{Function signatures}{2}.

Hence the C++ template instantiation \doxylink{classAriadne_1_1Function}{Function\texorpdfstring{$<$}{<}Effective\+Tag,Real\+Vector(Real)\texorpdfstring{$>$}{>}} has Python name \doxylink{classAriadne_1_1Function_a52deafdf4bacb66638681a3c34475c95}{Effective\+Vector\+Univariate\+Function}. This name is also a C++ type alias, so can also be used in C++ code.\hypertarget{python_neural_network_page_python_symbolic_function_tutorial}{}\doxysubsubsection{\texorpdfstring{Symbolic Functions}{Symbolic Functions}}\label{python_neural_network_page_python_symbolic_function_tutorial}
We first create the activation function $\sigma(y)=1/(1+e^{-y})$. Since the function has a single argument, and returns a single result, it is a \doxylink{group__FunctionModule_ga4a215a0a287e522d9422c606425448ec}{Scalar\+Univariate\+Function}. Since it is exactly specified and can be evaluated arbitrarily accurately, it is {\ttfamily \doxylink{classAriadne_1_1Concepts_1_1Effective}{Effective}}. Hence the Python class name is \doxylink{classAriadne_1_1Function_a91c3811cfb016061f1d24582b89bede1}{Effective\+Scalar\+Univariate\+Function}. (The C++ template class is \doxylink{classAriadne_1_1Function}{Function\texorpdfstring{$<$}{<}Effective\+Tag,Real(Real)\texorpdfstring{$>$}{>}}.)

The main way of working with functions is to convert to a polynomial approximation. The domain of the approximation must be a bounded set, which we take to be an \doxylink{classAriadne_1_1Interval}{Interval} in the case of {\ttfamily Univariate} functions, and a coordinate-\/aligned \doxylink{classAriadne_1_1Box}{Box} in the case of {\ttfamily Multivariate} functions.


\begin{DoxyCodeInclude}{0}
\DoxyCodeLine{00060\ \ \ \ \ dom=BoxDomainType([[dy\_(0.375),dy\_(0.5)],[dy\_(0.625),dy\_(0.75)]])}

\end{DoxyCodeInclude}
Note that the non-\/integer numbers must be prefixed with the modifier \doxylink{classAriadne_1_1Dyadic_a41ef5fd5ef08cda400230737c4afa334}{dy\+\_\+}, which indicates that the written values should be interpreted exactly as {\itshape dyadic} numbers, which have an finite {\itshape binary} expansion; equivalently can be written as $p/2^q$ for integers $p$, $q$; see the \doxylink{classAriadne_1_1Dyadic}{Dyadic} class for more details. It is an error to use a non-\/dyadic number. \begin{DoxyNote}{Note}
The requirement that the bounds of the domain type must be exact dyadic numbers may be dropped in a future release of Ariadne.
\end{DoxyNote}
To control the accuracy of the approximation, we use a \doxylink{classAriadne_1_1Sweeper}{Sweeper} class. A general-\/purpose sweeper is the {\itshape threshold sweeper} \doxylink{classAriadne_1_1ThresholdSweeper}{Threshold\+Sweeper}, which discards terms of the polynomial if they fall below a certain threshold.

We can then approximate the model function {\itshape f} over {\itshape dom}. We use a {\ttfamily Taylor\+Function\+Model} class, where {\ttfamily SIG} is the signature, which must match that of the function itsef, and {\ttfamily PR} is the precision of the floating-\/point type used in the approximation. Here we need a {\ttfamily Scalar\+Multivariate} function, and use double precision, abbreviated {\ttfamily \doxylink{namespaceAriadne_a20c85a0dd881b12bf7ca596b4f5fa815}{DP}}, and want a {\ttfamily Validated} approximation with known error bound, so the class name to use is \doxylink{group__FunctionModelSubModule_ga05c1c7011f989b1ec0ba7f5d4e81580f}{Validated\+Scalar\+Multivariate\+Taylor\+Function\+Model\+DP}.
