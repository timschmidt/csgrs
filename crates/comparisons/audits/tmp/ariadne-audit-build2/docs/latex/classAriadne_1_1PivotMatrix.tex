\doxysubsubsection{Description}
Permutation matrices defined as a sequence of transpositions. 

Pre-\/multiplying a matrix $A$ by the pivot matrix with pivots $[p_0,p_1,\ldots,p_{n-1}]$ first swaps row $0$ of $A$ with row $p_0$, then row $1$ of the new matrix with row $p_1\geq1$ of the new matrix, continuing until the final row. This allows all row permutations to be realised.
