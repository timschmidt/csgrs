Automatic differentiation (AD) is an approach to computing derivatives which (using exact arithmetic) yields the exact values from symbolic formulae and iterative/recursive programming constructs, without the need to construct explicit symbolic formulae for the derivatives.

Consider quantities $u$, $v$, $y$ which depend on independent quantities $x_1,\ldots,x_n$. If we know the values of $u$ and $v$, and their partial derivatives with respect to the $x_i$, and if $y=u\times v$, then we can compute the value of $y$ and its partial derivatives\+: \[ \begin{gathered} y=u\times v, \qquad \frac{\partial{y}}{\partial{x_i}} = \frac{\partial{u}}{\partial{x_i}} \times  v + u \times \frac{\partial{v}}{\partial{x_i}} \\ \frac{\partial^2{y}}{\partial{x_i}\partial{x_j}} = \frac{\partial{u}}{\partial{x_i}\partial{x_j}} \times v + \frac{\partial{u}}{\partial{x_i}}\times\frac{\partial{v}}{\partial{x_j}} + \frac{\partial{u}}{\partial{x_j}}\times\frac{\partial{v}}{\partial{x_i}} + u \times \frac{\partial^2{v}}{\partial{x_i}\partial{x_j}}  \end{gathered} \] More generally, for a multi-\/index $\alpha=(\alpha_1,\alpha_n,\ldots,\alpha_n)\in\N^n$ with $|\alpha|=\sum_{i=1}^{n}\alpha_i$, we define $\alpha! = \prod_{i=1}^{n}\alpha_i!$ and the notation \[ \frac{\partial^{|\alpha|}{y}}{\partial{x}^\alpha} = \frac{\partial^{|\alpha|}{y}}{\partial{x_1^{\alpha_1}}\partial{x_2^{\alpha_2}}\cdots\partial{x_n^{\alpha_n}}} . \] Then we can write \[ \frac{\partial^{|\alpha|}{(u\times v)}}{\partial{x}^\alpha} = \sum_{\beta+\gamma=\alpha} \frac{\alpha!}{\beta!\,\gamma!} \frac{\partial^{|\beta|}{u}}{\partial{x}^{\beta}} \times \frac{\partial^{|\gamma|}v}{\partial{x}^{\gamma}} . \] The formulae for addition and subtraction are straightforward\+: \[ \frac{\partial^{|\alpha|}{(u+v)}}{\partial{x}^\alpha} = \frac{\partial^{|\alpha|}{u}}{\partial{x}^\alpha} + \frac{\partial^{|\alpha|}{v}}{\partial{x}^\alpha}; \qquad \frac{\partial^{|\alpha|}{(u-v)}}{\partial{x}^\alpha} = \frac{\partial^{|\alpha|}{u}}{\partial{x}^\alpha} - \frac{\partial^{|\alpha|}{v}}{\partial{x}^\alpha} . \] The formula for division is more complicated. Further, efficient computations of the partial derivatives of $y=u\div v$\+: \[ \frac{\partial^{|\alpha|}{(u\div v)}}{\partial{x}^\alpha} = \biggl( \frac{\partial^{|\alpha|}{u}}{\partial{x}^\alpha}-\sum_{\beta+\gamma=\alpha\\\ \ \ \gamma\neq\alpha} \frac{\alpha!}{\beta!\,\gamma!} \frac{\partial^{|\beta|}{v}}{\partial{x}^{\beta}} \times \frac{\partial^{|\gamma|}y}{\partial{x}^{\gamma}}\biggr)\div v . \] If $y=f(u)$ for some smooth function $f:\R\to\R$, then \[ y=f(u); \qquad \frac{\partial{y}}{\partial{x_i}} = f\textnormal{\textquotesingle}(u) \frac{\partial{u}}{\partial{x_i}} ; \qquad \frac{\partial^2{y}}{\partial{x_i}\partial{x_j}} = f\textnormal{\textquotesingle}\textnormal{\textquotesingle}(u) \frac{\partial{u}}{\partial{x_i}}\frac{\partial{u}}{\partial{x_j}} + f\textnormal{\textquotesingle}(u) \frac{\partial^2{u}}{\partial{x_i}\partial{x_j}} . \] A general formula for higher-\/order derivatives is\+: \[ \frac{\partial^{|\alpha|}{f(u)}}{\partial{x}^\alpha} = \sum_{\beta+\gamma=\alpha\\\ \ \ \beta\neq0} \frac{\alpha!}{\beta!\,\gamma!} \frac{\partial^{|\beta|}{u}}{\partial{x}^\beta} \frac{\partial^{|\gamma|}f\textnormal{\textquotesingle}(u)}{\partial{x}^\gamma} .  \] This can be efficiently computed recursively. A similar approach works for functions $f:\R^n\to\R$. An explicit form is {\itshape Faà di Bruno\textquotesingle{}s formula}.

Automatic differentiation is especially useful in programming languages support for polymorphism, since the same code used for evaluating the function can be applied to a data type storing the value of $y$ and its partial derivatives.\hypertarget{differential_algebra_page_differential_algebra}{}\doxysubsection{\texorpdfstring{Differential Algebra}{Differential Algebra}}\label{differential_algebra_page_differential_algebra}
A {\itshape differential algebra} is an associative algebra $\A$ over a field $\X$, together with a collection of {\itshape derivative} operators $\partial_i$ satisfying the {\itshape Leibnitz rule} \[  \partial (a_1 \times a_2) = (\partial a_1) \times a_2 + a_1 \times (\partial a_2) \] and the commutation rule \[  \partial_i (\partial_j a) = \partial_j (\partial i a)  . \]

The canonical example of a differential algebra is the algebra of smooth functions $f:\R^n\to\R$, with the operator $\partial_i$ being the $i^\text{th}$ partial derivative $\partial_i{f}(x) = \partial{f(x)}/\partial{x_i}$.

Differential algebras provide a natural abstraction for defining the operations of automatic differentiation.
