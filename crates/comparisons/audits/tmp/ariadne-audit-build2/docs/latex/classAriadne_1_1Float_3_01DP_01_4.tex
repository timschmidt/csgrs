\doxysubsubsection{Description}
Floating point numbers (double precision) using rounded arithmetic. Abbreviation Flobber\+::Float\+DP. 

The {\ttfamily Float\+DP} class represents floating-\/point numbers. Unless otherwise mentioned, operations on floating-\/point numbers are performed approximately, with no guarantees on the output.

To implement {\itshape rounded arithmetic}, arithmetical operations of {\ttfamily Float\+DP} can be performed with guaranteed rounding by specifying {\ttfamily \+\_\+up} and {\ttfamily \+\_\+down} suffixes to arithmetical functions {\ttfamily add}, {\ttfamily sub}, {\ttfamily mul} and {\ttfamily div}. Additionally, operations can be performed in the current {\itshape rounding mode} by using the {\ttfamily \+\_\+rnd} suffix, or with rounding reversed using the {\ttfamily \+\_\+opp} suffix. The {\ttfamily \+\_\+approx} suffix is provided to specifically indicate that the operation is computed approximately.

Ariadne floating-\/point numbers can be constructed by conversion from built-\/in C++ types. Note that the value of a built-\/in floating-\/point value may differ from the mathematical value of the literal. For example, while {\ttfamily Float\+DP(3.\+25)} is represented exactly, {\ttfamily Float\+DP(3.\+3)} has a value of $3.2999999999999998224\ldots$. \begin{DoxyNote}{Note}
In the future, the construction of a {\ttfamily Float\+DP} from a string literal may be supported. 
\end{DoxyNote}
