\doxysection{Tutorial on Analysing Hybrid Systems }
\hypertarget{hybrid_evolution_tutorial_page}{}\label{hybrid_evolution_tutorial_page}\index{Tutorial on Analysing Hybrid Systems@{Tutorial on Analysing Hybrid Systems}}
In this tutorial, we show how to use Ariadne to model and analyse a hybrid automaton model of a simple water-\/tank system.\hypertarget{hybrid_evolution_tutorial_page_tutorial_system_model}{}\doxysubsection{\texorpdfstring{The Hybrid Automaton Model}{The Hybrid Automaton Model}}\label{hybrid_evolution_tutorial_page_tutorial_system_model}
The system represents a system used to control the height of water in a tank with inflow and outflow. The outflow of the tank is given by Toricelli\textquotesingle{}s law and is proportional to the height\+: \[ \dot{h}=\beta v-\alpha h \] The inflow is governed by a valve, which takes a certain amout of time to fully open or close. The opening and closing of the valve is regulated by a controller, which opens or closes the valve as the water level goes beyond lower and upper threshold values.\hypertarget{hybrid_evolution_tutorial_page_tutorial_building_system}{}\doxysubsection{\texorpdfstring{Building the Ariadne Hybrid Automaton}{Building the Ariadne Hybrid Automaton}}\label{hybrid_evolution_tutorial_page_tutorial_building_system}
The tank has a single mode, a single state variable {\ttfamily height}, and two constants {\ttfamily alpha} and {\ttfamily beta}, and an external input variable, the valve {\ttfamily aperture}.
