Computations in Ariadne are usually most efficiently performed using floating-\/point number types. Ariadne internally supports the \doxylink{namespaceAriadne_af915b9f1459c9691328efa71c6f39c6e}{Float\+DP} and \doxylink{namespaceAriadne_a07966b67e613cc8779412beecb60651d}{Float\+MP} types, which are respectively based on builtin IEEE double-\/precision floating-\/point numbers, and multiple-\/precision floating-\/point numbers from the MPFR library.

Since Python\textquotesingle{}s builtin {\ttfamily float} class uses rounded arithmetic, such numbers may not be an exact representation of a value, leading to unsafe computation. If a Python {\ttfamily float} is indeed an exact value, (e.\+g. 1.\+375 is an exact double-\/precision floating-\/point number), this must first be converted to an Ariadne \doxylink{classAriadne_1_1ExactDouble}{Exact\+Double} class\+: 
\begin{DoxyCodeInclude}{0}
\DoxyCodeLine{00079\ \ \ \ \ d=ExactDouble(1.375)}
\DoxyCodeLine{00083\ \ \ \ \ d=cast\_exact(1.375)}

\end{DoxyCodeInclude}
Numbers which are not exactly representable in double-\/precision should be converted to the \doxylink{classAriadne_1_1Decimal}{Decimal} class instead.

Ariadne uses C++/\+Python\textquotesingle{}s built-\/in floating-\/point types to provide a double-\/precision floating-\/point number class \doxylink{namespaceAriadne_af915b9f1459c9691328efa71c6f39c6e}{Float\+DP}, and the MPFR library to provide a multiple-\/precision floating-\/point type \doxylink{namespaceAriadne_a07966b67e613cc8779412beecb60651d}{Float\+MP}. Each type has a corresponding precision\+: 
\begin{DoxyCodeInclude}{0}

\DoxyCodeLine{00102\ \ \ \ \ mp=MultiplePrecision(128)}

\end{DoxyCodeInclude}
