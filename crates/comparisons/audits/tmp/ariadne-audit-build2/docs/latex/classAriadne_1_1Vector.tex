class Ariadne\+::\+Vector$<$ X $>$}
Vectors over some type {\itshape X}. Corresponds to elements of a {\itshape module} over a mathematical {\itshape ring}, or a {\itshape vector space} over a field. May also be used if {\itshape X} is an {\itshape algebra} {\itshape A} over another field. It must be possible to add and multiply any two elements of the vector. \begin{Desc}
