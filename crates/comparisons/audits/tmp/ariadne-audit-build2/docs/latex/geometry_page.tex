\hypertarget{geometry_page}{}\label{geometry_page}\index{Geometric Representation@{Geometric Representation}}
This page describes the theory of computable Euclidean geometry. For details on how this is implemented in Ariadne, see the \doxylink{group__GeometryModule}{Geometry Module} documentation.\hypertarget{geometry_page_Introduction}{}\doxysubsection{\texorpdfstring{Introduction}{Introduction}}\label{geometry_page_Introduction}
One of the main concerns of Ariadne is the computation of points and sets in Euclidean space. Unfortunately, the set of points in Euclidean space is uncountable (it has continuum cardinality) and so there is no way of modelling all points in Euclidean space using binary words. The set of subsets of Euclidean space is also uncountable, and has an even greater cardinality!

To represent an uncountable set, we can use approximations. We take a set of elements which we model exactly, such as {\itshape Float} or {\itshape Rational} reals, which we call {\itshape denotable} elements. This denotable set may be finite or countably infinite, the former being denoted by words of a fixed length, and the latter by arbitrary length words. An {\itshape approximation} to an element is then a pair consisting of a denotable element and an {\itshape error}. Ideally, we wish to be able to approximate to arbitrary precision; this means that the set of denotable elements must be {\itshape dense} in the set of all elements. We can then represent arbitrary elements be a {\itshape convergent sequence} of approximations. In terms of a concrete representation on a computer, we can think of a such a sequence as a neverending {\itshape stream} of data.

The material in this section is heavily influenced by the book "{}\+Computational Analysis"{} by Klaus Weihrauch.\hypertarget{geometry_page_state}{}\doxysubsection{\texorpdfstring{Standard representation of locally-\/compact second-\/countable Hausdorff spaces}{Standard representation of locally-\/compact second-\/countable Hausdorff spaces}}\label{geometry_page_state}
Let $\beta=\{I_1,I_2,\ldots\}$ be a countable base of pre-\/compact sets for a locally-\/compact second-\/countable Hausdorff space $X$. A typical example is Euclidean space $\mathbb{R}^n$ with the base of open rational cuboids. We call the elements $I$ of $\beta$ {\itshape basic open sets} and their closures $\overline{I}$ {\itshape basic compact sets}. A {\itshape denotable set} is the finite union of basic sets, $A=\bigcup_{j=1}^{k} I_j$ or $A=\bigcup_{j=1}^{k} \overline{I}_j$.

A {\itshape representation} of an object is a sequence of basic sets which specifies the object exactly.


\begin{DoxyItemize}
\item The standard representation $\rho$ of a point $x\in X$ or singleton set $\{x\}\subset X$ encodes all basic open sets $I\in\beta$ such that $x\in I$.
\end{DoxyItemize}

The standard representation of a point is equivalent to giving a monotone sequence of convergent approximations $(I_1,I_2,\ldots)$ to $x$ satisfying $\overline{I}_{j}\subset I_{j+1}^\circ$ for all $j$ and $\{x\}=\bigcap_{j=0}^{\infty} I_j$.


\begin{DoxyItemize}
\item The standard lower representation $\theta_<$ of an open set $U\in\mathcal{O}(X)$ encodes all basic open sets $I\in\beta$ such that $\overline{I}\subset U$.
\item The standard lower representation $\psi_<$ of a closed set $B\in\mathcal{A}(X)$ encodes all basic open sets $I\in\beta$ such that $B\cap I\neq\emptyset$.
\item The standard upper representation $\psi_>$ of a closed set $B\in\mathcal{A}(X)$ encodes all basic open sets $I\in\beta$ such that $B\cap \overline{I}=\emptyset$.
\item The standard upper representation $\kappa_>$ of a compact set $C\in\mathcal{K}(X)$ encodes all basic open covers $(I_1,\ldots,I_k)\in\beta^*$ such that $C\subset\bigcup_{j=1}^{k}I_j$.
\end{DoxyItemize}

The standard representations $\theta_<$, $\psi_<$ and $\kappa_>$ correspond to the following {\itshape approximation concepts} by a sequence of denotable sets $A_n\rightarrow S$, where we have\+:
\begin{DoxyItemize}
\item inner-\/approximation $A_{i}\subset A_{i+1}$ and $A_n\subset U$ is equivalent to $\theta_<$ for $U\in\mathcal{O}(X)$.
\item lower-\/approximation $A_{i}\subset N_{\epsilon_i}(A_{j})$ for $i<j$ and $A_n\subset N_{\epsilon_n}(B)$ is equivalent to $\psi_<$ for $B\in\mathcal{A}(X)$.
\item outer-\/approximation $A_{i+1}\subset A_{i}$ and $C\subset A_n^\circ$ is equivalent to $\kappa_>$ for $C\in\mathcal{K}(X)$.
\end{DoxyItemize}

Combining lower-\/approximation and outer-\/approximation, we obtain an approximation corresponding to the standard representation $\kappa=\psi_<\vee\kappa_>$ of compact sets\+:
\begin{DoxyItemize}
\item effective-\/approximation $C\subset A^\circ_{n} \subset A_{n} \subset N_{\epsilon_n}(C)$ for $C\in\mathcal{K}(X)$.
\end{DoxyItemize}\hypertarget{geometry_page_basicset}{}\doxysubsection{\texorpdfstring{Basic sets.}{Basic sets.}}\label{geometry_page_basicset}

There are a number of ways a set $S$ can be approximated by a set $A$\+:
\begin{DoxyItemize}
\item lower\+\_\+approximation()\+: $A\subset N_\epsilon(S)$
\item under\+\_\+approximation()\+: $A\subset S$
\item inner\+\_\+approximation()\+: $\overline{A}\subset S^\circ$
\item upper\+\_\+approximation()\+: ${\left(N_\epsilon(S^C)\right)}^C \subset A$
\item over\+\_\+approximation()\+: $S\subset A$
\item outer\+\_\+approximation()\+: $\overline{S}\subset A^\circ$
\end{DoxyItemize}

The approximations lower/upper, under/over and inner/outer are dual to each other. The lower/upper approximation concepts are the weakest, and inner/outer the strongest.

The inner approximation is most natural for open sets, and the lower approximation is most natural for (unbounded) closed sets. For compact sets, both lower and outer approximations are natural.

A set $S$ is {\itshape regular} if $S^\circ=\overline{S}^\circ$ and $\overline{S}=\overline{S^\circ}$. Both inner and under approximations are natural for regular sets, since a regular set can be considered as both open and closed.

The over and under approximations are typically used for converting "{}fuzzy"{} sets (with interval data) to sets with floating-\/point data. For example, the over-\/approximation of the fuzzy rectangle $[\overline{\underline{a}}_1,\overline{\underline{b}}_1]\times[\overline{\underline{a}}_2,\overline{\underline{b}}_2]$ is the rectangle $[\underline{a}_1,\overline{b}_1]\times[\underline{a}_2,\overline{b}_2]$, and the under-\/approximation is $[\overline{a}_1,\underline{b}_1]\times[\overline{a}_2,\underline{b}_2]$.

The error specification depends on the type of approximation used.
\begin{DoxyItemize}
\item When approximating by a Grid\+Set, the error is determined by the grid.
\item When approximating by a Partition\+Tree\+Set, the error is determined by the partition scheme and the depth.
\item When approximating by a List\+Set, the error is a metric error bound.
\end{DoxyItemize}\hypertarget{geometry_page_GeometricImplementation}{}\doxysubsection{\texorpdfstring{Implementation of Geometric Types and Operations}{Implementation of Geometric Types and Operations}}\label{geometry_page_GeometricImplementation}

A Rectangle can be directly converted to a Polytope or Polyhedron without using arithmetic. A Rectangle can be easily converted to a Zonotope, and a Zonotope to a Polytope, but these conversions require arithmetic. Conversion between a Polytope to a Polyhedron can be performed using the double description algorithm.

In many cases, it is not possible to evaluate geometric predicates concerning two sets using a given real number type. For this reason, the results of a geometric predicate returns an object of type {\itshape tribool}, which may be {\itshape true}, {\itshape false} or {\itshape indeterminate} (unknown).

Throughout this sections, we use the supremum norm on $R^n$, and the corresponding operator norm on $\mathbb{R}^{m\times n}$.

Given a zonotope $ Z=\{ c+Ae \mid ||e||\leq 1 \}\subset \mathbb{R}^n$, where $A\in \mathbb{R}^{n\times p}$, we wish to compute a zonotope $Z\textnormal{\textquotesingle} = \{ c + A\textnormal{\textquotesingle} e\textnormal{\textquotesingle} \mid ||e\textnormal{\textquotesingle}||\leq 1\}$ with fewer generators i.\+e. $A\textnormal{\textquotesingle}\in \mathbb{R}^{n\times p\textnormal{\textquotesingle}}$ with $p\textnormal{\textquotesingle}<p$. The general reduction method is to choose $ A\textnormal{\textquotesingle}$ such that $ A = A\textnormal{\textquotesingle} B$ with $||B||\leq 1$. The key to zonotopic reduction is to choose a method with good properties.

A simple criterion to note is that if $\sum_{j=1}^{p} |b_{ij}|<1$ for some $i$, then we can improve the approximation by taking $D=\mathrm{diag}(d_{i})$ with $d_{i}=\sum_{j=1}^{p} |b_{ij}|$, and $B\textnormal{\textquotesingle}= D^{-1}B$ which has $b\textnormal{\textquotesingle}_{ij}=b_{ij}/\sum_{k=1}^{p} |b_{ik}|$.

It is clear that if the rows of $B$ are close to a set of mutually orthogonal coordinate vectors, then the approximation is good, since the image of $B$ is close to the unit ball.

An {\itshape interval zonotope} is a set of the form  $ \{ y = c + A e \mid c\in R,\ A\in\mathcal{A} \text{ and } ||e||\leq1 \}
= R + \mathcal{A} B$. To reduce an interval zonotope, we first write $ R = \{ c + Be\mid ||e||\leq 1 \}$ and combine this in $\mathcal{A}$. To reduce $ \mathcal{A} $, write $ \mathcal{A} = A \mathcal{B} \mathcal{A} $ where $ A\in\mathcal{A}$ and $A\mathcal{B}\ni I$. Then take $ \mathcal{C} = \mathcal{B} \mathcal{A} $ and  $ || \mathcal{C} ||
  = \sup_{i]1}^{n} \sum_{j=1}^{p} \max |\mathcal{C}_{ij}| $, where $ \max |\mathcal{C}_{ij}| = \max\{ |x| \mid x\in \mathcal{C}_{ij}$.
