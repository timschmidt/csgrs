\doxysubsubsection{Description}
An open cell of a grid paving. This cell is open and the path from the primary cell defines its lower left sub cell wheres the complete open cell is a union of 4 cells. 

This class does not contain the tree structure, so cannot be used in cursors/iterators. NOTE\+: The open cell is defined by its base cell which is a simple \doxylink{classAriadne_1_1GridCell}{Grid\+Cell} corresponding to the left-\/most quadrant cell of the open cell. In this respect, height() and \doxylink{classAriadne_1_1GridAbstractCell_a75e29061fb3004a2912571edc2354a3f}{word()} return values defining the base cell and \doxylink{classAriadne_1_1GridAbstractCell_aeb1878e3de51b23a53d0573314ca52b1}{box()} returns the entire box related to the open cell. This box should be treated as an open set, i.\+e. its borders should be excluded. Inheritance diagram for Grid\+Open\+Cell\+:\begin{figure}[H]
