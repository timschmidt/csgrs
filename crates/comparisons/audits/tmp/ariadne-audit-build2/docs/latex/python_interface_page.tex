\doxysection{Python Interface }
\hypertarget{python_interface_page}{}\label{python_interface_page}\index{Python Interface@{Python Interface}}
The Python interface provides Python bindings to Ariadne\textquotesingle{}s C++ library. It does not introduce new functionality; instead it merely makes the C++ classes, methods, functions and variables usable from a Python script.

As far as possible, the Python interface mimics the C++ interface, so the C++ documentation is also applicable for Python users. However, there are some unavoidable differences, due to the differences between C++ and Python. The main differences that Python users consulting the C++ documentation should be aware of are given below\+:


\begin{DoxyItemize}
\item {\itshape Not all classes and methods are exported\+:} ~\newline
 To see which classes are exported, type\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{python3\ -\/c\ \textcolor{stringliteral}{"{}import\ ariadne;\ print(dir(ariadne))"{}}\ }

\end{DoxyCode}
 Missing classes may be added in a future release.
\item {\itshape C++ templates\+:} ~\newline
 C++ allows classes to be defined which depend on other classes; such classes are called {\itshape templates}. For example, the template \doxylink{classAriadne_1_1Bounds}{Bounds\texorpdfstring{$<$}{<}X\texorpdfstring{$>$}{>}} describes bounds on a quantity, where the lower and upper bounds are objects of class {\itshape X}. Thus \doxylink{classAriadne_1_1Numeric_1_1Bounds}{Bounds$<$\+Dyadic$>$} represents dyadic bounds on a real number, and \doxylink{classAriadne_1_1Bounds}{Bounds$<$\+Float\+MP$>$} would represents multiple-\/precision floating-\/point bounds. Each instantiation of a C++ template yields a different class. ~\newline
 Since Python does not have templates, in the Python interface, each instantiation is a separate class. The class name is derived from the template name and the class parameter. For example, \doxylink{classAriadne_1_1Bounds}{Bounds\texorpdfstring{$<$}{<}Dyadic\texorpdfstring{$>$}{>}} translates to the Python class \doxylink{classAriadne_1_1Dyadic_acb338d1e5663407eab31b6c5aaf70a77}{Dyadic\+Bounds}. The Python class name is available from C++ (and can be found in the documentation) as a C++ {\ttfamily typedef} class alias. ~\newline
 For some C++ templates, the C++ class {\ttfamily T\texorpdfstring{$<$}{<}X\texorpdfstring{$>$}{>} } is avalable in Python as {\ttfamily T\mbox{[}X\mbox{]}}. For example, the C++ template class Float\texorpdfstring{$<$}{<}DP\texorpdfstring{$>$}{>}, with Python class name \doxylink{namespaceAriadne_af915b9f1459c9691328efa71c6f39c6e}{Float\+DP}, is also available in Python as {\ttfamily Float\mbox{[}\doxylink{namespaceAriadne_a20c85a0dd881b12bf7ca596b4f5fa815}{DP}\mbox{]}}, and the C++ template class \doxylink{classAriadne_1_1Bounds}{Bounds\texorpdfstring{$<$}{<}Float\texorpdfstring{$<$}{<}DP\texorpdfstring{$>$}{>}\texorpdfstring{$>$}{>}} with python class name Float\+DPBounds, is also available in Python as {\ttfamily \doxylink{classAriadne_1_1Bounds}{Bounds}\mbox{[}Float\mbox{[}\doxylink{namespaceAriadne_a20c85a0dd881b12bf7ca596b4f5fa815}{DP}\mbox{]}\mbox{]}} or {\ttfamily \doxylink{classAriadne_1_1Bounds}{Bounds}\mbox{[}\doxylink{namespaceAriadne_af915b9f1459c9691328efa71c6f39c6e}{Float\+DP}\mbox{]}}.
\item {\itshape Conversion\+:} ~\newline
 Conversions from a class {\ttfamily F} to a class {\ttfamily T} are defined by a constructor {\ttfamily T(\+F)} in class {\ttfamily T}, or by a conversion operator {\ttfamily operator T()} in class {\ttfamily F}. Such conversions may be automatically applied in the Python interface when dispatching functions, though the conversion applied may differ slighly from the C++ version. When in doubt, use an explicit constructor {\ttfamily T(obj)} to convert to type {\ttfamily T}.
\item {\itshape Operators\+:} ~\newline
 In both C++ and Python, unary and binary mathematical operators represented by a symbol {\ttfamily ★} can be defined, and are used by {\ttfamily ★x} or {\ttfamily x1★x2}. e.\+g. the addition operator is used by {\ttfamily x1+x2}. In Python, operators are defined by specially-\/named class methods. e.\+g. addition is defined by the {\ttfamily {\bfseries{add}}} method. In C++, the operator {\ttfamily ★} is defined by the function with name {\ttfamily operator★}. e.\+g. addition is defined by {\ttfamily operator+(\+X1 x1, X2 x2)}. To find the information about a Python operator with symbol {\ttfamily ★}, you should look for {\ttfamily operator★} in the C++ API docmentation. ~\newline
 Note that C++ does not have a \textquotesingle{}power\textquotesingle{} operator; {\ttfamily operator\texorpdfstring{$^\wedge$}{\string^}} is \textquotesingle{}bitwise exclusive or\textquotesingle{}, and has a lower precedence than multiplication. In Python, the power operator is used by {\ttfamily x1 \texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*} x2}. ~\newline
 Since Python does not allow user-\/defined logical operations {\ttfamily and}, {\ttfamily or} and {\ttfamily not}, these are implemented by the \textquotesingle{}bitwise\textquotesingle{} operators {\ttfamily \&}, {\ttfamily \texorpdfstring{$\vert$}{|}} and {\ttfamily \texorpdfstring{$\sim$}{\string~}}, and are used by {\ttfamily b1\&b2}, {\ttfamily b1\texorpdfstring{$\vert$}{|}b2} and {\ttfamily \texorpdfstring{$\sim$}{\string~}b2}.
\item {\itshape Printing\+:} ~\newline
 In C++, printing is achieved by defining {\ttfamily \doxylink{namespaceAriadne_acbb98ddc4385af4599070e65a1a47ec1}{Output\+Stream}\& operator$<$$<$(\+Output\+Stream\& os, Class obj)}. In Python, printing is performed by the {\ttfamily print(obj)} statement, or by converting to a string using {\ttfamily str(obj)} or {\ttfamily repr(obj)}. The Python output of {\ttfamily repr} typically differs from the C++ output or that of {\ttfamily str}, and is designed so that {\ttfamily eval(repr(obj))} yields an object equivalent to the original argument.
\item {\itshape C++ extended literals\+:} ~\newline
 The C++ {\ttfamily operator"{}"{}} can be used to define extended numeric and string literals. For example, operator"{}"{}\+\_\+dy(long long double) can be used as {\ttfamily 1.\+375\+\_\+dy} to be interpreted as the \doxylink{classAriadne_1_1Dyadic}{Dyadic} number $11/2^3$. Python does not support extended literals, but the same result may be obtained either by a constructor, or by using the literal tag as a function e.\+g. {\ttfamily dy\+\_\+(1.\+375)}. 
\end{DoxyItemize}
