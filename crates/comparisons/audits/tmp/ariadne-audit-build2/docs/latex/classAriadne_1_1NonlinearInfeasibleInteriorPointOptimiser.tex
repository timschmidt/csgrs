\doxysubsubsection{Description}
Solver for linear programming problems using invalid interior point methods. 

Introduces variables $w$ and attempts to find $x\in D$ and $w\in C$ such that $g(x)=w$. The dual variables $y$ are unconstrained Lagrange multipliers for $y\cdot(g(x)-w)=0$. Inheritance diagram for Nonlinear\+Infeasible\+Interior\+Point\+Optimiser\+:\begin{figure}[H]
