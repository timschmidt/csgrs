class \mbox{\hyperlink{classAriadne_1_1HybridEnclosure}{Hybrid\+Enclosure}}
\begin{DoxyCompactList}\small\item\em A class representing an enclosure for a hybrid evolution. Handles progress, activation and guard constraints internally. The set is represented as the image of a box $D$ under a function model $\xi(s)=\hat{f}(s)$, under the constraints $\hat{c}(s) \leq 0$ and $\hat{e}(s)=0$. Also keeps track of the current time $\tau(s)=\hat{t}(s)$. \end{DoxyCompactList}\end{DoxyCompactItemize}
