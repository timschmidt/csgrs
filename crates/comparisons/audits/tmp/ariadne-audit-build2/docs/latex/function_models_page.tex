\doxysection{Function Models }
\hypertarget{function_models_page}{}\label{function_models_page}\index{Function Models@{Function Models}}
A {\itshape model} for a function $f:\mathbb{R}^n\rightarrow \mathbb{R}^m$ is an approximation of $f$ on some domain $D$. A {\itshape validated} model describes a set of possibilities for $f$, such as a ball around some fixed approximation in a function norm, whereas an {\itshape approximate} model merely gives an approxmation, with no guarantees on the true value.

A particularly useful approach is to first {\itshape scale} or otherwise perform a mapping of $D$ to a canonical domain, typically $[-1\!:\!+1]^n$, though for Fourier approximations we may prefer variables in $[-\pi\!:\!+\pi]$. We shall henceforth assume that our function models are defined on a rescaled domain.

For more information on Taylor (polynomial) models, see Berz \& Hoffstätter (1998) and Makino \& Berz (1999).\hypertarget{function_models_page_polynomial_models}{}\doxysubsection{\texorpdfstring{Polynomial Models}{Polynomial Models}}\label{function_models_page_polynomial_models}
A polynomial model represent represents a function $f$ on $X$ by in terms of a polynomial over $D$.

We recall that a polynomial $p$ in $n$ variables $(x_1,\ldots,x_n)$ can be written as \[ p(x) = \sum_{\alpha\in \aleph} c_{\alpha}\,x^{\alpha} . \] Here, $\alpha$ is a multi-\/index $(\alpha_1,\ldots,\alpha_m)$ with degree $|\alpha|=\alpha_1+\cdots+\alpha_m$, and $x^\alpha := x_1^{\alpha_1}\,x_2^{\alpha_2}\,\cdots\,x_m^{\alpha_m}$, and $\aleph$ is a finite set of multi-\/indices. We will write $\alpha_i$ for the multi-\/index $(\alpha_i)_i=1$, $(\alpha_i)_j=0,\;i\neq j$. The coefficients $c_\alpha$ are constants of a real-\/number type depending on the representation of the model.

In an {\itshape approximate} model, the coefficients are approximate values $\tilde{c}_\alpha$, typically of some Approximation\texorpdfstring{$<$}{<}FLT\texorpdfstring{$>$}{>} class.The model is then an approximate polynomial \[ \textstyle \tilde{p}(x) = \sum_{\alpha\in\aleph} \tilde{c}_\alpha x^\alpha \] such that $\tilde{p} \approx f$ over $D$.

There are many kinds of {\itshape validated} model.

A simple class of validated models can be described \[ \hat{p}(z) = \sum_\alpha c_\alpha z^\alpha \pm e = p(z)\pm \varepsilon \] which describes a continuous function in the set \[ \textstyle \langle p \pm \varepsilon\rangle = \{ f : D\to\R \mid \forall _{z\in D} | f(z) - p(z) | \leq \varepsilon \} . \] In other words, $\hat{p}$ is the ball of radius $e$ around $p(z)=\sum_\alpha c_\alpha z^\alpha$ in the uniform ( $L^\infty$) norm. Note that this model class does not support differentiation, since (here, restricting to one dimension) for any differentiable function $e$ with $\|e\|_\infty\leq \varepsilon$, we could have $f\textnormal{\textquotesingle}(z) = \sum_{\alpha} \alpha c_\alpha z^{\alpha-1} + e\textnormal{\textquotesingle}(z)$, so the derivative at any point can be made to take an arbitrary value.\hypertarget{function_models_page_higher_order_function_models}{}\doxysubsubsection{\texorpdfstring{Higher Order Function Models}{Higher Order Function Models}}\label{function_models_page_higher_order_function_models}
We can also consider models in higher differentiability classes by keeping track of higher-\/order norms. For example, we can keep track of error bounds $\varepsilon_\alpha$ on $\partial^\alpha f/\partial z^\alpha$ for $|\alpha|=1$ to obtain a {\itshape  $C^1$ function model}. Here, it is also useful to keep track of the error $\delta_0$ at $z=0$, since then we have the following bound on the uniform error\+: \[ \textstyle \sup_{z\in D}|f(z)-p(z)| \leq \delta_0 + \sum_i \epsilon_{\alpha_i} z_i , \]\hypertarget{function_models_page_interval_taylor_models}{}\doxysubsubsection{\texorpdfstring{Interval Taylor Models}{Interval Taylor Models}}\label{function_models_page_interval_taylor_models}
We can construct polynomial models using coefficients which are themselves non-\/exact\+: \[ \textstyle \hat{p}(z) = \sum_\alpha \hat{c}_\alpha z^\alpha \]\hypertarget{function_models_page_interval_taylor_model_semantics}{}\doxysubsubsubsection{\texorpdfstring{Semantics}{Semantics}}\label{function_models_page_interval_taylor_model_semantics}
Here there are two distinct interpretations\+:
\begin{DoxyItemize}
\item (i) We can assume that the $\hat{c}_\alpha$ are bounds for some fixed, but unknown value. In this case, $\langle \hat{p} \rangle$ is a set of {\itshape polynomials\+:} \[ \textstyle \langle \hat{p} \rangle = \{ f : D\to\R \mid \forall \alpha\in\aleph,\ \exists c_\alpha \in \hat{c}_\alpha,\ \forall z\in D,\ f(z) = \sum_\alpha c_\alpha z^\alpha \} , \]
\item (ii) We can assume that the $\widehat{c}_\alpha$ are bounds on the range of a function which may itself depend on $z$. In this case, we give the semantics\+: \[ \textstyle \langle \hat{p} \rangle = \{ f : D\to\R \mid \forall z\in D,\ \forall \alpha\in\aleph,\ \exists c_\alpha\in\widehat{c}_\alpha,\ f(z) = \sum_\alpha c_\alpha z^\alpha \} , \] or equivalently, \[ \textstyle \langle \hat{p} \rangle = \{ f : D\to\R \mid \forall \alpha\in\aleph,\ \exists \gamma_\alpha:D\to\widehat{c}_\alpha,\ f(z) = \sum_\alpha \gamma_\alpha(z) z^\alpha \} . \] Note that the interpretation (ii) gives more possible choices of $f$.
\end{DoxyItemize}

Interpretation (i) only allows representation of polynomial functions. For this reason, one would typically introduce an additional uniform remainder term\+: \[ \textstyle \hat{p}(z) = \sum_\alpha \hat{c}_\alpha z^\alpha \pm e \] to allow representation of arbitrary continuous functions \[ \textstyle \langle \hat{p}\pm e \rangle = \{ f : D\to\R \mid \forall \alpha\in\aleph,\ \exists c_\alpha \in \hat{c}_\alpha,\ \forall z\in D, \ \exists \epsilon\in e,\ f(z) = \sum_\alpha c_\alpha z^\alpha + \epsilon \} , \] Interpretation (ii) allows for the interpretation of analytic functions e.\+g. \[ \exp(z) \in 1+z+\cdots + \frac{1}{(n-1)!}z^{n-1} + \frac{[0.25\!:\!2.75]}{n!} z^{n} \subset \Bigl(1+\frac{[-2.75\!:\!2.75]}{n!}\Bigr) + z + \cdots + \frac{1}{(n-1)!} z^{n-1} . \]\hypertarget{function_models_page_interval_taylor_model_arithmetic}{}\doxysubsubsubsection{\texorpdfstring{Arithmetic}{Arithmetic}}\label{function_models_page_interval_taylor_model_arithmetic}
In both cases, arithmetic can be performed by using interval arithmetic on the coefficients\+:  \[ \begin{aligned} \textstyle (\sum_\alpha \hat{a}_\alpha z^\alpha) + (\sum_\beta \hat{b}_\beta z^\beta) &= \textstyle \sum_{\gamma} \bigl( \hat{a}_\gamma + \hat{b}_\gamma \bigr) z^\gamma \\
\textstyle (\sum_\alpha \hat{a}_\alpha z^\alpha) \times (\sum_\beta \hat{b}_\beta z^\beta) &= \textstyle \sum_{\gamma} \bigl( \sum_{\alpha+\beta=\gamma} \hat{a}_\alpha \times \hat{b}_\beta \bigr) z^\gamma . \end{aligned} \] and composition by using the addition and multiplication operations so defined.\hypertarget{function_models_page_interval_taylor_model_differentiation}{}\doxysubsubsubsection{\texorpdfstring{Differentiation}{Differentiation}}\label{function_models_page_interval_taylor_model_differentiation}
Howerver, interpretation (ii) does not support differentiation, since \[ \frac{d}{dz} \sum_k \gamma_k(z) z^k = \sum_k \bigl( \gamma_k\textnormal{\textquotesingle}(z) + (k+1) \gamma_{k+1}(z) \bigr) z^k , \] and $\gamma_k\textnormal{\textquotesingle}(z)$ cannot be bounded, while In the first interpretation, differentiation can be performed elementwise\+: \[ \frac{d}{dz} \sum_k \hat{c}_k z^k = \sum_k (k+1) \hat{c}_{k+1} z^k , \]\hypertarget{function_models_page_interval_taylor_model_integration}{}\doxysubsubsubsection{\texorpdfstring{Integration}{Integration}}\label{function_models_page_interval_taylor_model_integration}
Integration also differs between the two interpretations. In interpretation (i), \[ \int_a^b \sum_k \hat{c}_k z^k ,dz = \sum_k \tfrac{1}{k+1}\hat{c}_k \bigl[ z^{k+1}\bigr]_a^b = \sum_{k} \tfrac{1}{k+1}\hat{c}_k (b^{k+1}-a^{k+1}) , \] whereas in the second interpretation (ii), \[ \int_a^b \sum_k \hat{c}_k z^k \,dz = \Bigl[{{\sum}_k \tfrac{1}{k+1}\hat{c}_k z^{k+1}}\Bigr]_a^b = \sum_{k} \tfrac{1}{k+1} \bigl(\hat{c}_k b^{k+1}-\hat{c}_k a^{k+1}\bigr) . \] These are different, since the distributive law does not hold for interval arithmetic\+: in general, $(b-a)\hat{c} \subsetneq b\hat{c}-a\hat{c}$. However, for interpretation (ii) we can still use \[ \int_0^z \sum_k \hat{c}_k \zeta^k \,d\zeta = \Bigl[{{\sum}_k \tfrac{1}{k+1}\hat{c}_k \zeta^{k+1}}\Bigr]_0^z = \sum_{k} \tfrac{1}{k+1} \hat{c}_k z^{k+1} . \]\hypertarget{function_models_page_interval_taylor_model_multivalued}{}\doxysubsubsubsection{\texorpdfstring{Sets of functions}{Sets of functions}}\label{function_models_page_interval_taylor_model_multivalued}
In many cases, we use interval coefficients when we wish to denote an over-\/approximation to a {\itshape set} of functions, or to a {\itshape multivalued} function, rather than a range of possibilities for a {\itshape single} function point-\/valued function. We henceforth write $\widehat{C}_\alpha$ where distinguish use Upper\+Interval\texorpdfstring{$<$}{<}FLT\texorpdfstring{$>$}{>} as the type of coefficient.


\begin{DoxyItemize}
\item (iii) The interpretation as a set of functions is equivalent to (ii) \[ \textstyle \langle \widehat{P} \rangle = \{ f : D\to\R \mid \forall z\in D,\ \forall \alpha\in\aleph,\ \exists c_\alpha\in\widehat{C}_\alpha,\ f(z) = \sum_\alpha c_\alpha z^\alpha \} , \]
\item (iv) The interpretation as a {\itshape multivalued} function is \[ \textstyle \langle \widehat{P} \rangle = \{ F:D\rightrightarrows\mathbb{R} \mid \forall z, F(z) = \{ w \mid \forall \alpha\in\aleph,\ \exists c_\alpha \in \widehat{C}_\alpha, w=\sum_\alpha c_\alpha z^\alpha\} \} \]
\end{DoxyItemize}

In both cases, arithmetic is performed as for (i) and (ii), and for case (iii), differentiation is not supported, and integration follows case (ii).

{\bfseries{Example}} 

Consider the polynomial model $\hat{p}(z) = [0:1]+[2:4]z$.

In interpretation (i), $\langle \hat{p} \rangle$ is the set of affine functions $ f(z) = c_0 + c_1 z$ where $c_0\in[0:1]$ and $c_1\in[2:4]$. In this case, the possible values of $\int_{-1}^{+1} f(z) dz$ are $[0:2]$, since \[ \begin{aligned} \textstyle \int_{-1}^{+1} f(z)dz & = \textstyle \int_{-1}^{+1} c_0 + c_1 z dz=[c_0z+c_1\tfrac{1}{2}z^2]_{-1}^{+1}=c_0[z]_{-1}^{+1}+c_1[\tfrac{1}{2}z^2]_{-1}^{+1} \\ &\textstyle =c_0(1-(-1))+c_1(\tfrac{1}{2}-\tfrac{1}{2})=2c_0 \in [0:2] . \end{aligned} \]

In interpretation (ii), $\langle \hat{p} \rangle$ is the set all functions of the form $ f(z) = c_0(z) + c_1(z) z$ where for all $z$, $c_0(z)\in[0:1]$ and $c_1(z)\in[2:4]$. In this case, $\int_{-1}^{+1} f(z) dz$ are $[-1:+3]$. The maximum value the integral can take is for $f(z)=1+2z$ for $z\in[-1:0]$ and $1+4z$ for $z\in[0:+1]$, so \[ \textstyle \int_{-1}^{+1} f(z) dz \leq \int_{-1}^{0} 1+2z\,dz + \int_{0}^{+1} 1+4z\,dz = [z+z^2]_{-1}^{0} + [z+2z^2]_{0}^{+1} = (0-0) + (3-0) = 3 . \]

{\bfseries{Notation}} 

We henceforth describe a function $\hat{p}(z)=\sum_{\alpha} \hat{c}_\alpha z^\alpha$ using interpretation (i) as a {\itshape validated polynomial}. When using the interpretations (ii), we use the terminology {\itshape varying-\/coefficient Taylor model}, and for (iii), we say {\itshape interval Taylor model}.

See \doxysectlink{integration_methods_page_interval_taylor_model_differential_inclusions}{Solution (of differential inclusions) using interval Taylor models}{2} for information on using interval Taylor models to solve differential inclusions.\hypertarget{function_models_page_sweeping}{}\doxysubsubsection{\texorpdfstring{Simplification by sweeping}{Simplification by sweeping}}\label{function_models_page_sweeping}
One of the key operations on function models is simplification by {\itshape sweeping}, in which small (or high-\/order) terms are removed by either combining with other terms, or putting into a {\itshape remainder} term, such as the error bound.

For a $C^0$ model $p(z)\pm\varepsilon$, sweeping yields  \[ \textstyle \sum_{\alpha\in\alpha_1} c_\alpha z^\alpha + \sum_{\alpha\in\alpha_2} c_\alpha z^\alpha  \pm \varepsilon \preceq
     \sum_{\alpha\in\alpha_1} c_\alpha z^\alpha  \pm \bigl( \varepsilon + \sum_{\alpha\in\alpha_2} |c_\alpha| \|z^\alpha\| \bigr) . \] When working on the unit domain, $\|z^\alpha\|=1$ for all $\alpha$, so we can take error $\varepsilon + \sum_{\alpha\in\alpha_2} |c_\alpha|$.

Other model classes can be constructed from these basic building blocks. For example, we could consider models which are explicitly represented as a composition, or as a sum of other model classes.\hypertarget{function_models_page_taylor_model_efficiency_and_accuracy}{}\doxysubsubsection{\texorpdfstring{Efficiency and accuracy considerations}{Efficiency and accuracy considerations}}\label{function_models_page_taylor_model_efficiency_and_accuracy}
Consider the approximation of an analytic function $f:\mathbb{R}\to\mathbb{R}$. Assume that the Taylor series of $f$ at $0$ has coefficients $c_k$ and radius of convergence $R$.

Suppose we with to represent $f$ over the interval $[-h\!:\!+h]$ by a Taylor model with sweep threshold $\theta$. We are interested in the balance between the choice of $h$ and $\theta$, the accuracy of the approximation, and the number of terms used.

Since $R=\limsup_{k\to\infty} |c_k|^{1/k}$, there exists a constant $C$ such that $|c_k|\leq C/R^k$. Since we are working on $[-h\!:\!+h]$, scaling to the unit interval gives $f(z)=\sum_{k=0}^\infty c_k h^k z_k$ for $z\in[-1\!:\!+1]$. If $C h^k/R^k \leq \theta$, which occurs when $k\geq \log(\theta/C)/\log(h/R) = M$ (note that we require $h<R$, and we should therefore choose $\theta<C$), we discard the $k$th term. These terms have sum bounded by $C (h/R)^M /(1-h/R) = \theta /(1-h/R)$. The remaining $M$ coefficients $c_k h^k$ could also be less than $\theta$. If $N$ of these are keps, the additional extra error is $(M-N)\theta=\theta (\log(\theta/C)/\log(h/R)-N)$. Hence an over-\/approximation to the total error is \[ \varepsilon = \theta \Bigl( M - N + \frac{1}{1-h/R} \Bigr)\theta \Bigl( (1-\nu) \frac{\log(\theta/C)}{\log(h/R)}  + \frac{1}{1-h/R} \Bigr). \] Clearly, this decreases as $\theta$ decreases, but is non-\/monotone in $h$\+: for $h\to\R$, the Taylor expansion converges too slowly, but for $h\to 0$, all but the constant term decrease below the sweep threshold.

The accuracy considerations need to be balanced by the effort needed to compute with the approximations. We need $\Theta(1/h)$ pieces of width $2h$ to cover a given interval, so we should divide $\varepsilon$ by $h$. The effort $\sigma(N)$ needed to store and work with $N$ terms also needs to be considered; realistic choices are $O(N)$, $O(N\log N)$ and $O(N^2)$.

Assume $N\approx \nu M$ for some constant $\nu\in[0,1]$ i.\+e. a fraction $1-\nu$ of low-\/order terms are small, and are swept away. Denoting the total work by $\mu=\sigma(N)/h$ gives \[ \varepsilon \times \mu = \frac{\theta \sigma(N)}{h} \Bigl( (1-\nu)M + \frac{1}{1-h/R} \Bigr) \]

If we assume $\sigma(N)=N$, then \[ \varepsilon \times \mu = \nu \frac{\theta}{h} \frac{\log(\theta/C)}{\log(h/R)} \Bigr((1-\nu)\frac{\log(\theta/C)}{\log(h/R)}+\frac{1}{1-h/R} \Bigr) \] For $\nu=1$ (i.\+e. all terms with a small degree are kept), this seems to indicates a sweep threshold of around $\theta = C/\mathrm{e}\approx0.37C$ should be used, and $h\approx 0.24 R$.

If we were to take $\sigma(N)=N^2$, then we would expect to prefer a lower sweep threshould and more subintervals.\hypertarget{function_models_page_affine_models}{}\doxysubsection{\texorpdfstring{Affine Models}{Affine Models}}\label{function_models_page_affine_models}
An affine model represents a function $f$ on $X$ by $f(x) = b + A (x-c)$. Given $f$, an $C^1$ model can be computed by taking \[ [b] \ni f(c); \quad [A] \ni Df(X) \]\hypertarget{function_models_page_function_operation}{}\doxysubsection{\texorpdfstring{Function Operations}{Function Operations}}\label{function_models_page_function_operation}
We say a $(d,s)$-\/model is a polynomial of maximum degree $d$, and differentiability class $s$.

The following operations on functions are supported\+:
\begin{DoxyItemize}
\item Evaluation\+: If $p$ is a $(d,s)$-\/model $\mathbb{R}^m\rightarrow\mathbb{R}^n$, then $p(c_1,\ldots,c_m)$ is an interval.
\item Partial evaluation\+: If $p$ is a $(d,s)$-\/model $\mathbb{R}^m\rightarrow\mathbb{R}^n$, then $p(\cdot,\ldots,c_j,\ldots,\cdot)$ is a $(d,s)$-\/model $\mathbb{R}^{m-1}\rightarrow\mathbb{R}^n$.
\item Variable substitution\+: If $p$ is a $(d,s)$-\/model $\mathbb{R}^m\rightarrow\mathbb{R}^n$, and $q$ is a $(d,s)$-\/model $\mathbb{R}^{m-1}\rightarrow \R$, then $p(\cdot,\ldots,q(\cdot),\ldots,\cdot)$ is a $(d,s)$-\/model $\mathbb{R}^{m-1}\rightarrow\mathbb{R}^n$.
\item Addition/\+Subtraction\+: If $p$ and $q$ are $(d,s)$-\/models $\mathbb{R}^m\rightarrow\mathbb{R}^n$, then so are $p+q$ and $p-q$.
\item Multiplication\+: If $s$ is a scalar model $(d,s)$-\/model and $p$ is a $(d,s)$-\/model, then $s\times p$ is a $(d,s)$-\/model.
\item Division\+: If $s$ is a scalar model and $s(x)\neq0$, then $1/s$ is a $(d,s)$-\/model.
\item Differentiation\+: If $p$ is an $(d,s)$-\/model, then the single-\/variable derivative $\frac{\partial p}{\partial x_i}$ is a $(d-1,s-1)$-\/model.
\item Differentiation\+: If $p$ is an $(d,s)$-\/model, then the single-\/variable integral $\int^{x_j} p(x_1,\ldots,\xi_j,\ldots,x_m)\,d\xi_j$ is a $(d,s)$-\/model.
\item Direct sum (combine)\+: If $p_1:\mathbb{R}^{m_1}\rightarrow\mathbb{R}^{n_1}$ and $p_2:\mathbb{R}^{m_2}\rightarrow\mathbb{R}^{n_2}$ are $(d,s)$ models, then so is $p_1\oplus p_2 : \mathbb{R}^{m_1+m_2}\rightarrow\mathbb{R}^{n_1+n_2}$ given by $(p_1\oplus p_2)(x_1,x_2):=(p_1(x_1),p_2(x_2))$.
\item Cartesian product (join)\+: If $p_1:\mathbb{R}^{m}\rightarrow\mathbb{R}^{n_1}$ and $p_2:\mathbb{R}^{m}\rightarrow\mathbb{R}^{n_2}$ are $(d,s)$ models, then so is $p_1 \times p_2 : \mathbb{R}^{m}\rightarrow\mathbb{R}^{n_1+n_2}$ given by $(p_1\times p_2)(x):= (p_1(x),p_2(x))$.
\item Composition\+: If $p_1:\mathbb{R}^{m}\rightarrow\mathbb{R}^{l}$ and $p_2:\mathbb{R}^{l}\rightarrow\mathbb{R}^{n}$ are $(d,s)$-\/models, then $p_2\circ p_1$ is a $(d,s)$-\/model $\mathbb{R}^{m}\rightarrow\mathbb{R}^{n}$.
\item Inverse\+: If $p:\mathbb{R}^{n}\rightarrow\mathbb{R}^{n}$ is a $(d,s)$-\/model with $s\geq1$, and if $Dp$ is nonsingular, then $p^{-1}$ is a $(d,s)$ model. The inverse should be centred around $y=p(x)$, where $x$ is given, since locally $p^{-1}(y)$ may have several branches.
\item Implicit\+: If $p:\mathbb{R}^{m}\times\mathbb{R}^{n}\rightarrow\mathbb{R}^{n}$ is a $(d,s)$-\/model with $s\geq1$, and if $D_2p$ is nonsingular near $(x,y)$, then there is a $(d,s)$-\/model $q$ such that $y\in q(x)$ and $p(x,q(x))=z$.
\item Reduce\+: If $p:\mathbb{R}^{m}\times\mathbb{R}^{n}\rightarrow\mathbb{R}^{n}$ is a $(d_1,s_1)$-\/model, $d_2\leq d_1$ and $s_2\leq\min\{d_2,s_1\}$, then $p$ can be reduced to a $(d_2,s_2)$-\/model.
\end{DoxyItemize}\hypertarget{function_models_page_function_model_contractors}{}\doxysubsection{\texorpdfstring{Theory of Contractors}{Theory of Contractors}}\label{function_models_page_function_model_contractors}
Consider the equation $f_i(x_1,\ldots,x_k)=x_i$ for $i=1,\ldots,k$. A {\itshape contractor} is a set-\/based over-\/approximation to the $f_i$ working on a class of set with an {\itshape intersection} operation. (Actually, all we require of the intersection operation is that it is an over-\/approximation to the set-\/theoretic intersection, and that the intersection of {\itshape X} and {\itshape Y} is a subset of both {\itshape X} and {\itshape Y}.)

A contractor is {\itshape monotone} if $f_i(X_1,\ldots,X_k)\subset f_i(Y_1,\ldots,Y_k)$ if $X_i \subset Y_i$ for all $i$. Suppose $f_i(X_1,\ldots,X_k)=Y_i\subset X_i$, and $Y_j\subset X_j$ for $j\neq i$. Then $f_i(Y_1,\ldots,Y_k)\subset f_i(X_1,\ldots,X_k)\subset Y_i$.

A system of contractors applies updates $X_i\textnormal{\textquotesingle}=f_i(X_1,\ldots,X_k)\cap X_i$, possibly performing multiple updates simultaneously. If $f_i$ is monotone and $f_i(X_1,\ldots,X_k)\subset X_i$ at one stage, then inclusion holds at all stages. We can therefore apply contractors $f_i$ sequentially or in parallel. If for any $i$, $f_i(X_1,\ldots,X_k)\cap X_i = \emptyset$, then there is no fixed-\/point. If for all $i$, $f_i(X_1,\ldots,X_k)\subset X_i$, then there is at least one solution in $X_1\times\cdots\times X_k$.

The Taylor calculus operations are not monotone, since refining an argument may cause terms to be swept into the error. Further, the intersection of two Taylor expressions need not be a subset of either argument due to round-\/off error. However, both operations are over-\/approximations of the exact operations, and this allows us to prove the existence of solutions.

Suppose $f_i$ are monotone contractors, $\hat{f}_i$ are non-\/monotone numerical over-\/approximations to the $f_i$, and $\sqcap$ is an over-\/approximation to the intersection operator. Consider a system of contractors, $X_i\textnormal{\textquotesingle}=\hat{f}_i(X_1,\ldots,X_k) \sqcap X_i$. Suppose that for all $i$ at some stage of the operation, $\hat{f}_i(X_1,\ldots,X_k) \subset X_i$. Then the final result contains a solution of $f_i(x_1,\ldots,x_k)=x_i;\ i=1,\ldots,k$.

Consider the two-\/variable case. Suppose $\hat{f}_1(X_1,X_2)\subset X_1$, and that after applying some numerical contractors to obtain $(Y_1,Y_2)$ we have $\hat{f}_2(Y_1,Y_2)\subset Y_2$. Let $\tilde{Y}_1$ be the set obtained by applying the monotone contractors. Then $f_2(\tilde{Y}_1,Y_2)\subset f_2(Y_1,Y_2) \subset \hat{f}_2(Y_1,Y_2) \subset Y_2$, and $f_1(\tilde{Y}_1,Y_2)\subset \tilde{Y}_1$. Hence $(\tilde{Y}_1,Y_2)$ contains a solution, and therefore so does $(Y_1,Y_2)$.
