\doxysubsubsection{Description}
\subsubsection*{template$<$class M$>$\newline
class Ariadne\+::\+Scaled\+Function\+Patch$<$ M $>$}
A a type of function model in which a the restriction of a scalar function $f:\R^n\rightarrow\R$ on a domain $D$ is approximated by the composition of a scaling function $s^{-1}:D\fto\I^n=[-1\!:\!+1]^n$ with a scaled function model, such as a polynomial $p$ on $\I^n$ with uniform error $e$. 


\begin{DoxyTemplParams}{Template Parameters}
{\em M} & The class used for the function model over the box $[-1\!:\!+1]^n$. For example, \doxylink{classAriadne_1_1TaylorModel_a2b9341268568a075b2bc5d7c9c588447}{Validated\+Taylor\+Model\texorpdfstring{$<$}{<}F\texorpdfstring{$>$}{>}} would give a scaled representation which is a polynomial with coefficients of type {\ttfamily F}, with a uniform error bound.\\
\hline
\end{DoxyTemplParams}
Formally, a \doxylink{group__FunctionModelSubModule_ga05c1c7011f989b1ec0ba7f5d4e81580f}{Validated\+Scalar\+Multivariate\+Taylor\+Function\+Model\+DP} is a triple $(D,p,e)$ representing a set of continuous functions $\mathrm{T}(D,p,e)$ by \[ \mathrm{T}(D,p,e) = \{ f:\R^n\rightarrow \R \mid \sup_{x\in D}|f(x)-p(x)| \leq e \} . \] Note that there is no need for the functions $f$ to be themselves polynomial, and that no information is given about the values of $f$ outside of $D$. Information about the derivatives of $f$ is also unavailable. However, integrals of $f$ can be computed.

Internally, the polynomial $p$ is represented as the composition $p=m\circ s^{-1}$, where $m:[-1,+1]^n\rightarrow\R$ and $s:[-1,+1]^n\rightarrow D$ is a scaling function, $s_i(y_i)=(a_i+b_i)/2+(b_i-a_i)y_i/2$ where $D_i=[a_i,b_i]$ is the $i^\textrm{th}$ subinterval of $D$.

When solving algebraic equations by iterative Newton-\/like methods, it is necessary to compute the derivatives of $f$. For these applications, it suffices to compute the derivative of $p$, since only a uniform approximation to the solution is required.

Finding exact bounds for the range of $p$ over $D$ is an NP-\/complete problem, for but there are a number of techniques available.
