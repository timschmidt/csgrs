\doxysubsubsection{Description}
Base routines for hybrid evolution. Includes routines for extracting system information in a mode, applying initial events, computing crossing times, computing the evolution time, and applying a time step. 

\begin{DoxySeeAlso}{See also}
The \doxylink{hybrid_evolution_page}{Hybrid Evolution Methods } page for details of the basic algorithm.
\end{DoxySeeAlso}
NOTE\+: This class currently contains both a skeleton for hybrid evolution, and default implementations of many of the routines. It would be cleaner to have an interface class without these default implementations. However, which operations are needed may depend on the higher-\/level operations involved, so these methods should also not go in the interface. Process the {\itshape starting\+\_\+set} to find any {\itshape immediately active} events, and compute the relevant {\itshape jump} sets and the {\itshape flowable} or {\itshape progress} set. 

First, and {\itshape invariants} $i_e(x)\leq0$ are processed to give an {\itshape allowable} or {\itshape invariant} $I=\{ x\in S \mid \forall e\in E_{\mathrm{inv}},\ i_e(x)\leq0\}$. Then for each urgent or permissive transition, the {\itshape active} set $A_e = \{ x\in I \mid g_e(x)\geq 0\}$ and jump set $ _e = r_e(A_e)$ are computed. Finally, any progress predicates $p_e(x)\leq0$ are processed (including those derived from urgent events), to give the flowable set $P=\{ x\in I \mid \forall e\in E_{\mathrm{tcp}},\ p_e(x)\leq0\}$.
