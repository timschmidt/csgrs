\hypertarget{group__HybridSetSubModule}{}\label{group__HybridSetSubModule}\index{Hybrid sets@{Hybrid sets}}


\doxysubsubsubsection{Description}
Sets in spaces with many components. 

The state space of a hybrid system consists of many disconnected components, one for each discrete mode. Hybrid sets consist of a union of many different sets, one for each component of the state space. \doxysubsubsubsubsection*{Classes}
