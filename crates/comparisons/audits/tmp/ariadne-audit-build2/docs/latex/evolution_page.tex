The infinite-\/time reachable set of a discrete-\/time dynamical system (automaton) is defined as \[ \mathrm{reach}(f,X_0) := \bigcup_{n=0}^{\infty} f^n(X_0) . \] As shown in Collins (2005, {\itshape Theor. Comput. Sci.}) it is not possible to compute convergent over-\/approximations to the reachable set. Instead, we consider the {\itshape  chain-\/reachable set}, which is defined as \[ \mathrm{chain\;\!reach}(f,X_0) := \bigcap_{n=0}^{\infty} \{ U\in\mathcal{O}(X) \mid X_0\cup f(\mathrm{cl}(U))\subset U \} . \] Note that $\mathrm{chain\;\!reach}(f,X_0)$ is closed, and $\mathrm{reach}(f,X_0)\subset \mathrm{chain\;\!reach}(f,X_0)$. If the chain-\/reachable set is compact, then it is possible to compute a convergent sequence of over-\/approximations, and the chain-\/reachable set is the smallest computable over-\/approximation to the reachable set. If the chain-\/reachable set is not compact, then may not be possible to approximate, even in a bounded region.

The {\itshape viability kernel} of $S$ under a system $f$ is defined as \[ \mathrm{viab}(f,S) := \bigcup_{n=0}^{\infty} f^{-n}(S). \] The viability kernel is the set of initial points for which the evolution remains in $A$ for all time. If $S$ is compact, then it is possible to compute convergent over-\/approximations to $\mathrm{viab}(f,S)$.\hypertarget{evolution_page_safetyverification}{}\doxysubsection{\texorpdfstring{Safety Verification}{Safety Verification}}\label{evolution_page_safetyverification}
The {\itshape safety verification problem} is to decide whether $\mathrm{reach}(f,X_0)\subset S$ for some set $S$. We assume that $S$ is bounded and {\itshape regular} which means that we can compute both over-\/ and under-\/approximations to $S$. We assume that $X_0$ is compact, so we can compute lower-\/approximations and over-\/approximations to $X_0$.

If $\mathrm{reach}(f,X_0)\not\subset \overline{S}$, then we can find a point in $X_0$ which leaves $S$, and hence prove that $\mathrm{reach}(f,X_0)\not\subset S$. If $\mathrm{chain\;\!reach}(f,X_0)\subset S^\circ$, then we can find an over-\/approximation to $\mathrm{chain\;\!reach}(f,X_0)$ which is a subset of $S$, and hence prove that $\mathrm{reach}(f,X_0)\subset S$. However, if $\mathrm{reach}(f,X_0)\subset \overline{S}$ but $\mathrm{chain\;\!reach}(f,X_0)\not\subset S^\circ$, then it is {\itshape impossible} to decide whether $\mathrm{reach}(f,X_0)\subset S$ using approximative numerical methods.

Since $ \mathrm{reach}(f,X_0) \subset S \iff X_0 \subset \mathrm{viab}(f,S) , $ we can test for $\mathrm{reach}(f,X_0) \not\subset S$ by checking $X_0 \not\subset \mathrm{viab}(f,S)$, which may be computationally easier as over-\/approximations are usually easier to work with than lower-\/approximations.\hypertarget{evolution_page_discretetimeevolution}{}\doxysubsection{\texorpdfstring{Evolution of Discrete-\/\+Time Systems}{Evolution of Discrete-\/\+Time Systems}}\label{evolution_page_discretetimeevolution}
To evolve a system in Ariadne, we require a number of core methods
\begin{DoxyItemize}
\item A method evaluate an over-\/approximation of the image of a Basic\+Set type.
\item A method to subdivide the Basic\+Set type.
\item A method to approximate the Basic\+Set type on a grid.
\end{DoxyItemize}

The computation of over-\/approximations to forward iterates and reachable sets proceeds as follows\+: First, the set to be evolved is approximated as a union of basic sets. Then each basic set is evolved for a number of evolution time steps. This evolution should use higher-\/order methods to preserve accuracy. If the basic set becomes too large, the error in the evolution step becomes large, and the basic set may be subdivided to avoid catastrophic loss of accuracy. Finally, after a specified number of time steps, the evolved sets are over-\/approximated or "{}locked"{} back to the grid. Locking to the grid causes a loss of accuracy since the operation is zero-\/order, but allows previously evaluated traces to be re-\/used.

The best basic set type to use depends on the smoothness of the system. For differentiable maps, a zonotope is usually a good choice, as it gives first-\/order accuracy in space. For higher-\/order accuracy, {\itshape Taylor sets} may be used; these are polynomial images of cuboids.\hypertarget{evolution_page_continuoustimeevolution}{}\doxysubsection{\texorpdfstring{Evolution of Continuous-\/\+Time Systems}{Evolution of Continuous-\/\+Time Systems}}\label{evolution_page_continuoustimeevolution}
The basic method for integrating a continuous-\/time system is similar to that for a discrete-\/time system. The time step is adaptively determined, between user-\/specified minimum and maximum values. However, care must be taking when setting the lock-\/to-\/grid time, since locking to the grid causes loss of accuracy. Setting the lock-\/to-\/grid time too low will probably result in the entire state space to be covered. A good choice for the lock-\/to-\/grid time is the average recurrence time of the system.

There are essentially two methods to compute reachable sets $\mathrm{reach}(f,X_0,T) := \Phi_{[0,T]}(X_0)$, where $\Phi_t$ is the flow of $f$. We either have \[ \Phi_{[0,T]}(X_0) =  \bigcup_{n=0}^{N-1} \Phi^n_{T/N}\bigl(\Phi_{[0,T/N]}(X_0)\bigr) \] or \[ \Phi_{[0,T]}(X_0) = \Phi_{[0,T/N]}\Biggl( \bigcup_{n=0}^{N-1} \Phi^n_{T/N}(X_0)  \Biggr) . \] In other words, we either first integrate $N-1$ times with a time step of $T/N$ and finally perform a reachability step, or first perform a reachability step and then integrate the resulting set $N-1$ times.

Similar considerations hold for infinite-\/time reachable sets.\hypertarget{evolution_page_hybridtimeevolution}{}\doxysubsection{\texorpdfstring{Evolution of Hybrid-\/\+Time Systems}{Evolution of Hybrid-\/\+Time Systems}}\label{evolution_page_hybridtimeevolution}
For hybrid systems, there are two semantics of evolution, {\itshape lower semantics} and {\itshape upper semantics}. In most cases, there is no difference between the two. However, where the system exhibits {\itshape grazing} (tangential contact between a flow line and a guard set) or {\itshape multiply-\/enabled transistion} (such as on the boundary of two different guard sets) the semantics differ. With lower semantics, the system evolution {\itshape blocks} if it is not possible to determine which course of action to follow. (For grazing behaviour, this would mean that trajectories near the grazing orbit block, since numerical errors will make it impossible to determine whether the guard set is crossed or not.) With upper semantics, the system evolves {\itshape nondeterministically} with both courses of action being taken. This means that we use lower semantics if we want to prove that it is possible to reach a given set, and upper semantics if we want to prove that the evolution remains inside a given set. See Collins \& Lygeros (2005) for more details.

The simplest way to compute the chain-\/reachable set of a hybrid system is to alternate discrete transitions with computing the chain-\/reachable set in each mode.
