\doxysubsubsubsubsection{Description}
Classes and functions for solving nonlinear algebraic equations. 

For the mathematical theory of algebraic equations, including implicit function problems, see the \doxysectlink{algebraic_equations_page}{Algebraic Equations}{0} Page.

A {\itshape Solver} class provides functionality for solving algebraic equations, as defined in the Solver\+Interface. Two basic kinds of problem are considered. The first is computing roots of a function $f:\R^n\to\R^n$, which are generically isolated points. The second kind of problem is solving parametrised equations, so for a function $ f:\R^m\times\R^n\to\R^n $, we find a function $ h:\R^m\to\R^n $ such that $ f(x,h(x))=0 $ for all $ x $ in some domain $ D $.
