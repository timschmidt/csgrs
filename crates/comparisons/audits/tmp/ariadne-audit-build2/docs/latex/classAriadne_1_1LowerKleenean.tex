\doxysubsubsection{Description}
A logical class representing the result of a verifyable predicate over a continuous (uncountable) data type. 

A canonical example is strict positivity of a real number given only lower bounds to its value, since sufficient accurate lower bounds for a strictly positive number are themselves strictly positive, but negativity cannot be deduced given only lower bounds to a negative number. \doxysubsubsubsection*{Public Member Functions}
