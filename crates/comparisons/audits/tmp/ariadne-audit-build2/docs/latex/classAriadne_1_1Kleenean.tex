\doxysubsubsection{Description}
A logical class representing the result of a quasidecidable predicate over a continuous (uncountable) data type. 

A canonical example is (strict) positivity of a real number, which is undecidable for zero, since positivity cannot be determined from arbitrarily accurate approximations. \doxysubsubsubsection*{Public Member Functions}
