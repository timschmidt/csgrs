\doxysubsubsubsection{Information }
\hypertarget{group__InformationSubModule}{}\label{group__InformationSubModule}\index{Information@{Information}}
Tag classes describing the information provided by a type, notably \doxylink{structAriadne_1_1ExactTag}{Exact\+Tag}, as \doxylink{structAriadne_1_1EffectiveTag}{Effective\+Tag}, \doxylink{structAriadne_1_1ValidatedTag}{Validated\+Tag} and \doxylink{structAriadne_1_1ApproximateTag}{Approximate\+Tag}. 

{\itshape For the mathematical theory of computable analysis and kinds of information, see the \doxysectlink{computable_analysis_page}{Foundations of Computable Analysis}{0} Page.}

\label{group__InformationSubModule_information_section}%
\Hypertarget{group__InformationSubModule_information_section}%
 In order to indicate the kind of guarantees on the approximation provided by a concrete object, every type in Ariadne has an associated {\itshape \doxylink{namespaceAriadne_a8db63fe3c811b0cb1e1ee876b1b0e340}{Paradigm}} tag, denoted by the tempate parameter {\ttfamily P}. The \doxylink{structAriadne_1_1ExactTag}{Exact\+Tag} indicates that the object represents a value exactly, and with decidable equality. The \doxylink{structAriadne_1_1EffectiveTag}{Effective\+Tag} indicates that an object allows approximations to be computed to arbitrary, known accuracy. The \doxylink{structAriadne_1_1ValidatedTag}{Validated\+Tag} indicates that the objects provides an approximation with guarantees on the error, such as lower-\/ and upper-\/bounds, or an error bound. The \doxylink{structAriadne_1_1ApproximateTag}{Approximate\+Tag} indicates that the object is an approximation with no guarantees on the accuracy.

Whenever the paradigm tag {\ttfamily P} occurs as a template parameter, a type alias is given in which the type is prefixed by the tag name. For example, \doxylink{classAriadne_1_1Number}{Number\texorpdfstring{$<$}{<}Validated\+Tag\texorpdfstring{$>$}{>}} has alias \doxylink{classAriadne_1_1Number_a820ba577a94ed1682c33d544f6430ae1}{Validated\+Number}, and \doxylink{classAriadne_1_1Function}{Function\texorpdfstring{$<$}{<}Effective\+Tag,SIG\texorpdfstring{$>$}{>}} has alias \doxylink{group__FunctionModule_ga1ce9d5a1cfb352fbd1daf2f696740357}{Effective\+Function\texorpdfstring{$<$}{<}SIG\texorpdfstring{$>$}{>}}.

\begin{DoxyRemark}{Remarks}
In a future version of Ariadne, it may be the case that information tags are replaced by template prefixes, so \doxylink{classAriadne_1_1Number}{Number\texorpdfstring{$<$}{<}Validated\+Tag\texorpdfstring{$>$}{>}} becomes {\ttfamily \doxylink{classAriadne_1_1Concepts_1_1Validated}{Validated$<$\+Number$>$}}.
\end{DoxyRemark}
