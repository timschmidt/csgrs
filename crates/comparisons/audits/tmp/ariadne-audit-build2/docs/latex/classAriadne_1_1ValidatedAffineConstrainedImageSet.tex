\doxysubsubsection{Description}
A constrained image set defined by affine functions. Defines a set of the form $S=\{ f(x) \mid x\in D \mid g(x)\leq 0 \wedge h(x)=0 \}$ where $f$, $g$ and $h$ are vector-\/valued affine functions on $\R^n$ and $D$ is a box in $\R^n$. 

Includes the class of zonotopes $Z=\{ f(x) \mid x\in D\}$, polyhedra $\{ f(x) \mid x\in\R^n \mid g(x)\leq 0\}$ and polytopes $\{ f(x) \mid x\in[0,\infty)^n \mid \sum_{i=1}^{n} x_i -1 = 0\}$. \begin{DoxySeeAlso}{See also}
