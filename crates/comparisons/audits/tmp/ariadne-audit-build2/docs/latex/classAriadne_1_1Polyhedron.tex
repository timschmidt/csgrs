\doxysubsubsection{Description}
A polyhedron (not necessarily is\+\_\+bounded polyhedral set) described by a system of linear inequalities. 

The set is described as $ \{ x\in\mathbb{R}^d \mid Ax \leq b \} $ where $A$ is a $n\times d$ matrix and $b$ is a vector of size $n$. Inheritance diagram for Polyhedron\+:\begin{figure}[H]
