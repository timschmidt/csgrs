class Ariadne\+::\+Function\+Model$<$ P, SIG, PR, PRE $>$}
Generic class representing approximations to functions on bounded domains. 


\begin{DoxyTemplParams}{Template Parameters}
{\em P} & The information paradigm tag, which can be either \doxylink{structAriadne_1_1ValidatedTag}{Validated\+Tag}, indicating that the approximation has a known (uniform) error bound, or \doxylink{structAriadne_1_1ApproximateTag}{Approximate\+Tag}, indicating that no error bound is available. See the \doxylink{group__InformationSubModule}{Information} for more details. \\
\hline
{\em SIG} & The signature, which has the standard C++ form RES(\+ARG), so signature Real(\+Real\+Vector) indicates a function $f:\R^n\to\R$. See \doxysectlink{group__FunctionModule_function_signature_section}{Function signatures}{2} for more details. \\
\hline
{\em PR} & The precision used for numerical values within the approximation. \\
\hline
{\em PRE} & The precision used for error bounds provided for the approximation. \\
\hline
