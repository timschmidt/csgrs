\subsubsection*{template$<$class T$>$\newline
class Ariadne\+::\+Space$<$ T $>$}
A space defined as a list of named variables of type {\itshape T}. Allows conversion between the indexed space {\itshape T\textsuperscript{n}} and the space {\itshape T\textsuperscript{V}} defined by named variables {\itshape V}. 

Ariadne\textquotesingle{}s main computational functionality is based around Euclidean space $\R^n$. However, it is more convenient to define sets and functions symbolically in terms of named variables. A \doxylink{classAriadne_1_1Space}{Space$<$\+Real$>$} provides an ordering of variables which allows conversion between the two kinds of representation.

The main conversion allowed is between \doxylink{classAriadne_1_1Valuation}{Valuation} of type {\itshape T\textsuperscript{V}} for a set of {\itshape n} variables {\itshape V}, and a \doxylink{classAriadne_1_1Vector}{Vector} or type {\itshape T\textsuperscript{n}}. It also allows conversion between sets defined in terms of named variables and those defined in terms of numbered indices, such as \doxylink{classAriadne_1_1VariablesBox}{Variables\+Box} and \doxylink{classAriadne_1_1Box}{Box}. In general, the conversion operations are provided by the symbolic class.
