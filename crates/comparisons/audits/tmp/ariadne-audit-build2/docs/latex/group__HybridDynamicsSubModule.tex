The way trajectories of the flow $\phi(x_0,t)$ of $\frac{dx}{dt}=f(x)$ cross the guard set $g(x)=0$. The rate of change of the guard function changes along flow lines is given by $d g(x(t))/dt = L_{f}g(x(t))$ where the Lie derivative $L_{f}g$ is defined by $L_{f}g(x) = (\nabla g\cdot f)(x)$.

The kind of step taken in the evolution. Determines how the evolution time is specified. 

Assumes that the starting set and time is given as a subset of $\{ \xi(s); \tau(s) \mid s\in D\}$ where $s\in D$ is a parameter, $x=\xi(s)$ is the state corresponding to parameter $s$, and $t=\tau(s)$ is the time the point has so far been evolved for. Assumes that the flow is given by a function $x\textnormal{\textquotesingle}=\phi(x,t)$, typically only defined over a bounded set of space and time. \begin{DoxySeeAlso}{See also}
