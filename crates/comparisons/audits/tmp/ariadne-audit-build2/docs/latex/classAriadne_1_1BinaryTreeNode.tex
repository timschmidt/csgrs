\doxysubsubsection{Description}
The binary tree node. 

This node is to be used in a binary tree designed for subdividing the state space into enabled and disabled cells. This is required for representing subsets of the state space.

{\bfseries{\doxylink{classAriadne_1_1Storage}{Storage}\+:}} We only store pointers to the left and right subtrees and the \doxylink{classAriadne_1_1ValidatedKleenean}{Validated\+Kleenean} value indicating whether this cell is enabled/disabled or we do not know. \doxysubsubsubsection*{Public Member Functions}
