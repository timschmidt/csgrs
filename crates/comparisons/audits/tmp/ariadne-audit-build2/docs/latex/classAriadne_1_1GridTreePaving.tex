\doxysubsubsection{Description}
The Grid\+Tree\+Paving class represents a set of cells with mixed integer and dyadic coordinates. The cells can be enabled or disabled (on/off), indicating whether they belong to the paving or not. It is possible to have cells that are neither on nor off, indicating that they have enabled and disabled sub cells. 

A trivial cell (level 0) of the paving corresponds to a unit hypercube, of the n-\/dimensional state space. Subdivision of any 0-\/level paving is based on dyadic numbers and thus is a binary-\/style partitioning of the cell. All cells with purely integer coordinates are enclosed in a (virtual) binary tree. We illustrate this for a two dimensional case\+:
\begin{DoxyEnumerate}
\item Take the unit cell \mbox{[}0, 0\mbox{]}\texorpdfstring{$\ast$}{*}\mbox{[}1, 1\mbox{]},
\item Cells \mbox{[}-\/1, 0\mbox{]}\texorpdfstring{$\ast$}{*}\mbox{[}0, 1\mbox{]} and \mbox{[}0, 0\mbox{]}\texorpdfstring{$\ast$}{*}\mbox{[}1, 1\mbox{]} are rooted to \mbox{[}-\/1, 0\mbox{]}\texorpdfstring{$\ast$}{*}\mbox{[}1, 1\mbox{]},
\item Cells \mbox{[}-\/1, -\/1\mbox{]}\texorpdfstring{$\ast$}{*}\mbox{[}0, 0\mbox{]} and \mbox{[}0, -\/1\mbox{]}\texorpdfstring{$\ast$}{*}\mbox{[}1, 0\mbox{]} are rooted to \mbox{[}-\/1, -\/1\mbox{]}\texorpdfstring{$\ast$}{*}\mbox{[}1, 0\mbox{]},
\item Cells \mbox{[}-\/1, -\/1\mbox{]}\texorpdfstring{$\ast$}{*}\mbox{[}1, 0\mbox{]} and \mbox{[}-\/1, 0\mbox{]}\texorpdfstring{$\ast$}{*}\mbox{[}1, 1\mbox{]} are rooted to \mbox{[}-\/1, -\/1\mbox{]}\texorpdfstring{$\ast$}{*}\mbox{[}1, 1\mbox{]}.
\end{DoxyEnumerate}

Adjoin an outer approximation to a given set, computing to the given resolution. This method computes an outer approximation for the set {\itshape the\+Set} on the grid {\itshape the\+Grid}. Note that, the depth is the total number of subdivisions (in all dimensions) of the unit cell of the grid. This method does the followig\+: 


\begin{DoxyEnumerate}
\item Computes the smallest Primary cell enclosing {\itshape the\+Set} 
\item Allocates the paving for this cell
\item Minces the paving to the level\+: depth + \texorpdfstring{$<$}{<}the primary cell extent\texorpdfstring{$>$}{>}
\item Iterates through the enabled leaf nodes of the paving (all the nodes are initially enabled)
\item Disables the cells that are disjoint with the {\itshape the\+Set} 
\end{DoxyEnumerate}
