\doxysubsubsection{System Module }
\hypertarget{group__SystemModule}{}\label{group__SystemModule}\index{System Module@{System Module}}


\doxysubsubsubsection{Description}
\doxylink{classAriadne_1_1Concepts_1_1Abstract}{Abstract} base classes for system interface, and some commonly used systems. 

Systems fall into three basic classes, namely {\itshape discrete-\/time systems}, {\itshape continuous-\/time systems}, and {\itshape hybrid-\/time systems}, which are a combination of dicrete-\/time and hybrid-\/time systems. There is a further subdivision into {\itshape dynamical systems}, which are deterministic, {\itshape multivalued systems}, which are nondeterministic, and {\itshape control systems} in which control inputs and noise may be present.

A system is defined by an algorithm to approximate the image of a basic set, and possibly to approximate the derivative over a basic set. It is {\itshape not} the purpose of the classes in the system module to compute the image of denotable sets; this is the purpose of the Evaluation module.
