\doxysubsubsection{Description}
An abstract cell of a grid paving. This class is the base of the \doxylink{classAriadne_1_1GridCell}{Grid\+Cell} -\/ a regular cell on the \doxylink{classAriadne_1_1Grid}{Grid} and the \doxylink{classAriadne_1_1GridOpenCell}{Grid\+Open\+Cell} -\/ an open cell on a \doxylink{classAriadne_1_1Grid}{Grid}. Here we only store common data and operations. 

This class contains the geometric data of a cell, as well as the combinatoric data needed to easily adjoin it to a tree. It does not contain the tree structure, so cannot be used in cursors/iterators. NOTE\+: The "{}\+Primary root cell"{} is the cell that the {\itshape Grid\+Tree\+Set} can be rooted to (the {\itshape Grid\+Tree\+Subset} can be rooted to a non primary cell). The cell size is always double the size of the previous-\/level cell and one of the corners stays the same as well. If Li, Ri are the left-\/, right-\/corned coordinates at livel i then we have the following recursive definition\+: L0 = 0, R0 = 0 Li = 2\texorpdfstring{$\ast$}{*}L(i-\/1) -\/ R(i-\/1) (if i is odd) Li = L(i-\/1) (if i is even) Ri = R(i-\/1) (if i is odd) Ri = 2\texorpdfstring{$\ast$}{*}R(i-\/1) -\/ L(i-\/1) (if i is even)

WARNING\+: The returned box must be interptered relative to some grid. In other words, we assume some lattice and the relation to the original space is not taken into account.

Here {\itshape the\+Extent} defines the height of the primary cell above the zero level and {\itshape dimensions} is the number of dimension in the considered space
