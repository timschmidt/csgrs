Compute the flow polynomial from the vector field {\itshape f}, with order {\itshape d}. 

For a polynomial $p(x,t)$, the flow $\phi(x,t)$ is the solution of the differential equation $\dot{\phi}(x,t) = p(\phi(x,t),t)$ with $\phi(x,0)=x$.
