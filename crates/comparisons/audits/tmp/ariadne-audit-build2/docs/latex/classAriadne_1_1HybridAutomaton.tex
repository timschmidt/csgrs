\doxysubsubsection{Description}
A hybrid automaton, comprising continuous-\/time behaviour at each discrete mode, coupled by instantaneous discrete transitions. The state space is given by a hybrid set. 

A hybrid automaton is a dynamic system with evolution in both continuous time and discrete time. The state space is a product $X=\bigcup\{q\}\times X_q$ where $q$ is the {\itshape discrete state} and $X_q$ is the {\itshape continuous state space} of corresponding to each discrete state.

For each Discrete\+Mode, the dynamics is given by a Vector\+Field describing the continuous dynamics, and a Set giving an invariants which must be satisified at all times.

The discrete time behaviour is specified by Discrete\+Transition objects. Each discrete transition represents an jump from a {\itshape source} mode to a {\itshape target} mode. There can be at most one discrete transition in an automaton with the same event and source.

A discrete transision can either be {\itshape urgent} or {\itshape permissive}. An urgent transition much occur as soon as it is activated. A permissive transition may occur at any time it is activated, but is only forced to occur if the continuous evolution is blocked by an invariant. An urgent transistion may not have an activation condition defined elsewhere, even if this is permissive.
