Python Module Demonstrations

On this page, we illustrate how to use Ariadne via the Python interface. The focus is on the syntax used (which may be different from the C++ syntax) and not on how to use Ariadne to solve problems, for which examples can be found on the Tutorial on Rigorous Numerics and Computable Analysis page and the Python Module Tutorials page.

First, a brief overview of the numerical types and linear algebra operations are given in the Numerical Types and Linear Algebra sections. A guide to the nonlinear functions available is given in Function Calculus, including a guide to the use of polynomial function calculus in Taylor Function Calculus. A guide to working with sets and geometry is given in Sets and Geometry. Solving algebraic and differential equations, and optimisation problems is handled in Solvers for Algebraic and Differential Equations.

The full code of the demonstrations are given in the following files in the python/tutorials/ directory: numeric_demonstration.py, algebra_demonstration.py, function_demonstration.py, geometry_demonstration.py and solver_demonstration.py.

Links are given to the main classes used in the demonstrations. The documentation for these classes is automatically generated from comments in the C++ code. To help Python users unfamiliar with C++ understand this documentation, a guide on the main differences between C++ and Python can be found on the Python Interface page.

The Ariadne module.

First, import the Ariadne module. For ease-of-use, the from version of import is recommended:

from pyariadne import *

To see all the classes and functions available in Ariadne, type:

print(dir(ariadne))

Numerical Types

The full code of this demonstration is given in the file python/tutorials/numeric_demonstration.py.

Ariadne supports several basic numerical types, including core Natural, Integer, Dyadic, Decimal, Rational and Real classes, which store numbers exactly. These number types are good for problem specification, but may be inefficient for actual numerical computations.

The Integer class supports integers of arbitrary size.

0 z=Integer(5)

The Dyadic class supports numbers of the form \(p/2^q\) where \(p\) and \(q\) are integers; equivalently, numbers with a terminating binary expansion. These include all numbers of binary floating-point types and are useful as computational intermediates.

41 w=Dyadic(z)
42 w=Dyadic(5)
43 w=Dyadic(11,3) # Constructs the number 11/2^3=11/8
44 w=11/two**3 # Alternative syntax for 11/2^3

The Decimal class supports exact representation of decimal numbers. Numbers can be constructed from floating-point values up to around 9 decimal places; for more accuracy a string literal must be used:

45 g=Decimal(w)
49 g=Decimal(9.81)
50 g=Decimal("9.81")

The Rational class supports exact representation of rational numbers.

51 q=Rational(w);
55 q=Rational(5);
56 q=Rational(11,8);

The Real number class represents general real numbers

57 r=Real(q)

All numeric classes support standard arithmetical operators

61 +r; -r; r+r; r-r; r*r; r/r

named versions of these arithmetical operations,

67 pos(r); neg(r); # add(r,r); sub(r,r); mul(r,r); div(r,r);

and other arithmetical operations, including halving hlf and reciprocal rec.

69 nul(r); sqr(r); hlf(r); rec(r); pow(r,-3)

elementary functions (root, exponential, logarithm and trigonometric)

71 sqrt(r); exp(r); log(r); sin(r); cos(r); tan(r); atan(r)

lattice operations

73 abs(r); max(r,r); min(r,r)

comparisons

75 k=(r<=r)

and the distance function

77 dist(r,r)

A full list of these operations is given in the list of supported operations.

Floating-point numbers

Computations in Ariadne are usually most efficiently performed using floating-point number types. Ariadne internally supports the FloatDP and FloatMP types, which are respectively based on builtin IEEE double-precision floating-point numbers, and multiple-precision floating-point numbers from the MPFR library.

Since Python's builtin float class uses rounded arithmetic, such numbers may not be an exact representation of a value, leading to unsafe computation. If a Python float is indeed an exact value, (e.g. 1.375 is an exact double-precision floating-point number), this must first be converted to an Ariadne ExactDouble class:

79 d=ExactDouble(1.375)
83 d=cast_exact(1.375)

Numbers which are not exactly representable in double-precision should be converted to the Decimal class instead.

Ariadne uses C++/Python's built-in floating-point types to provide a double-precision floating-point number class FloatDP, and the MPFR library to provide a multiple-precision floating-point type FloatMP. Each type has a corresponding precision:

84 dp=DoublePrecision()
101 dp=double_precision
102 mp=MultiplePrecision(128)

Floating-point numbers can be constructed from integers and dyadic numbers by supplying the precision:

103 xdp=FloatDP(exact(1.75),dp)
106 xmp=FloatMP(exact(1.75),mp)

Raw floating-point numbers only support rounded arithmetic, so are best avoided in user code. Instead, they can be used in safe correctly-rounded generic types Value<F>, Ball<F,FE>, Bounds<F>, UpperBound<F>, LowerBound<F> and Approximation<F>. In Python, this template parameter is appended to the class name, so FloatDPBounds is the Python name for Bounds<FloatDP>, and FloatMPBounds is the name for Bounds<FloatMP>.

For example, the Bounds classes support outward-rounded interval arithmetic

110 xdpb=FloatDPBounds(Decimal(1.2),dp) # Creates the interval [1.19999999999999996:1.20000000000000018]
114 xdpb=FloatDPBounds(Rational(11,10),Rational(14,10),dp) # Creates the interval [1.09999999999999987:1.40000000000000013]
123 xmpb=FloatMPBounds(dec("1.2"),mp) # Creates the interval [1.19999999999999996:19999999999999996]
127 xmpb=FloatMPBounds(dec(1.5),dec(2.25),mp) # Creates the interval [1.5,2.25]
131 xmpb=FloatMPBounds(Rational(11,10),Rational(14,10),mp) # Creates the interval [1.10000000000000009:1.39999999999999991]

and the Approximation classes support approximate arithmetic.

135 xdpa=FloatDPApproximation(1.23,dp)
139 xmpa=FloatMPApproximation(1.23,mp)
147 xmpa=FloatMPApproximation(Decimal("1.23"),mp)

Linear Algebra

Ariadne supports linear algebra operations based on Vector and Matrix classes. In the C++ library, these types are parameterised by the scalar type (e.g. Rational, FloatDPBounds). In Python, this gives class names such as RationalVector and FloatDPBoundsMatrix.

Vector and matrix classes can be constructed using Python lists.

0 bq=RationalVector([1,q_(2.4),Rational(31,8)])
32 Aq=RationalMatrix([[1,2,4],[3,q_(1.5),2],[0,0,1]])
37 Aq=Matrix[Rational]([[1,2,4],[3,q_(1.5),2],[0,-1,1]])

As well as matrix and vector arithmetic, Ariadne provides a solve routine for solving systems of linear equations:

38 xq=solve(Aq,bq)

Function Calculus

Ariadne's Function class supports nonlinear functions by means of templated abstract classes, with template parameters indicating the argument and result times. These include EffectiveScalarMultivariateFunction for scalar functions \(f:\R^m\rightarrow\R\)

0 x=[EffectiveScalarMultivariateFunction.coordinate(2,index) for index in range(0,2)]
32 sf=sqrt(sqr(x[0])+sqr(x[1]))
33 sfa=sf(a)
36 sfb=sf(b)

and the EffectiveVectorMultivariateFunction for functions \(f:\R^m\rightarrow\R^n\).

39 x=EffectiveVectorMultivariateFunction.identity(3)
42 vf=EffectiveVectorMultivariateFunction([sqrt(sqr(x[0])+sqr(x[1])),x[1]+x[2]])
43 vfa=vf(a)
46 vfb=evaluate(vf,b)

and functions of a scalar argument EffectiveScalarUnivariateFunction for functions \(f:\R\rightarrow\R\), EffectiveVectorUnivariateFunction for \(f:\R\rightarrow\R^n\).

These functions can be differentiated with respect to their coordinates.

49 dsf0=derivative(sf,0);

The Polynomial<X> class provides concrete implementations of the function calculus. For example, FloatDPApproximationMultivariatePolynomial class defines a polynomial in multiple variables with coefficients of type FloatDPApproximation. A polynomial can be created by using the coordinate(n,j) static method, which creates the polynomial \(p(x)=x_j\) for \(x\in\R^n\):

52 p0=FloatDPApproximationMultivariatePolynomial.coordinate(2,0,dp);
55 p1=FloatDPApproximationMultivariatePolynomial.coordinate(2,1,dp);

The standard arithmetical operations are available for polynomial expressions:

56 q=p0*(p0+p1*a3)+a5

Taylor Function Calculus

The generic function interfaces cannot generally be directly manipulated. Instead, they can be converted to numerical ValidatedScalarMultivariateTaylorFunctionModelDP and ValidatedVectorMultivariateTaylorFunctionModelDP types which can then be worked with.

The core type is a ScalarMultivariateTaylorFunctionModel<P,F>, which is a polynomial p precomposed by a scaling s-1 of a function f on a box D in Euclidean space with uniform error e: \( f(x) = p(s^{-1}(x))\pm e \text{ for } x\in D . \)

To construct a Taylor function model, we need to give the domain and a "sweeper" which controls the accuracy.

60 dom=BoxDomainType([{4:7},{1:6},{-1:+1}])
69 swp=ThresholdSweeperDP(dp,1e-8)

Constant and coordinated functions can easily be created

73 tc=ValidatedScalarMultivariateTaylorFunctionModelDP.constant(dom,dec_(4.2),swp)
78 t1=ValidatedScalarMultivariateTaylorFunctionModelDP.coordinate(dom,1,swp)

and a general function can be converted to a Taylor function model

82 p=EffectiveScalarMultivariateFunction.coordinate(3,0)
100 tp=ValidatedScalarMultivariateTaylorFunctionModelDP(dom,p,swp)

We can extract the domain of the functions, and over-approximations to the codomain/range

101 print("tx.domain():",tx.domain())
106 print("tx.codomain():",tx.codomain())
108 print("tx.range():",tx.range())

Taylor function models support arithmetic

110 +tx; -tx; tx+ty; tx-ty; tx*ty; tx/ty;

and mixed arithmetic with numerical types

118 tx+c; tx-c; tx*c; tx/c;
121 c+tx; c-tx; c*tx; c/tx;

They also support lattice operations,

122 min(tx,ty); max(tx,ty); abs(tx);

standard named arithmetical operations,

128 neg(tx);
131 rec(tx);
132 sqr(tx);
133 pow(tx,n);

and roots, exponentials, logarithms and trigonometric functions

134 sqrt(tx);
137 exp(tx); log(tx);
138 sin(tx), cos(tx), tan(tx/2)

In-place operations are also provided

139 tx+=ty; tx-=ty;
142 tx+=c; tx-=c; tx*=c; tx/=c;

We can compute antiderivatives (indefinite integrals) with respect to the coordinates

143 Itf0=antiderivative(tf,0)

specifying an optional base-point

153 Itf1=antiderivative(tf,1,c)

For higher accuracy, the approximation can be restricted to a subdomain

155 rw=restriction(w,subdom)

Standard function operations are provided, including direct sum (join) \(x\mapsto[f(x),g(x)]\) and product (combine) \([x,y]\mapsto[f(x),g(y)]\).

162 tfg=join(tf,tg)
167 tfg=combine(tf,tg)

Taylor function models can be post-composition by a generic function

171 fth=compose(f,th)
186 gth=compose(g,th)

or composed with another Taylor function model

190 tfh=compose(tf,th)
195 tgh=compose(tg,th)

Since Taylor function models provide a set of possibilities for the actual function, we can test whether two computations are inconsistent (disjoint) or if one refines another, and compute the common refinement

200 ic=inconsistent(tf1,tf2)
210 rf=refines(tf1,tf2)
212 tf=refinement(tf1,tf2)

Sets and Geometry

Ariadne supports a Interval<UB> class with different types for the endpoints, such as RationalInterval and FloatDPUpperInterval, the latter being Interval<FloatDPUpperBound>.

0 ivlq = RationalInterval(Rational(4,7),Rational(3,5))
32 ivlu = FloatDPUpperInterval({exact(1.5):exact(2.5)})

A Box is the Cartesian product of intervals, and can be created from a list of intervals

35 bx = RealBox([ [Rational(4,7),Rational(3,5)] , {exact(1.5):exact(2.5)} ])

Standard geometric predicates are supported

41 subset({2:3},{1:4})
46 disjoint({2:3},{4:5})

Sets can also be defined based on constraints, such as ConstraintSet.

47 cs = ConstraintSet([sqr(x)+2*sqr(y)<=1,3*x+2*y>=1])

The intersections of a box and a set based on constraints is guaranteed to be bounded, with type BoundedConstraintSet

52 # Compute the intersection of a contraint set with a box, obtaining a bounded set
56 bcs = intersection(bx,cs)

and we can compute its image under a continuous function yielding a ConstrainedImageSet.

57 # Compute the image of a bounded contraint set under a continuous function
60 cis = image(bcs,h)

Sets can be discretised on a grid to obtain a GridTreePaving comprised of GridCell objects.

62 gtp = outer_approximation(cis,g,dpth)

The projection onto a two-dimensional coordinate space can be plotted

68 plot("geometry_demonstration", prj, wnd, [(green,cis)])

Solvers for Algebraic and Differential Equations

Ariadne uses Solver classes for complicated operations such as solving algebraic or differential equations.

Solving Algebraic Equations

We can solve parameterised algebraic equations using the operator implicit of a Solver class, such as IntervalNewtonSolver or KrawczykSolver/ If \(f:D_1\times D_2\rightarrow \R^n\) with \(D_2\subset\R^n\) then the operator implicit(f) attempts to compute a function \(h:D_1\to\R^n\) such that \(f(x,h(x))=0\) for \(x\in D_m\). The function \(h\) must satisfy \(h(D_1)\subset D_2\).

0 slv=IntervalNewtonSolver(1e-8,6)
32 f=join(x+4*y0+y1,y0+y1)
37 hf=slv.implicit(f,BoxDomainType([{-1:+1}]),BoxDomainType([{-1:+1},{-1:+1}]))
39 g=x-4*y+y*y
47 hg=slv.implicit(g, BoxDomainType([{-1:+1}]),IntervalDomainType({-1:+1}))

Solving Differential Equations

We can solve differential equations using the operator flow of an Integrator class, such as TaylorPicardIntegrator or GradedTaylorSeriesIntegrator. If \(:\R^n\to\R^n\), \(D\subset\R^n\) and \(h>0\), then the operator flow(f,D,h) computes a function \(\phi:D\times[0,h]\to\R^n\) satisfying \(\dot{\phi}(x,t)=f(\phi(x,t))\) and \(\phi(x,0)=x\).

49 integrator=GradedTaylorSeriesIntegrator(1e-8)
58 f=ValidatedVectorMultivariateFunction.identity(1)
63 phi=integrator.flow(f,dom,h)
