Description

template<class X>
class Ariadne::Approximation< X >

Floating point number approximations to real numbers supporting approxiamate arithmetic.

The Approximation<F> class represents approximate floating-point numbers. Operations are performed approximately, with no guarantees on the output.

See also
Real, NaiveReal, FloatDP, FloatMP, Float, Ball, Bounds.
