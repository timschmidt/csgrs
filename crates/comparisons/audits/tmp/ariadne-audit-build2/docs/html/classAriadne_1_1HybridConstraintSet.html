HybridConstraintSet Class Reference
Hybrid System Modules » Hybrid sets

#include <hybrid_expression_set.hpp>

Description

A hybrid set defined by a constraint system in each location. NOTE: If a location is not specified, the set is considered empty. This may be changed in future to the set being considered unconstrained (entire).
