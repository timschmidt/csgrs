Description

template<class P, class SIG, class PR = Void, class PRE = PR>
class Ariadne::FunctionModel< P, SIG, PR, PRE >

Generic class representing approximations to functions on bounded domains.

Template Parameters
PThe information paradigm tag, which can be either ValidatedTag, indicating that the approximation has a known (uniform) error bound, or ApproximateTag, indicating that no error bound is available. See the Information for more details.
SIGThe signature, which has the standard C++ form RES(ARG), so signature Real(RealVector) indicates a function \(f:\R^n\to\R\). See Function signatures for more details.
PRThe precision used for numerical values within the approximation.
PREThe precision used for error bounds provided for the approximation.

Note:

It is planned to change the precision paramters PR and PRE to the actual number types used.
