#include <solver_interface.hpp>

Description

Interface for solving (nonlinear) equations.

Two main kinds of problem are considered. The problem of finding roots of a function \( f \), which are solutions to the equation \(f(x)=0\), is addressed by the solve() method, The problem of finding a function \( h \) such that \( f(x,h(x))=0 \) is addressed by the implicit() method.

Additionally two parameters are defined which are applicable to any implementation. The maximum_error() provides an upper bound on the size of a box containing a solution point, uniforma bounds for an implicit function. The maximum_number_of_steps() provides a timeout mechanism.

virtual Vector< ValidatedNumericType > solve ( const ValidatedVectorMultivariateFunction & f,
const ExactBoxType & bx ) const
pure virtual

Solve \(f(x)=0\), starting in the box bx. Throws a SolverException if a unique solution is not found.

Parameters
fA function \(\R^n\to\R^n\) for which the root \(p\) is to be found.
bxA coordinate-aligned box \(B\) in \(\R^n\) for which the root is to be found.

A root \(p\) of \(f\) is transverse if the Jacobian derivative matrix \(Df(p)\) is nonsingular. The solution method should converge to a transverse root \(p\) if the box \(B\) contains \(p\) in its interior, and is sufficiently small.

The choice of box in which to search is to be determined by the user. If the box is too big, then the solution typically fails. The semantics of the method requires that there be a uniqure root in the box, and many algorithms also require the Jacobian derivative matrix \(Df(x)\) to be nonsingular over the entire box. The Jacobian derivative is nonsingular over a sufficiently small neighbourhood of a transverse root. However, choosing too small a box may also cause the algorithm to fail if the root is too close to the boundary.

The solve_all() method is an algorithm which attempts to find all roots.

Implemented in SolverBase.

virtual ValidatedVectorMultivariateFunctionPatch implicit ( const ValidatedVectorMultivariateFunction & f,
const ExactBoxType & A,
const ExactBoxType & X ) const
pure virtual

Solve \(f(a,x)=0\) for \(a\) in \(A\), looking for a solution with \(x\) in \(X\). The result is a function \(h\) with domain \(A\) such that \(f(a,h(a))=0\) for all \(a\in A\).

Parameters
fA function \(\R^{m+n}\to\R^n\).
AA subset of \(\R^m\) giving the required domain of the solution function \(h\).
XA subset of \(\R^n\) giving a codomain of \(h\) i.e. \(h\) satisfies \(h(a)\in X\) for all \(a\in A\).
Warning
If the domain A is too large, there may not be a continuous solution over it. If the codomain X is too small, then there may not be a solution within it, but if it is too large, there may not be a unique solution, and some solvers may have problems with the first few steps of the solution.

A strong solution to the problem exists if for every \(a\in A\), there is a unique solution \(x\in X\) to the equation \(f(a,x)=0\), and this solution varies continuously in \(a\). A weak solution is a function \(h\) with domain \(A\) such that \(f(a,h(a))=0\) for all \(a\in A\), if \(f(a,x)=0\) for \(x\in X\) then \(h(a)=x\), and there exists \((a,x)\in A\times X\) such that \(f(a,x)=0\). If \(D_2f(a,x)\) is nonsingular for all \((a,x)\in A\times X\), then any solution is guaranteed to be unique. May throw a NoSolutionException, but only if there are no solutions to \(f(a,x)=0\) in \(A\times X\). If there is a continuous branch of solutions \(x=h(a)\) such that \(h(a)\in X\) for some parameter values, but \(h(a)\not\in X\) for others, then \(h\) is a valid result for the function.

Implemented in IntervalNewtonSolver, and SolverBase.
