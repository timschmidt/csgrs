Neural Networks

In this tutorial, we'll look at the analysis of a simple neural network with a single hidden layer. We will use two input variables, three hidden nodes, and a single output variable, and take a sigmoid activation function.

Before starting, let's take a look at the documentation for the C++ Function<P,SIG> class. The class has two template parameters, the information or computational paradigm parameter P, which was explained in the Information, and a signature parameter SIG, which is explained in Function signatures.

Hence the C++ template instantiation Function<EffectiveTag,RealVector(Real)> has Python name EffectiveVectorUnivariateFunction. This name is also a C++ type alias, so can also be used in C++ code.

Symbolic Functions

We first create the activation function \(\sigma(y)=1/(1+e^{-y})\). Since the function has a single argument, and returns a single result, it is a ScalarUnivariateFunction. Since it is exactly specified and can be evaluated arbitrarily accurately, it is Effective. Hence the Python class name is EffectiveScalarUnivariateFunction. (The C++ template class is Function<EffectiveTag,Real(Real)>.)

There are two main ways of doing this. We show how to define \(\sigma\) in terms of the identity function \(\mathrm{id}(y)=y\):

0 #! Create activation function from the identity function
33 y=EffectiveScalarUnivariateFunction.identity()
34 sigma=1/(1+exp(-y))

As a slightly more efficient alternative to \(1/x\), we can use Ariadne's builtin reciprocal function rec:

35 sigma=rec(1+exp(-y))

Alternatively, we can define \(\sigma\) in terms of a variable \(y\). Using \(\lambda\)-calculus syntax \(\sigma=\lambda{y}.1/(1+e^{y})\) (in pure Python we would write lambda y : 1/(1+exp(-y)) ) we have:

36 y=Variable[Real]("y")
39 sigma=make_function(y,rec(1+exp(-y)))

We next create the functions representing the layers.

The first layer is a function which takes two input arguments, \(x_{0,0}\) and \(x_{0,1}\), and returns three output arguments, \(x_{1,0},x_{1,1},x_{1,2}\). Hence the function is an EffectiveVectorMultivariateFunction, To define the layer, we use a matrix \(A_0\) and vector \(b_0\), taking \(x_{1,i} = \sigma(\sum_{j=0}^{1}A_{0;i,j}x_j+b_{0;i})\). We define the coefficient matrix and bias vector:

40 A0=Matrix[Real]([[dec_(0.884),dec_(-1.097)],[dec_(1.586),dec_(0.380)],[dec_(-0.005),dec_(0.677)]])
45 b0=Vector[Real]([dec_(-0.127),dec_(2.747),dec_(0.378)])

Note that the non-integer numbers must be prefixed with the modifier dec_, which indicates that the writted values should be interpreted exactly as decimal numbers.

Then define the function \(f_0\) in terms of the identity function on the two coordinates \(x_{0,0}\) and \(x_{0,1}\).

46 x0=EffectiveVectorMultivariateFunction.identity(2)
49 f0=EffectiveVectorMultivariateFunction([compose(sigma,A0[0,0]*x0[0]+A0[0,1]*x0[1]+b0[0]),
50 compose(sigma,A0[1,0]*x0[0]+A0[1,1]*x0[1]+b0[1]),
51 compose(sigma,A0[2,0]*x0[0]+A0[2,1]*x0[1]+b0[2])])

The second layer is a function which takes two input arguments, \(x_{1,0}\), \(x_{1,1}\) and \(x_{1,2}\), and returns a single output \(y=x_2\). Hence the function is an EffectiveScalarMultivaluedFunction, To define the layer, we use a covecter \(A_1\) (a covector is a row-vector, or a matrix with a single row) and scalar \(b_1\), taking \(x_{2} = \sigma(\sum_{j=0}^{2}A_{1;j}x_j+b_{1})\). We define the coefficient covector and bias scalar:

52 A1=RealCovector([dec_(-0.541),dec_(-0.535),dec_(-0.255)])
56 b1=Real(dec_(0.244))

Then define the function \(f_1\) in terms of the identity function on the three coordinates:

57 x1=EffectiveVectorMultivariateFunction.identity(3)
59 f1=EffectiveScalarMultivariateFunction(compose(sigma,A1[0]*x1[0]+A1[1]*x1[1]+A1[2]*x1[2]+b1))

Polynomial function models

The main way of working with functions is to convert to a polynomial approximation. The domain of the approximation must be a bounded set, which we take to be an Interval in the case of Univariate functions, and a coordinate-aligned Box in the case of Multivariate functions.

60 dom=BoxDomainType([[dy_(0.375),dy_(0.5)],[dy_(0.625),dy_(0.75)]])

Note that the non-integer numbers must be prefixed with the modifier dy_, which indicates that the written values should be interpreted exactly as dyadic numbers, which have an finite binary expansion; equivalently can be written as \(p/2^q\) for integers \(p\), \(q\); see the Dyadic class for more details. It is an error to use a non-dyadic number.

Note
The requirement that the bounds of the domain type must be exact dyadic numbers may be dropped in a future release of Ariadne.

To control the accuracy of the approximation, we use a Sweeper class. A general-purpose sweeper is the threshold sweeper ThresholdSweeper, which discards terms of the polynomial if they fall below a certain threshold.

73 swp=ThresholdSweeperDP(double_precision,1e-9)

We can then approximate the model function f over dom. We use a TaylorFunctionModel class, where SIG is the signature, which must match that of the function itsef, and PR is the precision of the floating-point type used in the approximation. Here we need a ScalarMultivariate function, and use double precision, abbreviated DP, and want a Validated approximation with known error bound, so the class name to use is ValidatedScalarMultivariateTaylorFunctionModelDP.

74 model_f=ValidatedScalarMultivariateTaylorFunctionModelDP(dom,f,swp)

We can evaluate \( f \) using either the original function, or the polynomial model.

75 x=Vector[FloatDPBounds]([dy_(0.4375),dy_(0.6875)],dp)
78 print("f(x):",f(x))
79 print("model_f(x):",model_f(x))
