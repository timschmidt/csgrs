#include <hybrid_time.hpp>

Description

A value in a hybrid time domain, being a pair comprising a real continuous_time and an integer discrete_time.

When a HybridTime is used to define a bound on a hybrid evolution, the evolution should stop when either the continuous time or the discrete time reaches the bounding value. This is to ensure that the evolution time is finite; in particular, that no Zeno behaviour occurs.
