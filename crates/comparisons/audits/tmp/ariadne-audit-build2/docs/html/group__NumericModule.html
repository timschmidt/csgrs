Numeric Module
Core Modules

Description

Numerical types, including Natural, Integer, Dyadic, Decimal, Rational and Real types, generic types Number, double/multiple precision floating-point types Float<DP> and Float<MP> (with shorthands FloatDP and FloatMP), and correctly-rounded types Ball<F,FE>, Bounds<F> UpperBound<F>, LowerBound<F> and Approximation<F>.

For the mathematical theory of computability on real numbers, see the Computable Real Numbers Page.

In this module, we define Ariadne's base numerical types, including support for interval arithmetic via balls and bounds. The main concrete algebraic number types are Integer, Dyadic, and Rational. A Decimal number class is provided for user input. The main real number type is Real, with directed versions LowerReal and UpperReal. Generic numbers are defined using the Number templates, with typedefs e.g. EffectiveNumber for Number<EffectiveTag>. Validated and approximate versions of real numbers are given by ValidatedReal and ApproximateReal, and convergent sequences without error bounds by NaiveReal.

Concrete numerical types are defined in terms of the FloatDP and FloatMP floating-point number classes. These support rounded arithmetic and elementary functions using the down and up tags (equivalantly, downward and upward). Rounding to nearest is specified by the near (equivalently, to_nearest) tag. Approximate arithmetic without control of the rounding mode can be specified by the approx rounding type. Comparisons are performed considering these numbers as exact values, and must be decidable. This means that these "raw" floating-point types should not be used directly, but wrapped in one of the validated concrete approximation classes listed below.

Types supporting exact or rounded arithmetic may be used to define (validated) approximations to numbers via the classes Value<F>, Ball<F,FE>, Bounds<F> UpperBound<F>, LowerBound<F> and Approximation<F>.

Note that to prevent accidental calls to approximate functions, all non-exact operations (except explicitly-rounded operations on raw values) must yield an Approximation value.

Positive numbers can be defined using the Positive<X> template. A Natural is a Positive<Integer>.

The following aliases are used for arithmetical operations:

nul(x) is equivalent to 0*x
pos(x) is equivalent to +x
neg(x) is equivalent to -x
sqr(x) is equivalent to x^2, the square operation
hlf(x) is equivalent to x/2
rec(x) is equivalent to 1/x, the reciprocal operation.
add(x,y) is equivalent to x+y
sub(x,y) is equivalent to x-y
mul(x,y) is equivalent to x*y
div(x,y) is equivalent to x/y
pow(x,n) is equivalent to x^n
fma(x,y,z) is equivalent to x*y+z, the fused-multiply-and-add operation.

Note that C++ does not support the power operator ^. In Python, the power operator is denoted **. In Ariadne, only integer exponents n are supported; for general powers use the identity \(x^y=e^{x\log(y)}\) and write exp(y*log(x)).

The following non-arithmetical elementary functions are provided:

sqrt(x), the square-root function \(\sqrt{x}\)
exp(x), the natural exponent \(e^x\)
log(x), the natural logarithm \(\log(x)\) (sometimes written \(\ln(x)\)).
sin(x), the sine function \(\sin(x)\), with argument in radians.
cos(x), the cosine function \(\cos(x)\), with argument in radians.
tan(x), the tangent function \(\tan(x)\), with argument in radians.
atan(x), the inverse tangent function \(\arctan(x)\) or \(\tan^{-1}(x)\), returning princial value in the open interval \((-\pi/2\!:\!+\pi/2)\)

The following lattice operations are provided:

abs(x), the absolute-value \(|x|\)
max(x,y), the maximum \(\max(x,y)\)
min(x,y), the minimum \(\min(x,y)\)

We have the following operations on floating-point types

  • Exact arithmetic where possible:
    Float neg(Float);
    Float abs(Float);
    Float max(Float,Float);
  • Approximate and rounded arithmetic:
    Float add(near,Float,Float);
    Float add(down,Float,Float);
    Float add(up,Float,Float);
  • Arithmetic in the current rounding mode, or opposite rounding mode:
    Float add(rnd,Float,Float);
    Float add(opp,Float,Float);

We use the following abbreviations for template parameters for classes and concepts in this module:

  • Z: Integer
  • W: Dyadic
  • Q: Rational
  • R: Real
  • Y: Generic Number
  • PR: Precision
  • F: Float
  • X: Concrete Number

See the page Computable Real Numbers for more information.
