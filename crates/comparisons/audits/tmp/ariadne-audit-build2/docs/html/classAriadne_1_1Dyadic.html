Dyadic Class Reference
Core Modules » Numeric Module

#include <dyadic.hpp>

Description

A dyadic number of the form \(p/2^q\) for integers \(p\), \(q\); equivalently, a number with a finite binary expansion.

See also
Integer, Decimal, Rational, Float<DP>, Float<MP>

The number \(1.375\) is an example of a dyadic number, since it is equal to \(1.375=11/8=11/2^3=1.101_2\). The number \(0.1375\) is not a dyadic number, since \(0.1375=11/80=11/(2^4\times 5)=0.0010\overline{0011}_2\), so the denominator is not a power of \(2\), and its binary expansion is recurring.
