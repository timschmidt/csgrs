ApproximateKleenean Class Reference

#include <logical.hpp>

Description

A logical class representing a value of an undecidable predicate, either a NaiveKleenean value checked using some Effort, or applied directly to an Approximate object.

Note that definitely() and possibly() always return false and true, respectively.
