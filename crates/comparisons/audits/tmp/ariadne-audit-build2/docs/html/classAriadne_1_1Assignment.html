template<class V, class E>
class Ariadne::Assignment< V, E >

An assignment statement of the form \(v:=e\).

Template Parameters
VThe variable to be assigned to (left-hand-side). May be an extended variable (e.g. dot(v))
EThe expression to be assigned (right-hand-side).
