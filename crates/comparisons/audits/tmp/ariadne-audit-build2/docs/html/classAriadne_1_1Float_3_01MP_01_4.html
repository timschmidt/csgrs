#include <floatmp.hpp>

Description

Multiple-precision floating-point numbers. Abbreviation FloatMP.

Abbreviated form FloatMP. See Float<DP>. Currently defined as a wrapper around mpfr_t from the MPFR library. Default arithmetic operations are approximate, and comparisons are exact, so this class is unsafe.

See also
Float<DP>, Real, FloatBall, FloatBounds, FloatUpperBound, FloatLowerBound, FloatApproximation, FloatError
