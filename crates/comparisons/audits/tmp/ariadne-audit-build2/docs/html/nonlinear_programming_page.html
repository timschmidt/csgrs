Nonlinear Constrained Optimisation Problems

Standard optimisation problem

Consider the nonlinear programming problem

\[ \boxed{ \max f(x) \text{ s.t. } g_j(x)\geq 0,\ j=1,\ldots,l; \ h_k(x) = 0,\ k=1,\ldots,m . } \]

Applying a penalty function yields the unconstrained maximisation of

\[ f(x) + \mu \sum_{j=1}^{l} \log g_j(x) - \frac{1}{2\nu} \sum_{k=1}^{m} (h_k(x) )^2 . \]

Differentiating with respect to \(x\) yields

\[ \nabla_{\!i\,} f(x) + \mu \sum_{j=1}^{l} \frac{\nabla_{\!i\,}g_j(x)}{g_j(x)} - \frac{1}{\nu} \sum_{k=1}^{m} h_k(x)\nabla_{\!i\,}h_k(x) = 0. \]

Setting \(\lambda_j = \mu/g_j(x)\) and \(\kappa_k = - h_k(x)/\nu\) yields

\[ \nabla_{\!i\,} f(x) + \sum_{j=1}^{l} \lambda_j \nabla_{\!i\,}g_j(x) + \sum_{k=1}^{m} \kappa_k\,\nabla_{\!i\,}h_k(x) . \]

Combining these equations yields

\[ \begin{gathered} \nabla f(x) + \sum_{j=1}^{l} \lambda_j \nabla g_j(x) + \sum_{k=1}^{m} \kappa_k \nabla h_k(x) = 0; \\ \lambda_j g_j(x) - \mu = 0; \\ h_k(x) + \nu \kappa_k = 0; \\ \lambda_j \geq 0; \ g_j(x) \geq 0 . \end{gathered} \]

Setting \(\nu=0\) these equations yields the central path for the problem, which is a relaxation of the optimality conditions

\[ \boxed{ \begin{gathered} \nabla f(x) + \sum_{j=1}^{l} \lambda_j \nabla g_j(x) + \sum_{k=1}^{m} \kappa_k \nabla h_k(x) = 0; \\ \lambda_j g_j(x) = \mu; \\ h_k(x) = 0; \\ \lambda_j \geq 0; \ g_j(x) \geq 0 . \end{gathered} } \]

Taking \(\mu\to0\) yields the standard Karush-Kuhn-Tucker conditions for optimality

\[ \boxed{ \begin{gathered} \nabla f(x) + \sum_{j=1}^{l} \lambda_j \nabla g_j(x) + \sum_{k=1}^{m} \kappa_k \nabla h_k(x) = 0; \\ \lambda_j g_j(x) = 0; \\ h_k(x) = 0; \\ \lambda_j \geq 0; \ g_j(x) \geq 0 . \end{gathered} } \]

A Lagrangian for this problem is

\[ \boxed{\displaystyle L(x,\lambda,\kappa) = f(x) + \sum_{j=1}^{l} \lambda_j g_j(x) + \sum_{k=1}^{m} \kappa_k h_k(x) . } \]

The standard Karush-Kuhn-Tucker conditions for optimality are obtained by setting the partial derivatives of \(L\) to zero, with the inequality constraints \(\lambda_j,g_j(x)\geq0\) allowing for the relaxation \(\lambda_j=0 \vee g_j(x)=0\).

The standard (Fritz) John conditions for optimality are

\[ \boxed{ \begin{gathered} \mu \nabla f(x) + \sum_{j=1}^{l} \lambda_j \nabla g_j(x) + \sum_{k=1}^{m} \kappa_k \nabla h_k(x) = 0; \\ \lambda_j g_j(x)=0; \\ h_k(x)=0; \\ \mu + \sum_j \lambda_j + \sum_k \kappa_k^2 = 0; \\ \lambda_j \geq 0; \ g_j(x) \geq 0 . \end{gathered} } \]

Note
Taking \(f(x) = -cx\), \(g(x)=-x\) and \(h(x)=Ax-b\) yields the primal linear programming problem \(\min cx \mid Ax=b,\ x\geq 0\). Taking \(f(y)=yb\), \(g(y) = yA-c\) yields the dual linear programming problem \(\max yb \mid yA\leq c\). This means that the standard primal nonlinear programming problem with only affine inequality constraints more closely resembles the dual linear programming problem. Despite this, we shall use x for the primal variables of the standard primal nonlinear programming problem.

Inequality constrained optimisation problem

Consider the problem

\[ \max f(x) \text{ s.t. } g(x) \geq 0 . \]

The central path is defined by

\[ \boxed{ \begin{gathered} \nabla f(x) + \lambda \cdot \nabla g(x) = 0; \\ \lambda g(x) = \mu; \\ \lambda \geq 0,\ g(x) \geq 0. \end{gathered} } \]

Taking \(\mu\to 0\), we obtain the standard Karush-Kuhn-Tucker conditions.

\[ \boxed{ \begin{gathered} \nabla f(x) + \lambda \cdot \nabla g(x) = 0; \\ \lambda g(x) = 0; \\ \lambda \geq 0,\ g(x) \geq 0. \end{gathered} } \]

Equality constrained optimisation problem

Consider the problem

\[ \max f(x) \text{ s.t. } h(x) = 0 . \]

The central path is defined by

\[ \boxed{ \begin{gathered} \nabla f(x) + \kappa \cdot \nabla h(x) = 0; \\ h(x) + \kappa \mu = 0. \end{gathered} } \]

The Karush-Kuhn-Tucker optimality conditions are

\[ \boxed{ \begin{gathered} \nabla f(x) + \kappa \cdot \nabla h(x) = 0; \\ h(x) = 0. \end{gathered} } \]

The problem can be relaxed by adding the penalty function \(-g(x)^2/2\mu\). Then the optimality conditions are

\[ \nabla f(x) - \frac{g(x)}{\mu} \nabla g(x) = 0\]

Taking Lagrange multiplier \(\lambda = g(x)/\mu\), we obtain

\[ \boxed{ \begin{gathered} \nabla f(x) - \lambda \nabla g(x) = 0; \\ g(x) - \lambda \mu = 0 \end{gathered} } \]

which relaxes to \(g(x)=0\) as \(\mu\to0\).

Bounded constraints

Consider the problem

\[ \max f(x) \text{ s.t. } |g(x)| \leq \delta \]

We can handle the problem in two ways; either by considering the smooth constraint \(\delta^2-g(x)^2\geq0\) or the two constraints \(\delta + g(x) \geq 0\) and \(\delta - g(x)\geq 0\).

In the former case, we obtain the conditions

\[ \begin{gathered} \nabla f(x) + 2 \lambda g(x) \nabla g(x) = 0; \\ \lambda (\delta^2 - g(x)^2) = \mu. \end{gathered} \]

Replacing the standard Lagrange multiplier \(\lambda\) with \(-2\lambda g(x)\), we obtain

\[ \begin{gathered} \nabla f(x) - \lambda \nabla g(x) = 0; \\ -\lambda (\delta^2 - g(x)^2) / 2g(x) = \mu. \end{gathered} \]

Rearranging the second formula gives

\[ \boxed{ \begin{gathered} \nabla f(x) - \lambda \nabla g(x) = 0; \\ \bigl(\delta^2-g(x)^2\bigr) \lambda + 2 g(x) \mu = 0 . \end{gathered} } \]

Differentiating gives

\[ (\delta^2-g(x)^2) {\Delta\lambda} + (2 \mu - 2 g(x) \lambda) \nabla g(x) {\Delta x} = 0\]

In order to solve for \({\Delta x}\) in terms of \({\Delta\lambda}\), we require \( \mu - g(x) \lambda \neq 0\). Since the optimal \(x^*,\lambda^*\) satisfy \((\delta^2-g(x^*)^2) \lambda^* + 2 g(x^*) \mu = 0\), we have \(\lambda^* g(x^*) \geq 0\).

In the former case, we obtain the conditions

\[ \begin{gathered} \nabla f(x) - \lambda^+ \nabla g(x) + \lambda^- \nabla g(x) = 0; \\ \lambda^+ (\delta + g(x)) = \mu; \\ \lambda^- (\delta - g(x)) = \mu \end{gathered} \]

Set \(\lambda = \lambda^+ - \lambda^-\). Then we have

\[ \lambda = \mu \biggl( \frac{1}{\delta+g(x)} - \frac{1}{\delta-g(x)}\biggr) = \frac{-2\mu g(x)}{\delta^2-g(x)^2} . \]

Rearranging again gives

\[ (\delta^2-g(x)^2) \lambda + 2 g(x) \mu = 0\]

Note that \(\lambda^+ + \lambda^- = 2\delta\mu/(\delta^2-g(x)^2) \geq \bigl|\lambda^+-\lambda^-\bigr| \)

State constraints

Setting \(g(x)=x\) and taking \(\underline{x}\leq x\leq\overline{x}\), we obtain the state constraints

\[ \boxed{ \begin{gathered} \nabla f(x) - \lambda \nabla g(x) = 0; \\ (\overline{x}-x)(x-\underline{x})\lambda + (2x-\underline{x}-\overline{x}) \mu = 0 . \end{gathered} } \]

If \(\overline{x}=-\underline{x}=\delta\), this simplifies to

\[ (\delta^2-x^2) \lambda + 2 x \mu = 0 . \]

Differentiating yields

\[ {\Delta\lambda} = -2\mu \frac{\delta^2+x^2}{(\delta^2-x^2)^2} {\Delta x} \]

which can be used to eliminate these Lagrange multipliers entirely.

General Optimisation Problem

In Ariadne, we need to problems with a more general form of the constraints including bounds on the variables and constraints with upper and lower bounds. We henceforth consider the generalised problem:

\[ \boxed{\min f(x) \text{ s.t. } \underline{w}_j \leq g_j(x)\leq \overline{w}_j, \ j=1,\ldots,m; \ \underline{x}_i \leq x_i\leq \overline{x}_i,\ i=1,\ldots,n. } \]

We make the constraints on \(g\) into equality constraints by introducing variables \({w}_i\)

\[ g_j(x) - w_j = 0, \ \underline{w}_j \leq w_j \leq \overline{w}_j,\ j=1,\ldots,m. \]

We add a penalty function, and attempt to minimise the function

\[ \boxed{ f(x) - \mu \sum_{j=1}^{m} \bigl(\log(w_j-\underline{w}_j) + \log(\overline{w}_j-w_j) \bigr) - \mu \sum_{i=1}^{n} \bigl( \log(x_i-\underline{x}_i) + \log(\overline{x}_i-x_i) \bigr) + \frac{1}{2\nu} \sum_{j=1}^{m} (g_j(x)-w_j)^2 . } \]

Differentiating with respect to \(w\) and \(x\) gives

\[ \begin{gathered} \nabla_{\!i\,}f(x) - \mu \Bigl( \frac{1}{x_i-\underline{x}_i} - \frac{1}{\overline{x}_i-x_i} \Bigr) + \frac{1}{\nu} \sum_{j=1}^{m} (g_j(x)-w_j) \nabla_{\!i\,}g_j(x) = 0; \\ - \mu \Bigl(\frac{1}{w_j-\underline{w}_j} - \frac{1}{\overline{w}_j-w_j} \Bigr) - \frac{1}{\nu} (g_j(x)-w_j) = 0. \end{gathered} \]

Setting \(y_j = -(g_j(x)-w_j)/\nu\) gives

\[ \begin{gathered} \mu \Bigl(\frac{1}{w_j-\underline{w}_j} - \frac{1}{\overline{w}_j-w_j} \Bigr) - y_j = 0; \\ \nabla_{\!i\,}f(x) - \mu \Bigl( \frac{1}{x_i-\underline{x}_i} - \frac{1}{\overline{x}_i-x_i} \Bigr) - \sum_{j=1}^{m} y_j \nabla_{\!i\,}g_j(x) = 0; \\ g_j(x)-w_j + \nu\,y_j = 0. \end{gathered} \]

Setting \(\nu=0\) simplifies to

\[ \boxed{ \displaystyle \begin{gathered} \mu \Bigl(\frac{1}{w_j-\underline{w}_j} - \frac{1}{\overline{w}_j-w_j} \Bigr) - y_j = 0; \\ \nabla_{\!i\,}f(x) - \mu \Bigl( \frac{1}{x_i-\underline{x}_i} - \frac{1}{\overline{x}_i-x_i} \Bigr) - \sum_{j=1}^{m} y_j \nabla_{\!i\,}g_j(x) = 0; \\ g_j(x)-w_j = 0. \end{gathered} } \]

Setting \(z_i=\mu \bigl( 1/(x_i-\underline{x}_i) - 1/(\overline{x}_i-x_i) \bigr)\) gives

\[ \boxed{ \displaystyle \begin{gathered} \mu \Bigl(\frac{1}{w_j-\underline{w}_j} - \frac{1}{\overline{w}_j-w_j} \Bigr) - y_j = 0; \\ \mu \Bigl( \frac{1}{x_i-\underline{x}_i} - \frac{1}{\overline{x}_i-x_i} \Bigr) - z_i = 0; \\ \nabla_{\!i\,}f(x) - z_i - \sum_{j=1}^{m} y_j \nabla_{\!i\,}g_j(x) = 0; \\ g_j(x)-w_j + \nu\,y_j= 0. \end{gathered} } \]

It is possible to eliminate the dual variables \(y_j\) to obtain the alternative (and less useful) form

\[ \begin{gathered} -\nabla_{\!i\,}f + \mu \biggl( \frac{1}{x_i-\underline{x}_i} - \frac{1}{\overline{x}_i-x_i} \biggr) + \mu \sum_{j=1}^{m} \biggl( \frac{1}{w_j-\underline{w}_j} - \frac{1}{\overline{w}_j-w_j} \biggr) \nabla_{\!i\,} g_j(x) = 0; \quad g_j(x) - w_j + \nu\,y_j = 0. \end{gathered} \]

Note that if \(\underline{x}_i=0\) and \(\overline{x}_i=\infty\), then

\[ \mu ( 1/x_i - 1/\infty ) - z_i = 0 \]

so

\[ x_i\,z_i = \mu . \]

Note that if \( \underline{w}_j = \overline{w}_j \), then \( w_j = \underline{\overline{w}}_j \) and we can set \(y_j\) arbitrarily. Hence \(\mu \bigl(\frac{1}{w_j-\underline{w}_j} - \frac{1}{\overline{w}_j-w_j} \bigr) - y_j = 0\) is replaced by \(w_j-\underline{\overline{w}}_j\) for this \(j\).

The linear case

If \(f(x) = c^Tx\), \(g(x)=Ax-b\), \(\underline{w}=\overline{w}=0\), \(\underline{x}=0\) and \(\overline{x}=\infty\), then \(w=0\) and we obtain the conditions

\[ x_i\,z_i = \mu; \quad A^Ty + z = c; \quad Ax + \nu\,y = b,\]

which are a relaxed version of the standard conditions for linear programming

Conversely, if \(f(x)=-b^Tx\), \(g(x)=c-A^Tx\), \(\underline{w}=0\), \(\overline{w}=\infty\), \(\underline{x}=-\infty\) and \(\overline{x}=+\infty\), then \(z=0\) and

\[ w_j\,y_j = 0; \quad Ay = b; \quad A^T x+w = c + \nu\,y = 0 . \]

This is a relaxed version of the standard conditions for linear programming with \(w\) instead of \(z\) for the slack variables, and \(x\) and \(y\) interchanged.

General feasibility problem

Consider the generalised feasibility problem:

\[ \boxed{ \underline{w}_j \leq g_j(x)\leq \overline{w}_j, \ j=1,\ldots,m; \ \underline{x}_i \leq x_i\leq \overline{x}_i;\ i=1,\ldots,n. } \]

where \(-\infty < \underline{x}_i < \overline{x}_i < +\infty\).

A similar analysis to the minimisation problem with \(f(x) = 0\) gives the relaxation

\[ \begin{gathered} \mu \Bigl(\frac{1}{w_j-\underline{w}_j} - \frac{1}{\overline{w}_j-w_j} \Bigr) - y_j = 0; \\ \mu \Bigl( \frac{1}{x_i-\underline{x}_i} - \frac{1}{\overline{x}_i-x_i} \Bigr) + \sum_{j=1}^{m} y_j \nabla_{\!i\,}g_j(x) = 0; \\ g_j(x)-w_j + \nu\,y_j = 0. \end{gathered} \]

Setting \(z_i=\mu \bigl( 1/(x_i-\underline{x}_i) - 1/(\overline{x}_i-x_i) \bigr)\) gives

\[ \boxed{ \displaystyle \begin{gathered} \mu \Bigl(\frac{1}{w_j-\underline{w}_j} - \frac{1}{\overline{w}_j-w_j} \Bigr) - y_j = 0; \\ \mu \Bigl( \frac{1}{x_i-\underline{x}_i} - \frac{1}{\overline{x}_i-x_i} \Bigr) - z_i = 0; \\ z_i + \sum_{j=1}^{m} y_j \nabla_{\!i\,}g_j(x) = 0; \\ g_j(x)-w_j + \nu\,y_j= 0. \end{gathered} } \]

The Lagrangian function is defined as

\[ \boxed{ \displaystyle L(w,x,y) = \sum_{j=1}^{m} \bigl( \log(w_j-\underline{w}_j)+\log(\overline{w}_j-w_j) \bigr) + \sum_{i=1}^{n} \bigl( \log(x_i-\underline{x}_i)+\log(\overline{x}_i-x_i) \bigr) + \sum_{j=1}^{m} y_j(g_j(x)-w_j) } \]

The optimality conditions are obtained as a critical point of the Lagrangian. Hence the derivative of the optimality conditions is a symmetric matrix, being the Hessian of the Lagrangian, and is the matrix

\[ \begin{pmatrix} -D & 0 & -I \\ 0 & -E + Y\cdot H & A^T \\ -I & A & 0 \end{pmatrix} \]

where

\[ \begin{gathered}D_{jj}=1/(w_j-\underline{w}_j)^2+1/(\overline{w}_j-w_j)^2, \\ E_{ii}=1/(x_i-\underline{x}_i)^2+1/(\overline{x}_i-x_i)^2, \\ Y_{jj}=y_j, \\ A_{ji} = \partial{g_j(x)}/\partial{x}_i, \\ H_{ji_1i_2} = \partial^2g_j(x)/\partial x_{i_1}\partial x_{i_2} . \end{gathered} \]

To solve the Newton step for

\[ \begin{aligned} D \delta w + \delta y &= r_w; \\ (E-Y\cdot H) \delta x -A^T\delta y &= r_x; \\ \delta w - A\delta x &= r_y ; \end{aligned}\]

we find

\[ A^TD \, \delta w + (E-Y\cdot H) \delta x = A^T r_w + r_x \]

and hence

\[ \begin{aligned} (A^TDA + E - Y\cdot H) \delta x &= A^T r_w + r_x - A^T D r_y \\ &= A^T(r_w-Dr_y)+r_x . \end{aligned} \]

We therefore can solve the system as

\[ \boxed{\begin{aligned} (A^TDA + E - Y\cdot H) \delta x &= A^T(r_w-Dr_y)+r_x \\ \delta w &= A \delta x + r_y \\ \delta y &= r_w - D \!\; \delta w . \end{aligned} } \]

Since a feasible solution \((w^*,x^*)\) must satisfy

\[ \sum_{j=1}^{m} y_j^* (g_j(x^*)-w_j^*) = 0, \]

a test of infeasibility is

\[ y^* \cdot (g([x])-[w]) \not\ni 0 .\]

This can be most accurately evaluated as

\[ \boxed{ \displaystyle (y^* \cdot g)([x])- y^*\cdot [w] \not\ni 0 . } \]

For this reason, we prefer a method which keeps the dual variables \(y_j\), but not the variables \(z_i\).

This yields the basis of an infeasible interior point method. We keep the constraints on \(x\) and the inequality constraints on \(w\) satisfied, and try to solve the constraints \(g_j(x)-w_j = 0 \). The method can be applied with or without explicit use of the dual variables \(y\) and \(z\).

Reformulation of the nonlinear feasibility problem

We can multiply out the fractional terms to obtain

\[ \boxed{\begin{gathered} g_j(x) - w_j = 0. \\ z_i - \sum_{j=1}^{m} y_j \nabla_{\!i\,} g_j(x) = 0 \\ z_i(x_i-\underline{x}_i)(\overline{x}_i-x_i) - (\underline{x}_i+\overline{x}_i-2x_i) = 0 \\ y_i(w_j-\underline{w}_j)(\overline{w}_j-w_j) - (\underline{w}_j+\overline{w}_j-2w_j) = 0 \end{gathered} } \]

We can separate out the lower and upper terms to obtain

\[ \boxed{\begin{gathered} g_j(x) - w_j = 0. \\ (\underline{z}_i - \overline{z}_i) - \sum_{j=1}^{m} (\underline{y}_j - \overline{y}_j) \nabla_{\!i\,} g_j(x) = 0 \\ \underline{z}_i(x_i-\underline{x}_i) = 0; \quad \overline{z}_i(\overline{x}_i-x_i) = 0 \\ \underline{y}_j({w}_i-\underline{w}_i) = 0 ; \quad \overline{y}_j(\overline{w}_j-w_j) = 0 \end{gathered} } \]

Remarks
If there are no equality constraints, we can eliminate \(y\) to yield

\[ \frac{1}{x_i-\underline{x}_i} - \frac{1}{\overline{x}_i-x_i} - \sum_{j=1}^{m} \Biggl( \frac{1}{w_j-\underline{w}_j} - \frac{1}{\overline{w}_j-w_j} \Biggr) \, \nabla_{\!i\,} g_j(x) = 0; \qquad g_j(x)-w_j = 0 . \]

We can further eliminate \(w\) to yield

\[ \displaystyle \frac{1}{x_i-\underline{x}_i} - \frac{1}{\overline{x}_i-x_i} - \sum_{j=1}^{m} \Biggl( \frac{1}{g_j(x)-\underline{w}_j} - \frac{1}{\overline{w}_j-g_j(x)} \Biggr) \, \nabla_{\!i\,} g_j(x) = 0 \]

If there are equality constraints, which we write \(h_k(x) = 0\), then

\[ \frac{1}{x_i-\underline{x}_i} - \frac{1}{\overline{x}_i-x_i} - \sum_{j=1}^{m} \Biggl( \frac{1}{g_j(x)-\underline{w}_j} - \frac{1}{\overline{w}_j-g_j(x)} \Biggr) \, \nabla_{\!i\,} g_j(x) + \sum_{k=1}^{l} y_k \, h_k(x) = 0 ; \qquad h_k(x) = 0. \]

However, since our general case includes both inequality and equality constraints, it is more straightforward to use Lagrange multipliers for both kinds of constraint.

Inequality constrained feasibility problems

Consider the feasibility problem

\[ g_j(x) \leq 0, \ j=1,\ldots,m; \ \ \underline{x}_i \leq x_i\leq \overline{x}_i,\ i=1,\ldots,n. \]

We can re-cast this as an optimisation problem by introducing an extra variable \(t\) and taking

\[ \max t \ \text{ s.t. } \ g_i({x})+t\leq 0,\ j=1,\ldots,n;\ \ \underline{x}_i \leq x_i\leq \overline{x}_i,\ i=1,\ldots,n. \]

The Karush-Kuhn-Tucker conditions for optimality with dual variables \(y\) and slack variables \(w\) are

\[ \textstyle \sum_{i=1}^{m} y_i \nabla g_i({x}) = 0; \ \sum_{j=1}^{n} x_j =1; \ g_i({x}) + t + {w}_i = 0; \ {w}_iy_i=0;\ {w}_i,y_i\geq 0,\ i=1,\ldots,m \]

The problem has no solution if there exists \(y^*\) such that

\[ y^*_i \cdot g_i([x]) > 0 . \]

Solving the Karush conditions by Newton-like methods

We now consider the general nonlinear programming problem

\[ \max f(x) \mid \underline{x}_i \leq x_i \leq \overline{x}_i \wedge \underline{w} \leq g_j(x) \leq \overline{w}_j \]

We assume a bounded domain with nonempty interior, so \(-\infty < \underline{x}_i < \overline{x}_i \leq +\infty\), but allow for the other constraints to be equality constraints \(\underline{w}_j=\overline{w}_j\) or unbounded \(\underline{w}_j=-\infty\) or \(\overline{w}_j=+\infty\). We set \(w_j=g_j(x)\), so we can write \(\underline{w} \leq w_j \leq \overline{w}_j\) and \(g(x)-w=0\). However, we treat bounded, unbounded and equality constraints slightly differently.

We can write the relaxed Karush conditions in the following form

\[ \begin{gathered} \nabla f(x) - \sum_{j=1}^{m} \lambda_j \nabla g(x) = 0\\ s_j(g_j(x),\lambda_j,\mu) = 0 \end{gathered} \]

where \(s_j(w_j,\lambda_j,\mu)\) depends on the bounds \(\underline{w}_j,\overline{w}_j\). Setting \(y_j=g_j(x)\), the Jacobian matrix for the Karush conditions is given by

\[ \begin{pmatrix} \nabla^2 f + \sum_j \lambda_j \nabla^2 g_j & \nabla g ^T \\ \nabla_w s \nabla g & \nabla_\lambda s \end{pmatrix} \]

Writing \(H=\nabla^2 f + \sum_j \lambda_j \nabla^2 g_j\), \(A=\nabla g\), \(W_{jj} = \partial s_j/\partial \lambda_j\), and \(\Lambda_{jj} = \partial s_j/\partial w_j \), we have the system

\[ \begin{pmatrix} H & A^T \\ \Lambda A & W \end{pmatrix} \]

Premultiplying by \(\Lambda^{-1}\) and setting \(D=\Lambda^{-1}W\) yields the form

\[ \begin{pmatrix} H & A^T \\ A & D \end{pmatrix} \]

which is symmetric since \(H\) is symmetric and \(D\) is diagonal. This system can be solved for \(\Delta x\) by inverting the matrix \(H-A D^{-1} A^T = H-AW^{-1}\Lambda A\). In particular, the matrix can be formed as long as \(\partial s_j/\partial \lambda_j \neq 0\) for all \(j\). This is indeed the case for all the examples we have considered.

The values of \(\Lambda_{ii}=\partial s/\partial y\) \(W=\partial s/\partial \lambda\) are given below for various constraints:

  • \(g(x)=0 : s(y,\lambda,\mu) = y-\lambda \mu; \ \partial s/\partial y = 1; \ \partial s/\partial\lambda = -\mu\)
  • \(g(x)\geq0 : s(y,\lambda,\mu) = \lambda y - \mu; \ \partial s/\partial y = \lambda; \ \partial s/\partial\lambda = y\)
  • \(g(x)\leq0 : s(y,\lambda,\mu) = \lambda y - \mu; \ \partial s/\partial y = \lambda; \ \partial s/\partial\lambda = y\)
  • \(|g(x)|\leq\delta : s(y,\lambda,\mu) = (\delta^2-y^2)\lambda -2y\mu; \ \partial s/\partial y = -2\lambda y-2\mu; \ \partial s/\partial\lambda = (\delta^2-y^2) \)
  • \( a \leq g(x) \leq b: s(y,\lambda,\mu) = (b-y)(y-a)\lambda -(2y-a-b)\mu; \ \partial s/\partial y = -\lambda (2y-a-b)-2\mu; \ \partial s/\partial\lambda = (b-y)(y-a) \)

Primal-dual-slack methods

In a primal-dual method, we introduce slack variables \(s_i\) corresponding to each inequality constraint \(g_i({x})\leq 0\) to form an equality constraint \(g_i({x})+s_i=0\). However, these slack variables are temporaries, and are recomputed each step.

In a primal-dual-slack method, we instead update the slack variables using a Newton-like step

\[ x'=x-\alpha \Delta x; \quad s'=s-\alpha\Delta s \]

with

\[ \nabla g_i({x}) \Delta x + \Delta s_i = g_i({x})+s_i . \]

After the Newton-like step, the equality \(g_i(x') + s_i'\) does not hold, unless \(g_i\) is affine, in which case \(g_i(x')+s'=0\) up to roundoff error. We call methods in which the slack is stored and updated by a Newton-like step primal-dual-slack methods, to distinguish them from ordinary primal-dual methods.

In general, enforcing primal feasibility using a primal-dual-slack method may be harder than for an ordinary primal-dual method. We doubt these methods are advantageous in practise.

Interval Methods for Nonlinear Programming

See Hansen & Walster (1993).

Interval methods for solving the Karush-Kuhn-Tucker conditions

Consider the standard nonlinear optimisation problem with inequality constraints only

\[ \max f(x) \text{ s.t. } g(x)\geq0 \]

and look for a solution with \(x\in X = [\unl{x},\ovl{x}] \)

The Karush-Kuhn-Tucker optimality conditions are

\[ \begin{gathered} \nabla_j f(x) + \sum_{i=1}^{m} y_i \cdot \nabla_j g_i(x) = 0; \\ y_i \, g_i(x) = 0; \quad y_i,g_i(x) \geq 0. \end{gathered} \]

Applying the one-dimensional Taylor theorem with remainder to each component, we obtain

\[ F(x+\delta{x},y+\delta{y}) \in F(x,y) + D_xF(X,y)\,\delta{x} + D_yF(X,Y)\,\delta{y} \]

and can hence use the Jacobian matrix

\[ \begin{pmatrix} \nabla^2f(X)+y\!\cdot\!\nabla^2g(X) & \nabla g(X)^T \\ \nabla g(X) & \mathrm{diag}(g(X)/y) \end{pmatrix} \]

Note that the variables \(y\) only enter into the Jacobian in the non-interval form. Hence even if the interval \(Y_i\) contining the dual variable \(y_i\) is unbounded, the interval Newton step only requires a suitably-chosen point \(y_i\in Y_i\).

Interval methods for solving the John conditions

Introduce variables \(w,y,z\) and use the following form of the John conditions

\[ \boxed{\begin{gathered} g(x) - w = 0. \\ z_i - \sum_{j=1}^{m} y_j \nabla_i g(x_j) = 0 \\ z_i (x_i-\underline{x}_i) (\overline{x}_i-x_i) - \mu (\underline{x}_i+\overline{x}_i-2x_i) = 0 \\ y_j (w_j-\underline{w}_j) (\overline{w}_j-w_j) - \mu (\underline{w}_j+\overline{w}_j-2w_j) = 0 \\ \sum_{j=1}^{m} y_j^2 + \sum_{i=1}^{n} z_i^2 = \mu^2 \end{gathered} } \]

Bounds on the objective function.

Consider the nonlinear programming problem without equality constraints,

\[ \max f(x) \text{ s.t. } g_j(x)\leq 0,\ j=1,\ldots,m;\ x\in[x] . \]

Suppose \(x_0\) is any point in \([x]\) (not necessarily feasible) and \(x_0\geq0\). Then

\[ \begin{aligned} f(x) &= f(x_0) + \nabla f([x]) (x-x_0) \\ &= f(x_0) + \nabla f(x_0) (x-x_0) + \bigl(\nabla f([x])-\nabla f(x_0)\bigr)(x-x_0) \\ &= f(x_0) + \bigl(\nabla f(x_0) - \lambda_0\cdot \nabla g(x_0)\bigr)(x-x_0) + \lambda_0\cdot\nabla g(x_0)(x-x_0) + \bigl(\nabla f([x])-\nabla f(x_0)\bigr)(x-x_0) \end{aligned}\]

Now

\[ g(x) = g(x_0) + \nabla g(x_0) (x-x_0) + \bigl(\nabla g([x])-\nabla g(x_0)\bigr) (x-x_0) \]

which upon rearranging yields

\[ \nabla g(x_0) (x-x_0) = g(x)-g(x_0) - \bigl(\nabla g([x])-\nabla g(x_0)\bigr) (x-x_0) \]

Substituting into the equation for \(f(x)\) yields

\[ \begin{aligned} f(x) &= f(x_0) + \lambda_0\cdot\bigl(g(x)-g(x_0)\bigr) + \bigl(\nabla f(x_0) - \lambda_0\cdot\nabla g(x_0)\bigr)(x-x_0) + \bigl(\nabla f([x])-\nabla f(x_0)\bigr)(x-x_0) - \bigl(\nabla g([x])-\nabla g(x_0)\bigr) (x-x_0) \\ &= f(x_0) + \lambda_0\cdot\bigl(g(x)-g(x_0)\bigr) + \bigl(\nabla f(x_0) - \lambda_0\cdot\nabla g(x_0)\bigr)(x-x_0) + \bigl( (\nabla f([x])-\lambda_0\cdot\nabla g([x])) - (\nabla f(x_0)-\lambda_0\cdot\nabla g(x_0)) \bigr) (x-x_0) \end{aligned}\]

Using the fact that \(\lambda g(x)\leq 0\) for any feasible \(x\) and \(\lambda\), we obtain

\[ \boxed{ f(x) \leq f(x_0) - \lambda_0\cdot g(x_0) + \bigl(\nabla f(x_0) - \lambda_0\cdot\nabla g(x_0)\bigr)(x-x_0) + \bigl( (\nabla f([x])-\lambda_0\cdot\nabla g([x])) - (\nabla f(x_0)-\lambda_0\cdot\nabla g(x_0)) \bigr) (x-x_0)} \]

This equation can also be written as

\[ \boxed{ f(x) \leq f(x_0) - \lambda_0\cdot g(x_0) + \bigl( \nabla f(x_0)-\lambda_0\cdot\nabla g(x_0) \bigr) (x-x_0) + \bigl( \nabla^2 f([x])-\lambda_0\cdot\nabla^2 g([x]) \bigr) (x-x_0)^2} \]

A particularly useful form is given below. Note that the function \(\nabla f-\lambda_0\cdot\nabla g\) is first computed and simplified, and only then evaluated over the box \([x]\). Since we can choose \( \nabla f(x_0)-\lambda_0\cdot\nabla g(x_0) \approx 0 \), this can be used to obtain good bounds on \(f(x)\).

\[ \boxed{ f(x) \leq f(x_0) - \lambda_0\cdot g(x_0) + \bigl( \nabla f-\lambda_0\cdot\nabla g \bigr)[x] (x-x_0)} \]

Alternative approach

We make the constraints on \(g\) into equality constraints by setting

\[ g_j(y) + t + z^u_j = c^u_j; \ -g_j(y) + t + z^l_j = -c^l_j; \ j=1,\ldots,n. \]

Taking extended variable \(\hat{y}=(y,t)\), and letting \(e^T\) denote a row vector all of whose elements are \(1\) we have matrices

\[ \widehat{A} = \left(\begin{matrix} A(y)&-A(y)&I&-I \\ e^T&e^T&e^T&e^T \end{matrix}\right); \qquad \widehat{H} = \left(\begin{matrix} H(x^{cu}-x^{cl},y)&0 \\ 0&0 \end{matrix}\right); \qquad \widehat{D} = \left(\begin{matrix} D(x^{cu},z^{cu})&0&0&0 \\ 0&D(x^{cl},z^{cl})&0&0 \\ 0&0&D(x^{bu},z^{bu})&0 \\ 0&0&0&D(x^{bl},z^{bl}) \end{matrix}\right) . \]

yielding

\[ \widehat{A}\widehat{D}\widehat{A}^T = \left(\begin{matrix} A(D^{cu}+D^{cl})A^T+(D^{bu}+D^{bl})&A(D^{cu}-D^{cl})e+(D^{bu}-D^{bl})e\\e^T(D^{cu}-D^{cl})A^T+e^T(D^{bu}-D^{bl})&e^T(D^{cu}+D^{cl}+D^{bu}+D^{bl})e \end{matrix}\right) . \]

Note that considering lower and upper bounds requires no extra matrix multiplications, and recasting the problem as an optimisation problem in \(m+1\) variables involves a single extra matrix multiplication \(A(D^u-D^l)e^T\) and one extra variable in the matrix inversion. In other words, the extra work is minimal.

Remarks
If \(c^u_j=\infty\), then \(z^u_j=\infty\) so \(x^u_j=0\) and \(D^u_{jj}=0\), so the constraint drops out of consideration in the inverse matrix. However, when computing the residuals, we obtain, assuming \(0<x^{cu}_j,z^{cu}_j<\infty\) that \(rz^{cu}_j=\infty\), and this propagates through the computation of the step to give \(\delta x=\delta y=\delta z=\infty\). If we take \(0<x^{cu}_j\) and \(z^{cu}_j=\infty\), then the residual \(rz^{cu}_j\) is \(\mathrm{nan}\) which again propagates through the computation.

When some of the constraints \(c^u\) or \(c^l\) are infinite, then use of floating-point arithmetic will give nan in the corresponding constraints. In principle, we need to consider half-unbounded constraints directly, rather than as box constraints. However, since the result is bounded, we can take the unbounded part of these constraints large enough that they are automatically satisfied.

Proving feasibility of equality constraints

Consider the problem of proving that the system of equality constraints \(h(x)=0\) has a solution in a box \(X\), where \(h:\R^n\rightarrow\R^m\) and \(m\leq n\). If \(m=n\), then if \(Dh\) is invertible, we can find a solution using an interval Newton method. If \(m<n\), we wish to reformulate the problem in \(m\) variables.

Fix \(x\) and let \(A\) be an approximation to \(Dh(x)\). If \(Dh(x)\) has full (row) rank and \(A\) is sufficiently accurate, then \(AA^T\) is invertible; let \(R\) be an approximate inverse. Let \(S\) be a box in \(\R^m\) containing \(0\), and let \(f(s) = h(x+A^Ts)\) for \(s\in S\). Note \(df(0) = Dh(x) A^T \approx AA^T\). We can use the interval Newton method to prove that \(f\) has a zero in \(B\). Then \(h\) has a zero in \(x+A^TS\).

If \(X\) is a box in \(\R^n\), then \(RA(X-x)\) is a suitable guess for a box in \(V\).

Algorithms for Nonlinear Feasibility Problems

In Ariadne, we are interested in solving feasibility problems where the constraints gradually tighten. This means that a feasable point can be used as in initial seed for iterating a tighter subproblem, and bound on the feasibly set of \(y\) can be used in a tighter subproblem, and a certificate of infeasibility means that no further subproblems need to be considered.

A possible algorithm for solving feasibility problems is as follows:

  • Use a non-rigorous iterative nonlinear programming solver (e.g. an interior point solver) to find \(x_0,y_0\) giving a local solution to the related optimality problem.
  • If \(y_0\) is feasible, repeat for the tighter subproblems, using computed \((x_0,y_0)\) as a seed for the iterative solver.
  • If \(x_0\cdot g([y])>0\), the problem is infeasible.
  • Reduce \([y]\) using the constraint \(x_0\cdot g([y])\leq 0\) and hull/box reduce, possibly using the expansion \(x_0\cdot g([y]) = x_0\cdot g(y_0)+\nabla g([y])(y-y_0)\).
  • If \([y]\) is empty, the problem is infeasible.
  • Apply the Krawczyk contractor to the Karush-Kuhn-Tucker optimality conditions \( x\cdot \nabla g(y) = 0; \ \sum x_i =1; \ g(y) + t + z = 0; \ x_iz_i=0; \ x_i,z_i\geq 0,\ i=1,\ldots,n\).
  • Split domain in two and repeat. The splitting should be done to increase linearity of the \(\nabla g\), since linear solvers are very effective. Note that we should repeat from the beginning in case the failure to prove disjointness was due to \((x_0,y_0)\) being a local maximum.
  • It may be worth contracting \([y]\) from time to time to improve the iteration speed.
  • The use of \(x_0\cdot g([y])\leq 0\) rather than \(g_i([y])\leq 0\) to perform the contraction is to focus attention on the possibly violated constraints.

Infeasible Interior Point Methods

Consider the nonlinear programming problem

\[ \min f({x}) \ \text{ s.t. } \ \unl{d}\leq {x}\leq\ovl{d}, \quad \unl{c}\leq g({x})\leq\ovl{c} \]

where

\[ \begin{gathered} -\infty < \unl{d}_j < \ovl{d}_j < +\infty \\ -\infty \leq \unl{c}_i < +\infty, \quad -\infty<\ovl{c}_i\leq+\infty, \quad \unl{c}_i\leq \ovl{c}_i. \end{gathered} \]

By intersecting \(C\) with \(g(D)\) if necessary, we can assume that \(C\) is also bounded,

\[ -\infty < \unl{c}_i \leq \ovl{c}_i < +\infty \]

though there may be equality constraints \(\unl{c}_i=\ovl{c}_i\).

Introduce new variables \(w\) satisfying

\[ g({x}) - w = 0 , \]

and slack variables \(\unl{w}\), \(\ovl{w}\), \(\unl{x}\), \(\ovl{x}\) satisfying

\[ {w}+\unl{w}=\unl{c},\ {w}+\ovl{w}=\ovl{c},\ {x}+\unl{x}=\unl{d},\ {x}+\ovl{x}=\ovl{d},\]

and

\[ \unl{w},\unl{x}\leq 0,\ \ovl{w},\ovl{x}\geq 0 . \]

Add a penalty function to obtain

\begin{multline*} f(x) - \mu \sum_{i=1}^{m}\bigl(\log\!|\unl{w}_i|+\log\!|\ovl{w}_i|\bigr) - \mu \sum_{j=1}^{m}\bigl(\log\!|\unl{x}_j|+\log\!|\ovl{x}_j|\bigr) + \frac{1}{2\nu} \sum_{i=1}^{m}(g_i({x})-{w}_i)^2 \\ \shoveright + \frac{1}{2\nu} \sum_{i=1}^{m}\bigl(( {w}_i+\unl{w}_i-\unl{c}_i)^2+( {w}_i+\ovl{w}_i-\ovl{c}_i)^2\bigr) + \frac{1}{2\nu} \sum_{j=1}^{n}\bigl(({x}_j+\unl{x}_j-\unl{d}_j)^2+({x}_j+\ovl{x}_j-\ovl{d}_j)^2\bigr) \end{multline*}

Finding the critical points of the revised function gives

\[ \begin{gathered} \nabla_j{f}(x) + \frac{1}{\nu} \sum_{i=1}^{m}(g_i({x})-{w}_i) \nabla_j{g_i}(x) + \frac{1}{\nu}({x}_j+\unl{x}_j-\unl{d}_j)+\frac{1}{\nu}({x}_j+\ovl{x}_j-\ovl{d}_j)= 0; \\ -\frac{1}{\nu}(g_i({x})-{w}_i) + \frac{1}{\nu}( {w}_i+\unl{w}_i-\unl{c}_i) + \frac{1}{\nu}( {w}_i+\ovl{w}_i-\ovl{c}_i) = 0; \\ -\frac{\mu}{\unl{w}} + \frac{1}{\nu}( {w}_i+\unl{w}_i-\unl{c}_i) = 0; \quad -\frac{\mu}{\ovl{w}} + \frac{1}{\nu}( {w}_i+\ovl{w}_i-\ovl{c}_i) = 0; \\ -\frac{\mu}{\unl{x}} + \frac{1}{\nu}({x}_j+\unl{x}_j-\unl{d}_j) = 0; \quad -\frac{\mu}{\ovl{x}} + \frac{1}{\nu}({x}_j+\ovl{x}_j-\ovl{d}_j) = 0; \\ \end{gathered} \]

Introduce dual variables

\[ \begin{gathered} y = (g(x)-w)/\nu; \\ \unl{v}=({w}+\unl{w}-\unl{c})/\nu, \quad \ovl{v}=({w}+\ovl{w}-\ovl{c})/\nu, \\ \unl{z}=({x}+\unl{x}-\unl{d})/\nu, \quad \ovl{z}=({x}+\ovl{x}-\ovl{d})/\nu, \end{gathered} \]

satisfying

\[ \unl{v},\unl{z}\leq 0,\ \ovl{v},\ovl{z}\geq 0 . \]

On taking \(\nu\to0\), the criticality conditions become

\[ \begin{gathered} \nabla_j{f}(x) + \sum_{i=1}^{m} y_i \nabla_j{g_i}(x) + (\unl{z}_j+\ovl{z}_j) = 0; \\ g_i({x}) - {w}_i = 0; \quad -y_i + \unl{v}_i + \ovl{v}_i = 0; \\ {w}_i+\unl{w}_i-\unl{c}_i = 0; \quad \unl{v}_i\,\unl{w}_i - \mu = 0; \\ {w}_i+\ovl{w}_i-\ovl{c}_i = 0; \quad \ovl{v}_i\,\ovl{w}_i - \mu = 0; \\ {x}_j+\unl{x}_j-\unl{d}_j = 0; \quad \unl{z}_j\,\unl{x}_j - \mu = 0; \\ {x}_j+\ovl{x}_j-\ovl{d}_j = 0; \quad \ovl{z}_j\,\ovl{x}_j - \mu = 0; \end{gathered} \]

Setting \(A=\nabla\!g(x)\) and \(H=\nabla^2\!f(x)+\sum_{i=1}^{m} y_i \nabla^2 g_i({x})\), we have

\begin{equation*}\left( \begin{array}{c|ccc|cccc|cccc} & {w}&{x}&{y} & \unl{w}&\ovl{w}&\unl{x}&\ovl{x} & \unl{v}&\ovl{v}&\unl{z}&\ovl{z} \\ \hline {w} & 0 & 0 & -I & 0&0&0&0 & I&I&0&0 \\ {x} & 0 & H & A^T & 0&0&0&0 & 0&0&I&I \\ {y} & -I & A & 0 & 0&0&0&0 & 0&0&0&0 \\ \hline \unl{w} & 0 & 0 & 0 & \!\unl{D}\!\!\!&0&0&0 & I\,&0&0&0 \\ \ovl{w} & 0 & 0 & 0 & 0&\!\!\!\ovl{D}\!\!\!&0&0 & 0&\,I\,&0&0 \\ \unl{x} & 0 & 0 & 0 & 0&0&\!\!\!\unl{E}\!\!\!&0 & 0&0&\,I\,&0 \\ \ovl{x} & 0 & 0 & 0 & 0&0&0&\!\!\!\ovl{E}\! & 0&0&0&\,I \\ \hline \unl{v} & I & 0 & 0 & I&0&0&0 & 0&0&0&0 \\ \ovl{v} & I & 0 & 0 & 0&I&0&0 & 0&0&0&0 \\ \unl{z} & 0 & I & 0 & 0&0&I&0 & 0&0&0&0 \\ \ovl{z} & 0 & I & 0 & 0&0&0&I & 0&0&0&0 \end{array}\right) \left( \begin{array}{c} \\\hline \delta w\\\delta x\\\delta y \\\hline \delta\unl{w}\\\delta\ovl{w}\\\delta\unl{x}\\\delta\ovl{x} \\\hline \delta\unl{v}\\\delta\ovl{v}\\\delta\unl{z}\\\delta\ovl{z} \end{array}\right) = \left( \begin{array}{c} \\\hline \epsilon w\\\epsilon x\\\epsilon y \\\hline \epsilon\unl{w}\\\epsilon\ovl{w}\\\epsilon\unl{x}\\\epsilon\ovl{x} \\\hline \epsilon\unl{v}\\\epsilon\ovl{v}\\\epsilon\unl{z}\\\epsilon\ovl{z} \end{array}\right) = \left( \begin{array}{c} \\\hline -y+\unl{v}+\ovl{v}\\\nabla\!f(x)+\nabla g(x)^Ty+\unl{z}+\ovl{z}\\g(x)-w \\\hline \unl{v}-\mu/\unl{w}\\\ovl{v}-\mu/\ovl{w}\\\unl{z}-\mu/\unl{x}\\\ovl{z}-\mu/\ovl{x} \\\hline {w}+\unl{w}-\unl{c}\\{w}+\ovl{w}-\ovl{c}_i\\{x}+\unl{x}-\unl{d}\\{x}+\ovl{x}-\ovl{d} \end{array}\right) \end{equation*}

where

\[ \unl{D} = \unl{V}/\unl{W}; \quad \ovl{D}=\ovl{V}/\ovl{W}; \qquad \unl{E}=\unl{Z}/\unl{X}; \quad \ovl{E}=\ovl{Z}/\ovl{X} . \]

We can eliminate all variables except \(w\), \(x\) and \(y\) to obtain

\begin{equation*}\left( \begin{array}{c|ccc} & {w}&{x}&{y} \\ \hline \\[-2ex] {w} & D & 0 & -I \\ {x} & 0 & H\!+\!E & A^T \\ {y} & -I & A & 0 \end{array}\right) \left( \begin{array}{c} \delta\\\hline \delta w\\\delta x\\\delta y \end{array}\right) = \left( \begin{array}{c} \rho\\\hline \rho w\\\rho x\\\rho y \end{array}\right) \end{equation*}

where

\[ D = \unl{D} + \ovl{D} = \unl{V}/\unl{W}+\ovl{V}/\ovl{W}; \qquad E = \unl{E} + \ovl{E} = \unl{Z}/\unl{X}+\ovl{Z}/\ovl{X} ; \]

and

\[ \begin{aligned} \rho w &= \epsilon w - (\epsilon\unl{w}+\epsilon\ovl{w}) + \unl{D}\,\epsilon\unl{v} + \ovl{D}\,\epsilon\ovl{v} \,; \\ \rho x &= \epsilon x - (\epsilon\unl{x}+\epsilon\ovl{x}) + \unl{E}\,\epsilon\unl{z} + \ovl{E}\,\epsilon\ovl{z} \,; \\ \rho y &= \epsilon y \,. \end{aligned} \]

These equations further simplify to

\[ \begin{aligned} S\, &= (H+E+A^TDA) \\[1px] \delta x &= S^{-1} \bigl(\rho x+A^T(\rho w+D\rho y)\bigr) \\[1px] \delta w &= A \delta x - \rho y \\ \delta y &= D \delta w - \rho w \end{aligned} \]

We can recover the other changes as

\[ \begin{gathered} \delta\unl{w} = \epsilon\unl{v} - \delta w; \quad \delta\unl{v} = \epsilon\unl{w} - \unl{D}\,\delta\unl{w}; \\ \delta\ovl{w} = \epsilon\ovl{v} - \delta w; \quad \delta\ovl{v} = \epsilon\ovl{w} - \ovl{D}\,\delta\ovl{w}; \\ \delta\unl{x} = \epsilon\unl{z} - \delta x; \quad \delta\unl{z} = \epsilon\unl{x} - \unl{E}\,\delta\unl{x}; \\ \delta\ovl{x} = \epsilon\ovl{z} - \delta x; \quad \delta\ovl{z} = \epsilon\ovl{x} - \ovl{E}\,\delta\ovl{x}; \\ \end{gathered} \]

As an alternative, we can use \(\delta w = D^{-1}(\rho w+\delta y)\) to obtain

\begin{equation*}\left( \begin{array}{cc} H\!+\!E & A^T \\ A & D^{-1} \end{array}\right) \left( \begin{array}{c} \delta x\\\delta y \end{array}\right) = \left( \begin{array}{c} \rho x\\\rho y-D^{-1}\rho w \end{array}\right) \end{equation*}

Note that the conditions are equivalent to minimising the Lagrangian

\begin{multline*} L({w},{x},{y},\,\unl{w},\ovl{w},\unl{x},\ovl{x},\,\unl{v},\ovl{v},\unl{z},\ovl{z}) = f({x}) + \sum_{i=1}^{m} {y}_i(g_i({x})- {w}_i) \\ + \sum_{i=1}^{m} \bigl( \unl{v}_i( {w}_i+\unl{w}_i-\unl{c}_i)\!-\!\mu\log\!|\unl{w}_i| \;+\; \ovl{v}_i( {w}_i+\ovl{w}_i-\ovl{c}_i)\!-\!\mu\log\!|\ovl{w}_i| \bigr) \\ \qquad\qquad + \sum_{j=1}^{n} \bigl( \unl{z}_j({x}_j+\unl{x}_j-\unl{d}_j)\!-\!\mu\log\!|\unl{x}_j| \;+\; \ovl{z}_j({x}_j+\ovl{x}_j-\ovl{d}_j)\!-\!\mu\log\!|\ovl{x}_j| \bigr) \,. \end{multline*}

The variables are updated using a Newton step

\[ \mathbf{x}' = \mathbf{x} - \alpha \, \mathbf{\delta x} \]

where \(0<\alpha\leq 1\) is such that \(\unl{w}',\unl{x}',\unl{v}',\unl{z}' < 0\) and \(\ovl{w}',\ovl{x}',\ovl{v}',\ovl{z}'>0\). To avoid approaching too close to the boundary, we require

\[ \unl{w}_i\,\unl{v}_i > \mu \gamma, \quad \ovl{w}_i\,\ovl{v}_i > \mu \gamma, \quad \unl{x}_j\,\unl{z}_j > \mu \gamma, \quad \ovl{x}_j\,\ovl{z}_j > \mu \gamma, \]

where \(\gamma\) is a small constant, which we take to be \(1/1024\).

The parameter \(\mu\) is estimmated by

\[ \mu = \frac{1}{2(m+n)} \biggl( \sum_{i=1}^{m}\bigl(\unl{v}_i\,\unl{w}_i+\ovl{v}_i\,\ovl{w}_i\bigr) + \sum_{j=1}^{n}\bigl(\unl{z}_j\,\unl{x}_j+\ovl{z}_j\,\ovl{x}_j\bigr) \biggr) . \]

For the next step, we multiply \(\mu\) by a constant \(\sigma\), which we take to be \(1/8\).
