Geometric Representation

This page describes the theory of computable Euclidean geometry. For details on how this is implemented in Ariadne, see the Geometry Module documentation.

Introduction

One of the main concerns of Ariadne is the computation of points and sets in Euclidean space. Unfortunately, the set of points in Euclidean space is uncountable (it has continuum cardinality) and so there is no way of modelling all points in Euclidean space using binary words. The set of subsets of Euclidean space is also uncountable, and has an even greater cardinality!

To represent an uncountable set, we can use approximations. We take a set of elements which we model exactly, such as Float or Rational reals, which we call denotable elements. This denotable set may be finite or countably infinite, the former being denoted by words of a fixed length, and the latter by arbitrary length words. An approximation to an element is then a pair consisting of a denotable element and an error. Ideally, we wish to be able to approximate to arbitrary precision; this means that the set of denotable elements must be dense in the set of all elements. We can then represent arbitrary elements be a convergent sequence of approximations. In terms of a concrete representation on a computer, we can think of a such a sequence as a neverending stream of data.

The material in this section is heavily influenced by the book "Computational Analysis" by Klaus Weihrauch.

Standard representation of locally-compact second-countable Hausdorff spaces

Let \(\beta=\{I_1,I_2,\ldots\}\) be a countable base of pre-compact sets for a locally-compact second-countable Hausdorff space \(X\). A typical example is Euclidean space \(\mathbb{R}^n\) with the base of open rational cuboids. We call the elements \(I\) of \(\beta\) basic open sets and their closures \(\overline{I}\) basic compact sets. A denotable set is the finite union of basic sets, \(A=\bigcup_{j=1}^{k} I_j\) or \(A=\bigcup_{j=1}^{k} \overline{I}_j\).

A representation of an object is a sequence of basic sets which specifies the object exactly.

  • The standard representation \(\rho\) of a point \(x\in X\) or singleton set \(\{x\}\subset X\) encodes all basic open sets \(I\in\beta\) such that \(x\in I\).

The standard representation of a point is equivalent to giving a monotone sequence of convergent approximations \((I_1,I_2,\ldots)\) to \(x\) satisfying \(\overline{I}_{j}\subset I_{j+1}^\circ\) for all \(j\) and \(\{x\}=\bigcap_{j=0}^{\infty} I_j\).

  • The standard lower representation \(\theta_<\) of an open set \(U\in\mathcal{O}(X)\) encodes all basic open sets \(I\in\beta\) such that \(\overline{I}\subset U\).
  • The standard lower representation \(\psi_<\) of a closed set \(B\in\mathcal{A}(X)\) encodes all basic open sets \(I\in\beta\) such that \(B\cap I\neq\emptyset\).
  • The standard upper representation \(\psi_>\) of a closed set \(B\in\mathcal{A}(X)\) encodes all basic open sets \(I\in\beta\) such that \(B\cap \overline{I}=\emptyset\).
  • The standard upper representation \(\kappa_>\) of a compact set \(C\in\mathcal{K}(X)\) encodes all basic open covers \((I_1,\ldots,I_k)\in\beta^*\) such that \(C\subset\bigcup_{j=1}^{k}I_j\).

The standard representations \(\theta_<\), \(\psi_<\) and \(\kappa_>\) correspond to the following approximation concepts by a sequence of denotable sets \(A_n\rightarrow S\), where we have:

  • inner-approximation \(A_{i}\subset A_{i+1}\) and \(A_n\subset U\) is equivalent to \(\theta_<\) for \(U\in\mathcal{O}(X)\).
  • lower-approximation \(A_{i}\subset N_{\epsilon_i}(A_{j})\) for \(i<j\) and \(A_n\subset N_{\epsilon_n}(B)\) is equivalent to \(\psi_<\) for \(B\in\mathcal{A}(X)\).
  • outer-approximation \(A_{i+1}\subset A_{i}\) and \(C\subset A_n^\circ\) is equivalent to \(\kappa_>\) for \(C\in\mathcal{K}(X)\).

Combining lower-approximation and outer-approximation, we obtain an approximation corresponding to the standard representation \(\kappa=\psi_<\vee\kappa_>\) of compact sets:

  • effective-approximation \(C\subset A^\circ_{n} \subset A_{n} \subset N_{\epsilon_n}(C)\) for \(C\in\mathcal{K}(X)\).

Basic sets.

A BasicSet provides a building block for representing more complicated sets. Mathematically, a BasicSet type represents elements of a countable base of a topological space. More precisely, a BasicSet represents the closure of a basic set for the topology.

Generic classes fulfilling the BasicSet concept are Box (Ariadne::Box), Polytope (Ariadne::Polytope), Polyhedron (Ariadne::Polyhedron), Zonotope (Ariadne::Zonotope), Sphere (Ariadne::Sphere) and Ellipsoid (Ariadne::Ellipsoid). Subtypes are Simplex (Ariadne::Simplex) and Parallelotope (Ariadne::Parallelotope). At some point in the future, it is planned to support a TaylorSet type as a higher-order generalisation of Zonotope.

Denotable Sets

A DenotableSet implements a set as a union of basic sets. The specification of the Denotable Set concept is given by the class Ariadne::DenotableSetConcept.

Generic classes fulfilling the Denotable Set concept are ListSet<BS> (Ariadne::ListSet), GridCellListSet (Ariadne::GridCellListSet), GridMaskSet (Ariadne::GridMaskSet) and PartitionTreeSet (Ariadne::PartitionTreeSet).

Predicates and Operations on Sets

Predicates on Sets

The fundamental geometric predicates are:

  • contains(): test whether a set contains a point.
  • disjoint(): test whether two sets are disjoint.
  • subset(): test whether a set is a subset of another.
  • intersects(): test whether two sets intersect
  • superset(): Test whether the second set is a subset of the first.

All these predicates return a fuzzy logic value, since the result of the test may be impossible to determine at the given precision.

Operations on Sets

The fundamental geometric operations are:

  • open_intersection(): The intersection of the interiors of the sets.
  • closed_intersection(): The intersection of the closures of the sets.
  • union(): The union of two sets. ("join" in C++ since "union" is a reserved keyword).
  • difference(): The difference of the sets.

The union() and difference() functions always return denotable sets.

Additionally, the following operations on basic sets of appropriate types are provided:

  • convex_hull(): The convex hull of two sets or a set of points.
  • minkowski_sum(): The pointwise sum of two subsets of Euclidean space.
  • minkowski_difference(): The pointwise difference of two subsets of Euclidean space.

Approximating Sets

There are a number of ways a set \(S\) can be approximated by a set \(A\):

  • lower_approximation(): \(A\subset N_\epsilon(S)\)
  • under_approximation(): \(A\subset S\)
  • inner_approximation(): \(\overline{A}\subset S^\circ\)
  • upper_approximation(): \({\left(N_\epsilon(S^C)\right)}^C \subset A\)
  • over_approximation(): \(S\subset A\)
  • outer_approximation(): \(\overline{S}\subset A^\circ\)

The approximations lower/upper, under/over and inner/outer are dual to each other. The lower/upper approximation concepts are the weakest, and inner/outer the strongest.

The inner approximation is most natural for open sets, and the lower approximation is most natural for (unbounded) closed sets. For compact sets, both lower and outer approximations are natural.

A set \(S\) is regular if \(S^\circ=\overline{S}^\circ\) and \(\overline{S}=\overline{S^\circ}\). Both inner and under approximations are natural for regular sets, since a regular set can be considered as both open and closed.

The over and under approximations are typically used for converting "fuzzy" sets (with interval data) to sets with floating-point data. For example, the over-approximation of the fuzzy rectangle \([\overline{\underline{a}}_1,\overline{\underline{b}}_1]\times[\overline{\underline{a}}_2,\overline{\underline{b}}_2]\) is the rectangle \([\underline{a}_1,\overline{b}_1]\times[\underline{a}_2,\overline{b}_2]\), and the under-approximation is \([\overline{a}_1,\underline{b}_1]\times[\overline{a}_2,\underline{b}_2]\).

The error specification depends on the type of approximation used.

  • When approximating by a GridSet, the error is determined by the grid.
  • When approximating by a PartitionTreeSet, the error is determined by the partition scheme and the depth.
  • When approximating by a ListSet, the error is a metric error bound.

Implementation of Geometric Types and Operations

The core geometric types used by Ariadne to represent are Rectangle, Zonotope, Polytope (described by generators) and Polyhedron (described by constraints). The core geometric operations are contains(A,p), subset(A,B) and disjoint(A,B) (equivalent to intersects(A,B) ) .

Fundamental Geometric Types

  • Rectangle representation: \(l\leq x\leq u\).
  • Zonotope representation: \(x=c+Ge,\ -1\leq e\leq1\).
  • Polytope representation: \(x=Vs,\ \sum s_i=1,\ s\geq0\).
  • Polyhedron representation: \(Ax\leq b\).

Alternative representations for zonotopes, polytopes and polyhedron are given by taking \(\hat{x}=(x,1)\).

  • Zonotope representation: \(x = \hat{G}\hat{e},\ e_0=1,\ -1\leq e\leq1\).
  • Polytope representation: \(\hat{x} = Rs\), \(s\geq0\).
  • Polyhedron representation: \(C\hat{x}\geq0\).

Henceforth, we shall always assume \(-1\leq e\leq1\) and \(1\!\cdot\!s=1;\ s\geq0\).

Converting between basic sets

A Rectangle can be directly converted to a Polytope or Polyhedron without using arithmetic. A Rectangle can be easily converted to a Zonotope, and a Zonotope to a Polytope, but these conversions require arithmetic. Conversion between a Polytope to a Polyhedron can be performed using the double description algorithm.

In many cases, it is not possible to evaluate geometric predicates concerning two sets using a given real number type. For this reason, the results of a geometric predicate returns an object of type tribool, which may be true, false or indeterminate (unknown).

The conversion from a Rectangle or Zonotope to a Polytope or conversion between Polytope and Polyhedron may be of exponential complexity.

Testing inclusion

  • contains(Rectangle,Point) : Check \(l\leq x\leq u\).
  • contains(Zonotope,Point) : Solve \(x=c+Ge;\ -1\leq e\leq1\).
  • contains(Polytope,Point) : Solve \(x=Vs;\ 1\!\cdot\!s=1;\ s\geq 0\).
  • contains(Polyhedron,Point) : Check \(Ax\leq b\).

Testing intersection/disjointness

  • intersects(Rectangle,Rectangle) : Check \(l_1\leq u_2;\ l_2\leq u_1\).
  • intersects(Rectangle,Zonotope) : Solve \(x=c+Ge;\ l\leq x\leq u;\ -1\leq e\leq1\) or \(l\leq c+Ge\leq u;\ -1\leq e\leq 1\).
  • intersects(Zonotope,Zonotope) : Solve \(c_1+G_1e_1 = c_2+G_2e_2;\ -1\leq e_1\leq1;\ -1\leq e_2\leq1\).
  • intersects(Rectangle,Polytope) : Solve \(x=Vs;\ 1\!\cdot\!s=1;\ l\leq x\leq u;\ s\geq 0\) or \(l\leq Vs\leq u;\ 1\!\cdot\!s=1;\ s\leq 1\).
  • intersects(Zonotope,Polytope) : Solve \(c+Ge = Vx;\ \ 1\!\cdot\!s=1;\ -1\leq e\leq 1;\ s\geq0\).
  • intersects(Polytope,Polytope) : Solve \(V_1s_1=V_2s_2;\ 1\!\cdot\!s_1=1;\ 1\!\cdot\!s_2=1;\ \cdot s_1\geq0;\ s_2\geq0\).
  • intersects(Rectangle,Polyhedron) : Solve \(Ax\leq b;\ l\leq x\leq u\).
  • intersects(Zonotope,Polyhedron) : Solve \(Ac+AGe \leq b;\ -1\leq e\leq 1\).
  • intersects(Polytope,Polyhedron) : Solve \(AVs\leq b;\ 1\!\cdot\!s=1;\ s\geq0\).
  • intersects(Polyhedron,Polyhedron) : Solve \(A_1x\leq b_1;\ A_2x\leq b_2\).

All these problems can be solved using (a variant of) the simplex algorithm. When computing over-approximations of a set on a grid using disjoint(Rectangle R, ConvexSet S), it may be useful to pre-process S to simplify computation of an initial vertex for the feasibility problem.

Testing subset

Testing whether a convex set is a subset of a polyhedron, or whether a polytope is a subset of a convex set are easy:

  • subset(ConvexSet S, Polyhedron P) : Check disjoint(S,H) for all complementary halfspaces H of P.
  • subset(Polytope P, ConvexSet S) : Check contains(S,v) for all vertices v of P.

Checking whether a Rectangle, Zonotope or Polytope is a subset of a Rectangle can be performed directly:

  • subset(Rectangle, Rectangle) : Check \(l_1\geq l_2\ \textrm{and}\ u_1\leq u_2\).
  • subset(Zonotope, Rectangle) : Check \(\sum_{j} |G_{ij}|\leq \min\{c_i-l_i,u_i-c_i\} \forall\,i\).
  • subset(Polytope, Rectangle) : Check \(l\leq v\leq u\) for all vertices \(v\) of \(P\).

The following operations cannot be performed efficiently, but can be easily implemented by testing the vertices of the Rectangle, and are provided for conformance to the SetInterface interface.

  • subset(Rectangle, Zonotope)
  • subset(Rectangle, Polytope)

The following operation is provided to help with checking zonotopic over-approximations.

  • subset(Zonotope, Zonotope)

While a Rectangle can be directly converted to both a Polytope and a Polyhedron, the conversion to a Polytope yields \(2^d\) vertices. Hence testing subset(Rectangle, ConvexSet) is in general of exponential complexity, as is subset(Zonotope, ConvexSet). When testing subset(Rectangle R, ConvexSet S) for under-approximationg S on a grid, we need to check contains(S,v) for each grid vertex v once only, considerably reducing the amount of work.

Note that for a single test of subset(Rectangle R, Polyhedron P), we prefer to use disjoint(R,Hi), where Hi denotes the complementary halfspaces of P, but for under-approximating a polyhedron P on a grid, we prefer to check contains(P,vj) for the grid vertices vj.

Converting between a polyhedron and a polytope.

Augment the state by \(\hat{x}=(x,1)\).

  • Define a Polytope by generators \(x=\lambda g\), given as columns of the augmented generator matrix \(G'\).
  • Define a Polyhedron by constraints \(a\cdot x\geq 0\), given as rows of the augmented constraints matric \(A'\).

Construct the saturation matrix by

  • Generator \(g\) violates constraint \(a\) if \(a\cdot g<0\),
  • Generator \(g\) saturates constraint \(a\) if \(a\cdot g=0\).
  • Generator \(g\) satisfies constraint \(a\) if \(a\cdot g=0\). Saturation matrix \(S=\mathrm{sgn}(AG)\).

Generators are adjacent if the corresponding columns of the saturation matrix differ only in one row.

Zonotopic reduction methods

Throughout this sections, we use the supremum norm on \(R^n\), and the corresponding operator norm on \(\mathbb{R}^{m\times n}\).

Given a zonotope \( Z=\{ c+Ae \mid ||e||\leq 1 \}\subset \mathbb{R}^n\), where \(A\in \mathbb{R}^{n\times p}\), we wish to compute a zonotope \(Z' = \{ c + A' e' \mid ||e'||\leq 1\}\) with fewer generators i.e. \(A'\in \mathbb{R}^{n\times p'}\) with \(p'<p\). The general reduction method is to choose \( A'\) such that \( A = A' B\) with \(||B||\leq 1\). The key to zonotopic reduction is to choose a method with good properties.

A simple criterion to note is that if \(\sum_{j=1}^{p} |b_{ij}|<1\) for some \(i\), then we can improve the approximation by taking \(D=\mathrm{diag}(d_{i})\) with \(d_{i}=\sum_{j=1}^{p} |b_{ij}|\), and \(B'= D^{-1}B\) which has \(b'_{ij}=b_{ij}/\sum_{k=1}^{p} |b_{ik}|\).

It is clear that if the rows of \(B\) are close to a set of mutually orthogonal coordinate vectors, then the approximation is good, since the image of \(B\) is close to the unit ball.

An interval zonotope is a set of the form \( \{ y = c + A e \mid c\in R,\ A\in\mathcal{A} \text{ and } ||e||\leq1 \} = R + \mathcal{A} B\). To reduce an interval zonotope, we first write \( R = \{ c + Be\mid ||e||\leq 1 \}\) and combine this in \(\mathcal{A}\). To reduce \( \mathcal{A} \), write \( \mathcal{A} = A \mathcal{B} \mathcal{A} \) where \( A\in\mathcal{A}\) and \(A\mathcal{B}\ni I\). Then take \( \mathcal{C} = \mathcal{B} \mathcal{A} \) and \( || \mathcal{C} || = \sup_{i]1}^{n} \sum_{j=1}^{p} \max |\mathcal{C}_{ij}| \), where \( \max |\mathcal{C}_{ij}| = \max\{ |x| \mid x\in \mathcal{C}_{ij}\).
