NaiveKleenean Class Reference

#include <logical.hpp>

Description

A logical class representing the result of a undecidable predicate over a continuous (uncountable) data type.

A canonical example is (strict) positivity of a real number given only a convergent sequence, since without error bounds we can never know whether a given approximation is sufficiently close to deduce any properties of the number.
