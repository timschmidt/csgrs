Description

A prototype interface for subpavings.

A sub-paving is a paving-type set which is the restriction of another paving to a cell, called the root_cell of the subpaving. In general, a sub-paving supports the non-modifying operations of a paving.

The only modifying operations on a sub-paving which are logically allowable are those which apply to sub-cells of the root cell. These operations modify the paving itself.
