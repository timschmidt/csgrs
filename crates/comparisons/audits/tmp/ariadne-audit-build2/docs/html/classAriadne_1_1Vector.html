#include <vector.hpp>

Description

template<class X>
class Ariadne::Vector< X >

Vectors over some type X. Corresponds to elements of a module over a mathematical ring, or a vector space over a field. May also be used if X is an algebra A over another field. It must be possible to add and multiply any two elements of the vector.
