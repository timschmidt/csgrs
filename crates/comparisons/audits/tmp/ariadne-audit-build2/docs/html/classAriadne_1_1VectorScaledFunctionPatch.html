#include <scaled_function_patch.hpp>

Description

template<class M>
class Ariadne::VectorScaledFunctionPatch< M >

A a type of function model in which a the restriction of a vector function \(f:\R^n\rightarrow\R^m\) on a domain \(D\) is approximated by the composition of a scaling function \(s^{-1}:D\fto\I^n=[-1\!:\!+1]^n\) with a vector function \(p\) (such as a polynomial) on \(\I^n\) with uniform errors \(e\).

Template Parameters
MThe class used for the component function models over the box \([-1\!:\!+1]^n\).
See also
TaylorModel, ScaledFunctionPatch, ValidatedVectorMultivariateTaylorFunctionModelDP
