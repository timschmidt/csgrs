BoundedConstraintSet Class Reference
Core Modules » Geometry Module | Core Modules » Geometry Module » Exact sets

#include <function_set.hpp>

Description

A set defined as the intersection of an exact box with preimage of an exact box (the codomain) under a continuous function. The set is described as \(S=D\cap g^{-1}(C) = \{ x\in D \mid g(x)\in C\}\) where \(D\) is the domain, \(C\) is the codomain and \(g\) the function.
