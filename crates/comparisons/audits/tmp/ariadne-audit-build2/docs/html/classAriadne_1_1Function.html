#include <function.hpp>

Description

template<class P, class SIG>
class Ariadne::Function< P, SIG >

A generic continuous function.

Template Parameters
PThe information paradigm tag, which can be either ExactTag, EffectiveTag, ValidatedTag, or ApproximateTag.
SIGThe signature, which has the standard C++ form RES(ARG), so signature Real(RealVector) indicates a function \(f:\R^n\rightarrow\R\).

Class representing general continuous functions .
