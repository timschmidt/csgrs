Installation Guide

These installation instructions have been tested on Ubuntu 16.04 and OSX 10.11.

For the Ubuntu installation, we will refer to packages available on Aptitude. The OSX installation instead will assume you are using the Brew package manager.

The build system is CMake. The compilers we tested the library under Ubuntu are GCC and Clang, while for OSX is Clang.

Dependencies

Some packages are required to download and compile the sources. The syntax to install a package is:

sudo apt install <package-name>

The mandatory packages are the following:

  • git : to download the source code and retrieve a given version of the distribution;
  • cmake : to automate the build;
  • g++ or clang++: to compile the C++ sources;
  • libgmp-dev libmpfr-dev : internal dependencies (numeric libraries).
  • libboost-dev libboost-serialization-dev libboost-thread-dev : internal dependencies (support libraries).

You can install all the mandatory packages with:

sudo apt install git cmake g++ clang libgmp-dev libmpfr-dev libboost-dev libboost-serialization-dev libboost-thread-dev

The following packages instead are optional:

  • libbdd-dev : enables Binary Decision Diagram support, with improved efficiency (recommended);
  • libcairo2-dev : allows to plot analysis results (recommended);
  • libgtk2.0-dev : allows pop-up graphics windows;
  • python2.7-dev libboost-python-dev : to build the Python interface (recommended).
  • doxygen : to build the documentation (recommended).

OSX

Install the Command Line Developer Tools (will also be asked when installing Homebrew) from the Apple Store

Install Homebrew from http://brew.sh/ 

Homebrew packages required: \code cmake boost gtk cairo \endcode

Optionally, if you want to build the documentation, you need Doxygen and a working Latex distribution (including the Math packages).

Download

You can check out the latest development version on the Git repository into a local directory ariadne-development by typing:

git clone https://bitbucket.org/ariadne-cps/development.git ariadne-development

Building

To build the library in a clean way, it is preferable that you set up a build subdirectory:

$ mkdir build
$ cd build

Then you can prepare the build environment:

$ cmake ..

At this point, if no error arises, you can build the library libariadne.so itself:

$ make ariadne

On a multi-core processor you can use multiple cores to speed up the build process. e.g. To use 4 cores, type

$ make -j 4 ariadne

If you prefer to use the Python interface rather than the C++ library, you should build the file ariadne.so with:

$ make pyariadne

To compile a single example, e.g. the tutorial, use:

$ make tutorial

To compile all examples, use

$ make examples

Optionally, you can also build and run the test suite for the library:

$ make tests test

Ideally, no error should appear. Tests named "_issue" indicate known problems with the code, and may fail. This should not however impact the correctness of the results, but may indicate problems with accuracy, efficiency, or termination on certain problems.

To build libraries, tests and examples, simply type:

$ make

or

$ make all

To build the documentation, use:

$ make doc

The documentation will be placed in the directory build/docs/ .

Installing globally

To install the library globally, you must do

$ make install

To find the installed library under Ubuntu, you may need to set the LD_LIBRARY_PATH in the .bashrc file:

export LD_LIBRARY_PATH=$LD_LIBRARY_PATH:/usr/local/lib
