Enclosure Class Reference
Core Modules » Dynamics Module

#include <enclosure.hpp>

Description

An enclosure for part of the reachable or evolved set of a dynamical system. Defined as \(x=f(s)\) for \(s\in D\) satisfying \(g(s)\leq0\) and \(h(s)=0\).
