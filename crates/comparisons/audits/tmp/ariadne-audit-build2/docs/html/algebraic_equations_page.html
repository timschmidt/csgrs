Algebraic Equations

This page describes methods for the rigorous numerical solution of algebraic equations. For details on how this is implemented in Ariadne, see the Algebraic equation solvers documentation

Consider the system of nonlinear algebraic equations

\[ f(x) = 0; \quad x\in D \]

where \(f:\R^n\rightarrow \R^n\) and \(D\) is a compact box in \(\R^n\).

The Interval Newton Method

The interval Newton method is a direct intervalisation of the standard Newton method. Suppose \([x]\) is a box and \(x\in[x]\). Suppose further that there is a zero of \(f\) at \(x^*\in[x]\). Then by Taylor's theorem we have

\[ 0 = f_i(x^*) = f_i(x) + Df_i(\xi_i) (x^*-x) \]

for some \(\xi\in[x]\). Denoting the matrix formed by the gradients of \(Df_i(\xi_i)\) by \(Df(\xi)\) (note that this is not \(Df\) evaluated at a single point \(\xi\), we obtain

\[ 0 = f(x^*) = f(x) + Df(\xi) (x^*-x) \]

and by rearranging,

\[ x^* = x - Df(\xi)^{-1} f(x) . \]

The interval Newton method is given by the contraction algorithm

\[ \boxed{ [x_{n+1}] = [x_n] \cap \bigl( x_n - Df[x_n]^{-1} f(x_n) \bigr) } \]

where \(x_n\in[x_n]\) and \(Df[x]\) is the interval matrix of all partial derivatives \( \partial f_i/\partial x_j[x]\).

The Krawczyk method

The main disadvantage of the interval Newton method is the need to invert the interval matrix \(Df[x]\) which can be very wide. The Krawczyk method is a modification of the interval Newton method which avoids this difficulty.

Let \(x\in[x]\) and \(J\) be any matrix. Then from the equation,

\[ 0 = f(x) + Df(\xi) (x^*-x) \]

we multiply through by \( -J \) to obtain

\[ 0 = -Jf(x) - JDf(\xi)(x^*-x) \]

Now add \((x^*-x)\) to both sides to obtain

\[ x^*-x = -Jf(x) + (I - JDf(\xi)) (x^*-x) \]

and rearrange to obtain

\[ x^* = x -Jf(x) + (I - JDf(\xi)) (x^*-x) . \]

The Krawczyk method is given by the contraction algorithm

\[ \boxed{ [x_{n+1}] = [x_n] \cap \bigl( x_n -J_nf(x_n) + (I - J_nDf[x_n]) ([x_n]-x]) \bigr) } \]

Typically, we take either

\[ \boxed{ J = \mathrm{mid}(Df[x]) \text{ or } J=Df(x) } \]

The Modified Krawczyk Method

The main disadvantage of the Krawczyk method is the need to compute the matrix \(I-JDf[x_n]\) explicitly, since otherwise the interval errors are too large. This is especially undesirable if \(Df\) is sparse, since then typically \(J\) will not be sparse, and while \(JDf[x_n]\) will typically be close to \(I\), the off-diagonal elements are significant. However, we can avoid losing the structure of \(Df\) by the following modification.

Let \(K\) be any matrix. Then from the equation

\[ 0 = f(x) + Df(\xi) (x^*-x) \]

we negate the left-hand side and add \(K(x^*-x)\) to both sides to obtain

\[ K(x^*-x) = -f(x) + (K-Df(\xi)) (x^*-x) \]

Hence

\[ x^* = x - K^{-1} \bigl( f(x) + (Df(\xi)-K) (x^*-x) \bigr) \]

This gives a modified contraction algorithm

\[ [x_{n+1}] = x_n - [K_n^{-1}] \bigl( f(x_n) + (Df[x_n]-K_n) ([x_n]-x_n) \bigr) \]

Typically, we take \(K=\mid(Df[x])\) so that \(Df[x_n]-K_n\) is the matrix \(\mathrm{rad}(Df[x_n])\). Note that we need to take an interval solver for finding \(K^{-1}\), since the method is only valid if \([K^{-1}]\) contains the exact inverse of \(K\).

In many cases, we have a factorisation \(K=PQR\) where \(P^{-1}\) and \(R^{-1}\) are sparse matrices which can be easily and exactly computed, and \(Q\) is block-diagonal. We can then write \([Q]=[P^{-1}KR^{-1}]\) where the inverses are exact and the product is computed with interval arithmetic. Then \(K^{-1} \in R^{-1} [Q]^{-1} P^{-1} = [K^{-1}]\), so the equation \(K[x]=[r]\) can be solved easily.

As an example, in using the modified Krawczyk method to solve the Karush-Kuhn-Tucker conditions for nonlinear optimisation, we have to invert the matrix

\[ \left(\begin{matrix} Z&0&X\\-A&H&0\\0&A^T&I\\ \end{matrix}\right) \]

which factorises

\[ \left(\begin{matrix} Z&0&X\\-A&H&0\\0&A^T&I\\ \end{matrix}\right) = \left(\begin{matrix} Z&0&0 \\ 0&I&0 \\ 0&0&I \end{matrix}\right) \left(\begin{matrix} I&0&0 \\ -A&I&AZ^{-1}X \\ 0&0&I \end{matrix}\right) \left(\begin{matrix} I&0&0 \\ 0&H-AZ^{-1}XA^T&0 \\ 0&0&I \end{matrix}\right) \left(\begin{matrix} I&0&0 \\ 0&I&0 \\ 0&A^T&I \end{matrix}\right) \left(\begin{matrix} I&0&Z^{-1}X \\ 0&I&0 \\ 0&0&I \end{matrix}\right) \]

To compute the full interval inverse, we only need to invert the matrix \([H-AZ^{-1}XA^T]\), which is small and dense.

Hotstarting Validated Algebraic Equation Solvers

A validated algebraic equation solver requires an initial box containing the solution. We often have a candidate approximate solution \(\tilde{x}\), and wish to prove the existence of a solution near \(\tilde{x}\). A precise definition of "near" is as follows:

A solution \(x^*\) of \(f(x)=0\) is near \(\tilde{x}\) if \(\langle Df(\langle \tilde{x},x^*\rangle)\rangle\) is invertible.

Here, \(\langle \cdot \rangle\) denotes the convex hull. We conjecture that there is at most one solution near any starting point. A sufficient condition, which may be easier to check, is invertibility of \([Df([\tilde{x},x^*\rangle])]\), i.e. the interval hull of the Jacobians over the interval hull consists of invertible matrices.

An algorithm for computing a solution given a hotstart is to compute interval Newton iterates. Whenever an iterate \([\hat{x}]\) is disjoint from \([x]\) in the \(i\)th component, we take \(\mathrm{hull}([\hat{x}_i],\mathrm{mid}([x_i]))\) as the new component.

Solving Underdetermined Algebraic Equations

If \( f:\R^n\fto\R^m \) with \( m < n \), then the system of equations \(f(x)=0\) is underdetermined. A Newton-like step can be taken as

\[ x_{n+1} = x_n - A^T (AA^T)^{-1} f(x_n) \text{ where } A=Df(x_n) . \]
