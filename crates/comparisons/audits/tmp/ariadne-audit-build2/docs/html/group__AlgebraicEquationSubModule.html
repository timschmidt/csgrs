Description

Classes and functions for solving nonlinear algebraic equations.

For the mathematical theory of algebraic equations, including implicit function problems, see the Algebraic Equations Page.

A Solver class provides functionality for solving algebraic equations, as defined in the SolverInterface. Two basic kinds of problem are considered. The first is computing roots of a function \(f:\R^n\to\R^n\), which are generically isolated points. The second kind of problem is solving parametrised equations, so for a function \( f:\R^m\times\R^n\to\R^n \), we find a function \( h:\R^m\to\R^n \) such that \( f(x,h(x))=0 \) for all \( x \) in some domain \( D \).

Concrete solvers include IntervalNewtonSolver and KrawczykSolver.
