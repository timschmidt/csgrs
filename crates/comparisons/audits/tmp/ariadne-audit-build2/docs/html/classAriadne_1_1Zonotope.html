Zonotope Class Reference

#include <zonotope.hpp>

Description

A zonotope of arbitrary dimension.

A zonotope is a set of the form \(c+Ge\), where \(||e||_{\infty}\leq1\). The columns of the matrix \(G\) are the generators of the zonotope.

Zonotopes are always is_bounded. A zonotope always contains its centre point, so can never be empty. However, it may not be regular.

The intersection and membership tests may be performed using algorithms from:
Guibas, Leonidas J.; Nguyen, An; Zhang, Li, "Zonotopes as bounding volumes." Proceedings of the Fourteenth Annual ACM-SIAM Symposium on Discrete Algorithms (Baltimore, MD, 2003), 803–812, ACM, New York, 2003.

Storage: A Zonotope in dimension d with n generators is described by d(n+1) real numbers. The ith component of the centre is given by the ith element, and the ith component of the kth generator is given by the (kd+i)th element.
