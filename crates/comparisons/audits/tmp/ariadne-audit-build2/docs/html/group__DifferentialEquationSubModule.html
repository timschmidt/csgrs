Differential equation solvers
Core Modules » Solver Module

Description

Classes and functions for solving linear and nonlinear differential equations equations.

An Integrator class provides functionality for solving differential equations, as defined in the IntegratorInterface. Concrete solvers include TaylorPicardIntegrator and TaylorSeriesIntegrator.
