Function Evaluation

Ariadne is primarily a module for set-based computation. For this reason, functions are best defined by their actions on sets. However, we sometimes also want to compute function values on points, and to evaluate real-valued functions. For this reason, we also allow definition of functions on points.

We distinguish between computations on fixed-precision and multiple-precision types, between computations on points and sets, and between exact and approximate computations.

The basic computation on sets is to compute over-approximations to the image of basic sets From these computations, arbitrarily-accurate computations can be performed. The basic computation on points can be exact and approximate, as appropriate.

Computations on sets.

A valid arbitrary-precision computation on sets is defined as follows If \(f\) is a mathematical function, and BS is a basic set type, then a valid representation f of \(f\) is a function which, for any basic set \(A\), returns a set \(B\) such that \(f(A)\subset B\), and such that whenever \(A_n\) is a decreasing sequence of sets with \(\bigcap_{n=1}^{\infty} A_n=\{x\}\), then \(\bigcap_{n=1}^{\infty} B_n=\{y\}\), where \(y=f(x)\).

A valid fixed-precision computation on sets is an over-approximation. In other words, a valid representation f of \(f\) is a function which, for any basic set \(A\), returns a set \(B\) such that \(f(A)\subset B\). No guarentees on the accuracy are required. Note that it does not make sense to consider a sequence \(A_n\) converging to a point for fixed-precision types.

Computations on points.

If a denotable state type is invariant under a class of functions (e.g. polynomial functions on a ring), then the image of a point is given exactly. Otherwise, a fuzzy point is given, which is a point defined using interval coefficients. A Point<Interval<R>> can be automatically converted to a Rectangle<R>.

Note that even if f is exact, it is impossible to compute the action of \(f\) on a set just from the action of f on points, unless a modulus of continuity for \(f\) is known. However, it is possible to compute the action of \(f\) on sets from the action on fuzzy points.

Computations on real numbers.

Most continuous functions used in science and engineering are built up from elementary real-valued functions, either arithmetical or defined using Taylor series expansions. For this reason, Ariadne provides extended operations for computation on real-valued functions.

Arbitrary-precision computations may be exact or approximate. The function f(x) computes \(f(x)\) exactly, if possible. If exact computation is not possible, then f(x) either returns an interval containing the exact result, or gives an error at compile time. If a floating-point (i.e. non-interval) result is required, then the type of error must be explicitly specified. The function f_down(x) computes a lower-approximation to \(f(x)\), and f_up(x) computes an upper-approximation. The function f_approx(x) computes \(f(x)\) approximately, with no control on the error bound. For some arithmetical operations, the error of f_approx(x,y) may be specified.

Note that in many cases, including arithmetic and simple functions, it is possible to compute an interval \(J\) containing \(f(I)\) using f_down and f_up. This allows an implementation of the standard set-based function f(I). It is not, in general, possible to perform evaluation of functions on sets from their definitions on points, though in many cases such a computation can be extracted. In particular, we can construct interval computations from pointwise computations in the following cases, if error bounds on \(f(x)\) are known.

  • The function is Lipschitz with a known Lipschitz constant e.g. \(\sin,\ \cos\).
  • The function is monotone e.g. \(\exp\).
  • The function is piecewise-monotone with known branches e.g. arithmetic.
