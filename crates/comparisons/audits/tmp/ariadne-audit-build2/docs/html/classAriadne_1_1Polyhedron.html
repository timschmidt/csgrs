Polyhedron Class Reference

#include <polyhedron.hpp>

Description

A polyhedron (not necessarily is_bounded polyhedral set) described by a system of linear inequalities.

The set is described as \( \{ x\in\mathbb{R}^d \mid Ax \leq b \} \) where \(A\) is a \(n\times d\) matrix and \(b\) is a vector of size \(n\).
