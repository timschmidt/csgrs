NaiveReal Class Reference
Core Modules » Numeric Module

#include <naive_real.hpp>

Description

Real number type defined as limits of convergent sequences of (dyadic) rationals, without bounds on the convergence rate.

It is possible to compute arbitrarily accurate (dyadic) rational approximations, but the convergence rate is not known, so at no point in the the computation can anything concrete be deduced about the value of the number.

In principle useless for rigorous computation, but quickly-computed approximations to real numbers may be useful for preconditioning rigorous algorithms.
