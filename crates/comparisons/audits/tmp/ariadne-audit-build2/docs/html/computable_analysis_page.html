Foundations of Computable Analysis

This page describes the information-theoretic foundations of computable analysis. For details on how this is implemented in Ariadne, see the Information documentation.

For more detailed information on topological constructions, see the Topological Foundations page. Also see the Logical Foundations page, the Computable Real Numbers page.

For more information, see

  • P. Collins, "Computable Analysis with Applications to Dynamic Systems", Mathematical Structures in Computer Science 30(2), pp. 173-233, 2020.

Computability on Uncountable Spaces

Computable analysis deals with rigorous computations on the uncountable spaces arising in analysis, topology and geometry. In order to represent elements of uncountable spaces, we need sequences or streams of data, instead of finite lists or words. Computations are performed by ordinary Turing machines, but run forever, reading data from the input streams and writing to the output streams. In order to be useful, it must be possible to obtain meaningful information from a finite prefix of the output data, just as from a prefix of the decimal expansion \(\pi=3.14159\cdots\) we know \(\pi\in[3.14159\!:\!3.14160]\).

Formally, we fix a finite alphabet of symbols \(\Sigma\), such as the binary alphabet \(\{0,1\}\), and consider computation on \(\Sigma^\omega\). (One can also use countable alphabets, such as \(\N\), which gives rise to the same computability theory, but a less realistic theory of computational complexity.) A natural topology on \(\Sigma^\omega\) is generated by cylinder sets of the form \(W=\{ p\in\Sigma^\omega \mid p|_{|w|}=w \}\) for \(w\in\Sigma^*\). A Turing machine \(\mathcal{M}\) computes a partial function \(\eta_\mathcal{M}:\Sigma^\omega\pfto\Sigma^\omega\) which is continuous and is defined on a \(G_\delta\)-subset of \(\Sigma^\omega\) (i.e. on a countable intersection of open sets). We say a continuous partial function \(\eta:\Sigma^\omega\pfto\Sigma^\omega\) is machine-computable there is a Turing machine \(\mathcal{M}\) for which \(\eta=\eta_\mathcal{M}\).

Representations

A representation of a set \(X\) is a partial surjective functon \(\delta:\Sigma^\omega\psfto X\). An element \(p\in\Sigma^\omega\) such that \(\delta(p)=x\) is a \(\delta\)-name of \(x\).

The representation \(\delta\) induces the natural quotient topology on \(X\), with \(U\) open in \(X\) if, and only if, \(\delta^{-1}(U)\) is open in \(\Sigma^\omega\). If \(X\) already has a topology \(\tau\), we say \(\delta\) is a quotient representation of \((X,\tau)\) if \(\tau\) is the induced quotient topology of \(\delta\).

A representation is admissible if it is a "weakest" representation inducing the same topology. i.e. if whenever \(\phi:\Sigma^\omega\psfto X\) is continuous, then there exists continuous \(\eta: \Sigma^\omega\pfto\Sigma^\omega\) such that \(\phi=\delta\circ\eta\).

By a result of Schröder (2002), a space has an admissible quotient representation if, and only if, it is a quotient of a countably-based space.

The purpose of a representation is to transfer computability notions from \(\Sigma^\omega\) to \(X\). Given representations \(\delta_X\) of \(X\) and \(\delta_Y\) of \(Y\), a function \(f:X\to Y\) is \((\delta_X;\delta_Y)\)-computable if there is a machine-computable function \(\eta:\Sigma^\omega\pfto\Sigma^\omega\) such that \(f\circ\delta_X = \delta_Y\circ\eta|_{\dom(\delta_X)}\). The notion extends to functions \(f:X_1\times\cdots\times X_n\to Y\) in a natural way. An element \(y\) of \(Y\) is \(\delta_Y\)-computable if there is a machine with no inputs which outputs a name of \(y\).

A representation \(\delta'\) of \(X\) is weaker than \(\delta\) if there is a machine-computable function \(\eta:\Sigma^\omega\pfto\Sigma^\omega\) such that \(\delta'=\delta\circ\sigma\). In other words, given a \(\delta\)-name \(p\) of \(x\), we can compute a \(\delta'\)-name \(p'\). Representations are equivalent if each is weaker than the other.

For most spaces encountered in practise, there is precisely one natural representation, up to equivalence. Rather than explicitly mention this every time, we define a type \(\mathbb{X}\) as a pair \((X,[\delta])\) where \(X\) is a set/space, and \([\delta]\) is an equivalence class of representations of \(X\). For example, the real numbers have a unique equivalence class of representations under which arithmetic and comparisons are computable. (See the real_numbers page for more details.)

Universal type-two Turing machine

There exists a representation \(\sigma\) of continuous \(\Sigma^\omega\pfto\Sigma^\omega\), and a corresponding universal type-two Turing machine \(\mathcal{U}\) computing a function \(\epsilon:\Sigma^\omega\times\Sigma^\omega\to\Sigma^\omega\) with the following properties:

  • If \(\eta:\Sigma^\omega\pfto\Sigma^\omega\) is a machine-computable function, then there is a computable sequence \(p:\Sigma^\omega\) such that \(\sigma(p)=\eta\).
  • If \(p\in\dom(\sigma)\) and \(q\in\dom(\sigma(p))\), then \((p,q)\in\dom(\epsilon)\), and \(\epsilon(p,q)=[\sigma(p)](q)\).

In other words, \(p:\Sigma^\omega\) encodes the information needed to specify a continuous function \(\eta\) acting on sequences. If \(\eta\) is a computable function, then \(p\) is a computable sequence. The information encoded by \(p\) can be read by the Turing machine \(\mathcal{U}\) and used to compute the image of the input \(q\) under the encoded function \(\eta\).

Standard Type Constructions

There are a number of standard ways of constructing new types from old. In particular

  • Given types \(\X_0,\X_1,\X_2,\ldots\), the finite products \(\X_0\times\cdots\times\X_{n-1}\) and countable products \(\prod_{n=0}^{\infty}X_n\).
  • Given type \(\X,\Y\), the function type \(\X\to\Y\), also denoted \(\Y^\X\).
  • Given type \(\X\) and a subset \(S\), the subtype formed by restricting the representation of \(X\) to \(S\).

Effective and Validated Information

Given a type \(\X=(X,[\delta])\), given a word \(w\) we can consider the set \(\delta(w\Sigma^\omega)=\{x\in X\mid \exists p\in\Sigma^\omega, \delta(p)=x \wedge p|_{|w|}=w\}\). In other words, the set of all points with a name which has a prefix \(w\).

In general, these sets are neither open nor closed nor compact. However, for many representations, these sets are either open neighbourhoods, or compact sets.

In particular, we have a countable collection \(\widehat{X}\) of subsets of \(X\).

We call the information provided by a full name of an element \(X\) effective information, and information provided by a finite prefix of a full name validated (or verified).

Although effective information is stronger than validated information, there is no canonical conversion from effective to validated information, since each prefix of a name provides validated information. Instead, for every integer \(n\), we can extract the validated information provided by the word \(p|_n=p_0p_1\cdots p_{n-1}\).

We say a Turing machine \(\mathcal{M}\) computing a function \(\eta:\Sigma^\omega\to\Sigma^\omega\) is proper if it eventually reads every symbol for any valid input. Examples of non-proper Turing machines include those computing functions with constant pieces e.g. \(f(x)=\max(0,x)\). However, any non-proper machine can be converted to a proper machine computing the same function by unnecessarily reading extra symbols of the input stream.

Given representation \(\delta_{X},\delta_{Y}\) of \(X,Y\), a computable operator \(f:\X\to\Y\), and a Turing machine \(\mathcal{M}\) computing \(\eta_\mathcal{M}:\Sigma^\omega\to\Sigma^\omega\), we can consider computing applying \(\mathcal{M}\) to the partial information provided by a word \(w\in\Sigma^*\) which is a prefix of \(p\in\dom(\eta_\mathcal{M})\). As long as \(\mathcal{M}\) is proper (i.e. needs to access the complete sequence \(p\) to compute \(\eta_\mathcal{M}(p)\)), when applied to \(w\), the computation at some point needs to access the input beyond the information provided by \(w\). At this point, we terminate the computation, and output the word currently on the output stream. In this way, any proper Turing machine computing \(\eta:\Sigma^\omega\pfto\Sigma^\omega\) induces a natural operation \(\Sigma^*\to\Sigma^*\). Interpreting the computation on \(X,Y\), we obtain a function \(\hatX\to\hatY\).

Similarly, given representations \(\delta_{X_1},\delta_{X_2},\delta_{Y}\) of \(X_1,X_2,Y\), a computable operator \(f:\X_1\times \X_2\to \Y\), and a Turing machine \(\mathcal{M}\) computing \(\eta_\mathcal{M}:\Sigma^\omega\times\Sigma^\omega\to\Sigma^\omega\), we can consider computing on a finite prefix \(w_1\) of the first input \(p_1\), resulting in a machine-computable function \(\Sigma^*\times\Sigma^\omega\to\Sigma^*\), inducing a function \(\hatX_1\times X_2 \to\hatY\). In other words, a proper binary operator can be applied to an effective and a validated argument.

Effective to validated conversion

Note, however, that there is no general effective-to-validated conversion, even for functions. Even though an effective function can be applied to a validated argument, and this encodes all the information about the function, an algorithm to compute information about a function by evaluating on different arguments, still returns effective information, and typically will not terminate. (An example could be computing the definite integral; one can compute \(\int_0^1f(x)dx\) arbitrarily accurately given the function \(\widehat{\R}\to\widehat{\R}\) induced by \(f\).)
