◆ operator""_x()

FloatDP operator""_x ( long double lx)

Indicate that a floating-point literal is the exact value of a number in double-precision.

The input lx is converted first converted to a double-precision value x. If lx and x differ, then the decimal literal input to lx almost certainly does not represent a double-precision number exactly, and an assertion fails.

For example, 0.625_x yields the exact double-precision value \(5/2^3\), but 0.6_x fails, since \(3/5\) is not exactly representable as a double-precision number.

ExactDouble operator""_pr ( long double lx)
inline

Indicate that a floating-point literal is sufficiently precise that it can safely be taken to represent the closest double-precision floating-point number.

For example, writing 0.14285714285714285_pr claims that the exact decimal "0.14285714285714285" should be interpreted as the closest double-precision floating-point number, which has exact value \(0.142857142857142849212692681248881854116916656494140625\).
