#include <procedure.hpp>

Description

template<class Y>
class Ariadne::Vector< Procedure< Y > >

An algorithmic procedure for computing a function.

A Procedure is more efficient to compute than a Formula, since common subexpressions have already been removed. However, it is also more difficult to manipulate, so it should usually only be used when no further manipulations of the function are possible.
