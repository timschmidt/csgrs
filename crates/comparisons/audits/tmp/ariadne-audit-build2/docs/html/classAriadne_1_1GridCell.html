#include <grid_cell.hpp>

Description

A cell of a grid paving. Note that this class represents the closed cell. It is uniquely defined by the path from the primary cell and is exactly on cell in a grid. This is different from the GridOpenCell which is open and the path from the root cell defines its lower left sub cell wheres the complete open cell is a union of 4 cells.

This class does not contain the tree structure, so cannot be used in cursors/iterators.
