Description

template<class F>
class Ariadne::Bounds< F >

Validated bounds on a number with floating-point endpoints supporting outwardly-rounded arithmetic.

Note that direct construction from a floating-point number is prohibited, since FloatDPBounds(3.3,dp) would the singleton interval \([3.2999999999999998224,3.2999999999999998224]\) (the constant is first interpreted by the C++ compiler to give a C++ double, whereas FloatDPBounds(3.3_decimal,dp) yields the interval \([3.2999999999999998224,3.3000000000000002665]\) enclosing \(3.3\).

Comparison tests on Bounds use the idea that an interval represents a single number with an unknown value. Hence the result is of type ValidatedKleenean, which can take values { True, False, Indeterminate }. Hence a test \([\underline{x},\overline{x}]\leq [\underline{y},\overline{y}]\) returns True if \(\overline{x}\leq \underline{y}\), since in this case \(x\leq x\) whenever \(x_1\in[\underline{x},\overline{x}]\) and \(y\in[\underline{y},\overline{y}]\), False if \(\underline{x}>\overline{y}\), since in this case we know \(x>y\), and Indeterminate otherwise, since in this case we can find \(x,y\) making the result either true or false. In the case of equality, the comparison \([\underline{x},\overline{x}]\)== \([\underline{y},\overline{y}]\) only returns True if both intervals are singletons, since otherwise we can find values making the result either true of false. To test equality of representation, use same(x,y)

To obtain the lower and upper bounds of the possible values, use x.lower() and x.upper(). To obtain a best estimate of the value, use x.value(), which has an error at most x.error(). If \(v\) and \(e\) are the returned value and error for the bounds \([l,u]\), then it is guaranteed that \(v-e\leq l\) and \(v+e\geq u\) in exact arithmetic.

To test if the bounds contain a number , use models(Bounds<F>,F), and to test if bounds are inconsistent use inconsistent(x,y), and to test if x provides a better approximation, use refines(x,y).

See also
Real, FloatDP, FloatMP, Float, Ball, UpperBound, LowerBound, Approximation.
Python interface

In the Python interface, Ariadne validated bounds can be constructed from Python literals of the form {a:b} or (deprecated) [a,b] . The former is preferred, as it cannot be confused with literals for other classes such as Vector and Array types. Automatic conversion is used to convert FloatBounds literals of the form {a,b} to an FloatBounds in functions.

Care must be taken when defining intervals using floating-point coefficients, since values are first converted to the nearest representable value by the Python interpreter.

FloatDPBounds({1.1:2.3}) # Create the interval [1.1000000000000001, 2.2999999999999998]
FloatDPBounds({2.5:4.25}) # Create the interval [2.5, 4.25], which can be represented exactly
FloatDPBounds([2.5,4.25]) # Alternative syntax for creating the interval [2.5, 4.25]
