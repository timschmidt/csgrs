Core Modules » Solver Module » Optimisation solvers

#include <nonlinear_programming.hpp>

Description

Solver for linear programming problems using invalid interior point methods.

Introduces variables \(w\) and attempts to find \(x\in D\) and \(w\in C\) such that \(g(x)=w\). The dual variables \(y\) are unconstrained Lagrange multipliers for \(y\cdot(g(x)-w)=0\).

Precondition

A box \(X\) which definitely contains a feasible point, and contains a local optimum.
