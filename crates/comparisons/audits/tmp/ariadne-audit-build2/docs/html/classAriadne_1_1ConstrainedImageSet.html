ConstrainedImageSet Class Reference
Core Modules » Geometry Module | Core Modules » Geometry Module » Exact sets

#include <function_set.hpp>

Description

A set defined as the image of the intersection of a box \(D\) and a constraint set \(g^{-1}(C)\) under a function \(f\). In other words, \(S=f(D\cap g^{-1}(C))\).
